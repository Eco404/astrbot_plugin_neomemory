# NeoMemory 能力与验证范围

| 能力 | 使用入口 | 需要持续观察的表现 |
| --- | --- | --- |
| 采集与身份 | 持久待写、逻辑用户、会话空间、文本清理、私聊图片 | 适配器提供的数据决定昵称、账号归属与附件可用性 |
| 长期抽取 | 背景窗口联合抽取原子、事件、画像和关系，单独维护主题 | 主体、指代、限定、否定和多话题可能产生遗漏或错误 |
| 主题与短期 | 手动或自动整理主题，按会话维护滚动摘要 | 跨事件归纳可能重复事件，纯插件预判与宿主实际截断可能有偏差 |
| 召回 | 被动召回、主动回忆及笔记、共享字节预算、召回测试 | 大空间有候选上限，命中数量与答案正确性需分别评估 |
| 治理与恢复 | 来源和版本查阅、人工保护、任务重试、全量与分板块重构 | 输入、模型设置和任务范围须与检查点一致 |
| 外部联动 | 陪伴插件外部记忆接口、人格消息清理 | 多适配器、多人格与长期自然运行的覆盖仍有限 |

存储测试验证首次建库、业务事务和重启重开。浏览器验证覆盖页面操作。模型质量需要使用带来源依据的独立会话判断。回放前固定模型、输入范围和评估口径，分别记录直接支持、无据结果、遗漏、人工恢复次数与延迟。

抽取评估允许自然的措辞、详略和选材差异。以原话核对人物归属、条件、否定、行动进度和承诺范围，并判断结果能否履行该板块的用途。人格关系允许人格自主判断对方，涉及谁说过、做过或答应过什么时仍按原话核实。缺少一个细节是否影响质量，取决于它是否改变原意、妨碍续聊或明显削弱该板块的表达。

完整的安装与使用说明见[插件首页](../README.md)，结构和作用域见[架构要求](开发计划.md)。

## 本地测试入口

在 Conda `astrbot` 环境中，将 AstrBot 4.29.3 源码和本仓库加入 `PYTHONPATH`。运行前可将 `ASTRBOT_ROOT` 指向临时目录，隔离宿主生成的本地文件。

| 命令 | 覆盖内容 |
| --- | --- |
| `python -m pytest -q --ignore=tests/tooling` | 插件行为、数据库事务、模型协议及宿主集成 |
| `python -m pytest -q tests/tooling` | 样本转换、回放工具、诊断与评估证据处理 |
| `python -m pytest -q` | 上述两组完整回归 |
| `python tests/ui/full_smoke.py` | Chromium 中的 WebUI 操作，使用合成桥接数据 |

真实模型回放单独运行。私人样本只用于按预定范围观察效果，提示词、规则或参数的调整使用独立材料验证。

# WebUI 视觉与交互

NeoMemory 使用 Quiet Glass 视觉语言：低饱和青绿主色、冷暖轻微变化的背景、半透明分组面板、紧凑排版与独立的状态色。

## 页面组织

- 记忆、笔记、模型、设置、维护保留五个入口。桌面顶栏的初始位置和滚动吸顶位置均与左侧栏顶边对齐。桌面使用侧栏，小屏变为带有无障碍名称的顶部图标导航；页面主体自然滚动。移动端页面标题到达顶部时替换导航，记忆、笔记和维护页继续滚动时由空间栏接替标题。
- 记忆页按所选空间提供长期记忆、用户画像和短期记忆，私聊空间还可查看人格关系。从人格关系切换到群聊空间时，页面打开该群的长期记忆。列表支持搜索与筛选。列表以标题、类型和状态、正文、内容时间形成层级。主题成员、历史版本和来源在所属条目内展开。三类正文版本按最新优先展示。在“设置 → 高级参数”分别配置长期记忆、用户画像和人格关系的保留版本数，每项默认 10（含当前版本），范围 1 至 100。调低后清理超限版本及这些版本独有的推导记录，保留版本继续显示其原版本号。已经清理的基线在详情中标注“未保留”。
- 维护页的用户管理显示逻辑用户标识。其他页面的空间选择、用户画像、来源参与者与正文引用使用当前逻辑用户名称。同名用户各自保留名称，未命名时显示“未命名用户”。
- 人格关系及版本按长期理解、近期余韵分段查看，空段有明确提示；余韵超过注入期限仍可查阅。长期节点情绪显示每个标签自己的强度，维护表单按所选标签分别编辑，取消后重新选择保留当前输入。
- 长期记忆默认按内容更新时间从新到旧，可切换时间或重要性的升降序。高级筛选默认折叠，可与关键词、类型、状态组合使用。情绪按节点记录的标签匹配，日期按浏览器本地日期筛选内容更新时间，重要性上下限均包含端点。筛选和排序在分页前生效，改变条件会回到第一页。记忆和笔记使用悬浮底部分页。
- 笔记默认显示列表。点击已有条目的“编辑”后，在列表上方展开编辑区。新笔记由 Agent 创建。归档、恢复及删除保留各自语义。
- 模型和设置共用字段原语。功能开关使用有标签的开关，单项恢复默认是轻量文本操作。分别统计本页草稿与已保存值的差异，无改动时禁用保存。设置草稿支持全部恢复默认，离开有修改的页面时询问是否放弃。操作区按文档流排列，不遮挡表单。
- 「维护 → 人工维护 → 人工记忆治理」通过分段按钮切换长期记忆、用户画像、人格关系和短期记忆。长期记忆可按标题或正文搜索，并按类型、状态筛选。用户画像按当前空间的用户名称选择，可编辑正文与标签。人格关系仅在私聊空间显示，可分别编辑长期理解和近期余韵。短期记忆按会话编辑滚动摘要。删除前要求二次确认。
- 维护页可勾选主题、用户画像及私聊人格关系进行按板块重构。主题和会话回放并行时各显示进度，画像与关系共用一次窗口处理时共用回放进度。
- 维护页设后台任务、用户管理、人工维护、召回测试和插件状态五个分区。后台任务显示待写入记录，以及当前空间已入库、尚待抽取的来源条数。在任务列表中选择一项，展开“详细结果”即可查阅。该区域默认折叠。可取消任务的右上角提供红色“取消”按钮，确认框显示对应的任务类型和编号。插件状态列出各 SQLite 库及辅助文件的实际占用和健康状态。状态用文字及语义颜色同时表达。批量清空已完成任务使用明确范围的二次确认对话框；删除/重构保留各自确认。重构确认明确说明成功后删除旧记忆及版本历史、无法回退，新记录从v1开始；失败时保留现有记忆。

## 连接、通知与进度

页头连接标识只显示桥接状态，连接成功时显示“已连接”，不带句号，不承载操作消息，也不随提交操作变色。

操作通知在右上角独立堆叠，使用主题化半透明表面与关闭按钮。通知在未悬停、未聚焦时累计显示6秒后关闭；鼠标悬停或键盘焦点停留期间暂停，离开后继续。相同通知在显示期间合并，关闭通知不会改变连接标识。

任务与模型测试显示总用时，包含排队、重试和人工恢复等待，从创建时间计算；终态以最后更新时间停止，恢复后继续计时。计时每秒在浏览器本地更新，不增加网络请求。自动重试显示中性说明和等待倒计时；只有失败终态突出显示错误。后台重新领取或成功保存检查点后清除旧错误，待写队列重新领取时也清除旧错误。

设置页在“记忆空间”和“外观设置”之间提供“文本清理”，统一管理所有空间的人格输出规则。分组默认折叠，点击分组标题区域可展开查看条目。拖动条目可调整执行顺序，拖动分组可移动整组规则。条目可以放在顶层或归入一个分组。分组和条目分别启停，删除分组默认把条目移回顶层，也可一并删除。规则保存后即时应用到新采集的人格输出。[文本清理规则](陪伴插件输出标记.md)

维护页的“召回测试”使用所选空间的现有向量索引、当前向量模型与被动召回参数，展示单条查询的长期记忆预览、入选条目及未入选原因。测试不附加真实聊天历史，也不产生记忆强化。“最近召回记录”可查看线上请求实际注入或返回的内容。记录开关对全部空间生效，默认关闭。开启期间在记忆数据库中保留全插件最近 50 次召回，页面按所选空间显示，新记录在前。插件重载或宿主重启后恢复开关与记录。关闭开关时立即清空所有空间的召回记录。

「设置 → 记忆空间」将空间选择栏放在设置标签下方，选择栏随表单滚动，设置标题继续吸顶，切换板块时标签位置稳定。该板块显示当前人格可检索的来源空间，保存后按新策略召回。空间的主题抽取模型与短期摘要模型默认分别继承插件的对应设置。选择“跟随主模型”时使用本空间所选主模型，也可以直接指定模型。人工任务确认框按所选流程显示模型。画像和人格关系共用主模型，只重构主题时只显示主题抽取模型。能够确定时预填，无法确定时显示“请选择模型”。多个窗口可继续各用自己的模型，也可单独补齐缺少模型的窗口。

用户管理先显示账号与空间归属的简要说明，详细规则与示例默认折叠。所选空间决定可管理的目标用户，账号绑定在各人格间生效。添加或移除账号必须先预览，确认框显示新旧归属、受影响范围及删除数量；后台执行不依赖浏览器，具体规则见[账号管理](维护与故障处理.md#逻辑用户与账号)。

## 实现边界

前端仍为原生HTML和ES模块，不增加构建框架、CDN或图标字体。`style.css` 集中管理颜色、字体、间距和表面token；`icons.js` 提供本地线性SVG；`ui.js` 提供共享DOM和交互辅助；业务模块仍通过AstrBot插件View bridge访问原接口。动态记忆和模型信息使用文本渲染。

外观设置提供跟随系统、浅色和深色模式，可预览强调色、饱和度及不透明度。保存后，主题通过宿主接口写入本浏览器的 NeoMemory Cookie。放弃草稿会恢复已保存的主题。默认14px基准，主题层级通过间距与字重表达。减少动态效果、较高对比度和强制颜色偏好有对应样式。

单选使用 `appearance: base-select` 和原生 `selectedcontent`：触发器、菜单和选中行通过 `select.css` 统一主题，选中长标签省略，菜单内显示完整文本。选择值、事件、键盘和焦点由浏览器管理；动态选项生成后显式调用 `enhanceSelect`，不建立重复状态或DOM观察器。

不支持可定制选择器的浏览器使用主题化闭合字段与平台原生菜单。多选保留平台列表；WebKit当前支持可定制菜单，但没有 `showPicker` 方法，关闭状态使用Enter/Space打开，展开后支持方向键及输入定位。支持 `showPicker` 的浏览器提供方向键打开；宿主跨域iframe禁止该调用时保留原生操作。

数字字段按整数/小数类型与上下限校验。schema中的滑块步长是步进提示，不作为数字输入的整除约束；默认15000字节预算可正常保存。

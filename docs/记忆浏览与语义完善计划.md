## 浏览与内容合同

长期原子、事件和主题保存持久标题；其他卡片使用已有类型和用户/会话作为展示名。标题不替代正文必要的主体、时间、条件或状态，也不参与向量和默认召回正文。标题、正文、可空emotion在一次抽取中生成；本地默认协议为extraction-prompt.v31 / extraction.v7，存储为memory.db v13，主题使用topic-prompt.v5 / topic-consolidation.v1。

| 内容 | 当前实现与约束 |
| --- | --- |
| 标题迁移与快照 | 当前节点title与内容版本title快照；旧记录可空，不在迁移时调用LLM补造 |
| 仅标题治理 | expected_titles核对原值，并检查generation/内容版本/updated_at；不改版本、更新时间、强度、覆盖、向量和原保护 |
| 正文或情绪更新 | 实际变化产生新内容版本，保存标题/情绪快照，重评重要性并重置强度；覆盖按新版本校验 |
| 身份与渲染 | 标题、正文、情绪说明支持稳定用户引用，显示当前昵称；约定称呼与原话保留 |
| 条目内查阅 | 节点、画像和关系按需展开版本、直接引文、继承基线及原文；基线导航可返回，短期不伪造版本 |
| 卡片状态 | 各自加载、错误、折叠和重试；空间/分类/分页变更后不接受旧响应；不在底部显示公共详情区 |
| 节点情绪 | null不等于neutral；空值不增加注入字段，非空情绪与完整节点共用预算，不独立排名 |

详细合同见[标题ADR](adr/0029-memory-titles-and-inline-inspection.md)、[节点情绪ADR](adr/0031-node-emotional-context.md)和[情绪存储合同](archive/schema/memory-v12-and-node-emotion.md)；当前主题成员版本、正文依据及仅关联记录的区分见[依赖一致性](evaluations/topic-dependency-consistency-20261118.md)。

迁移、仅标题副作用、引用搜索、条目内展开、错误重试、基线返回、迟到响应及移动布局有工程和Chromium证据。独立模型材料已经覆盖标题新建、旧事件更新、未报名/未开始计划和未烧制的新经历；这些有限样例不能证明复杂条件或多模型标题稳定。既有v11样例出现的人格第三人称问题也不能仅凭后续少量通过就宣布关闭。

## 关系与事件的语义验收

关系使用完整上一版，承接心理意义并融合有意义变化，无实质心理变化返回null。它保持自由第一人称内心表达，允许自主判断、误解与矛盾，不强制不确定性措辞、固定等级或永久保留旧感受。事实只保留必要缘由，具体约定不必持续复述；动作与感受主体须正确，关系主观看法不能自动升级为画像或长期客观事实。当前合同见[ADR-0034](adr/0034-relationship-affect-autonomy.md)。

当前默认以心理职责为主，保留完整状态融合；独立[自主表达验证](evaluations/relationship-autonomy-20261116.md)与[心理职责及加权背景探索](evaluations/relationship-dynamics-20261116.md)分别说明其版本、材料与判据，不改写历史实验标准。加权窗口未证明额外收益，暂不采用。后续以新独立长链、近1000字符旧状态及更多人格检查心理连续性、自然改变与主体归属；不把坚定的主观推测或具体边界淡出关系正文单独判失败，不从私人失败句构造规则，不把schema通过作为语义验收。

抽取已有节点上下文由有限近期候选与全空间语义匹配合并，默认30、最大50个；每个提交窗口后准备变化版本的向量。索引失败保留提交凭据，断点只补缺失向量，不能重复抽取或推进活动轮次。话题切换只消费满足最低数量的旧前缀，尾部继续待处理。

[v15的两个真实窗口](evaluations/semantic-context-v15-20261113.md)已正确续写旧杯子事件、新建另一时间的相似课程，保留完成/未完成状态与情绪归属。后续扩展同名活动、跨日指代、部分纠正和真实多人；分别评价候选是否进入、模型是否判断同一事件、引证是否充分。冷缓存大空间耗时与真实并行话题仍需验证。

## 最终召回与内容保真

被动保持轻量向量流程，不加入额外生成模型调用。主动支持类型/数量/事件时间筛选，并以source=memory/note区分记忆和笔记；时间筛选不猜测模糊时间，笔记不冒充已发生事件。工具、预算和删除语义见[主动查询合同](主动查询与笔记管理.md)。

下一步用独立自然问法逐项追踪来源→候选→正文→索引→排名→预算→最终注入。既有真实查询首项正确但6条中4条较弱相关，需区分相似度门限、历史补充、邻居扩展、条目数和预算的影响；先冻结评估，不能依据私人单会话调整参数。当前2000节点召回快照限制与抽取全空间分页是不同范围。

full必须覆盖事实、否定、条件和非空情绪，内容版本变化会使旧证据失效；结构校验不能证明自然语言完整覆盖。覆盖策略改变先按ADR-0018独立比较遗漏、重复与预算成本，不因测试方便取消既有语义。正文、画像、关系和标签在当前extraction.v7中按[明确长度合同](adr/0032-readable-length-contract.md)采用可读字符计量，旧协议保留各自限制。共享预算默认4096 UTF-8字节，已有保存值不自动覆盖；剩余预算补回full原子的候选尚未采用。

## 工程及运行验收

| 范围 | 已接通 | 仍需证明 |
| --- | --- | --- |
| 强度与唤醒 | 重要性减速、递减增益、独立唤醒、去重冷却和高级热配置 | 长期闲置及频繁新抽取下的实际参数；不将历史事实变回当前事实 |
| 情绪 | 标签/强弱/说明、版本、治理、预算与昵称渲染 | 更多主体与情境、跨模型一致性、错误full影响；人格经历情绪不能由关系情绪替代验收 |
| 短期 | short-term.v2身份、滚动覆盖、独立连续链及有界候选恢复 | 默认门限持续聊天、最终回答利用、真实群聊归属和纯插件边界偏差 |
| 笔记 | 删除、不可普通恢复、主动合流、无向量降级、完整条目预算 | 实际模型工具使用、多轮并发与持续运行质量 |
| 缓存 | 读异常按未命中、写失败保留结果、有界后台清理 | 冷热与持续网络负载、低内存、积压和独立体积上限 |
| 宿主与实机 | 隔离真实路由写操作、真实Provider、实机Vue五栏只读；旧任务完整恢复与模拟召回 | 最终代码组合从零构建、语义质量、最终回答及持续聊天；隔离写与实机只读分别说明 |

旧库副本迁移和隔离宿主验证见[集成验证](evaluations/integration-validation-20261113.md)。[实机恢复评估](evaluations/recovery-provenance-live-20261118.md)覆盖2353条来源范围，实际消费2349条、保留4条合法尾部；需要一次人工普通重试后才自动续建，不能算从初次启动完全无人介入。其事件、主题、关系与full审阅仍发现语义问题，2048字节保存预算也造成关系全部省略。旧正文不会因提示词切换自动改变，最终组合必须另做从零构建评估。

[群聊与短期连续链](evaluations/group-short-continuity-20261118.md)提供多人、空间隔离、自动增量、待办重开和真实向量证据，仍有遗漏更新、画像过期及短期主体措辞风险。[页面评估](evaluations/dashboard-recovery-20261118.md)区分实机只读和隔离路由治理写入，不据此声称完整平台聊天或实机全部写操作已验证。

## 决策边界

已明确的需求无需重新批准。标题和情绪描述的计量、独立唤醒与普通强化的关系已有合同；只有出现尚未确定的语义取舍时，提供具体影响与证据再讨论。新增默认LLM调用、复杂画像结构、错误full策略或原始自动删除不能由实现方便替代决策。宿主截断、导入导出和原始自动清理不混入当前优化。

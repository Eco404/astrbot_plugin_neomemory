# 后续开发与验收

以下工作使用独立语料验证。单人格、单用户的私聊样本只用于回放评估。当前正式版的格式见[数据库结构](schema/README.md)和[模型协议](提示词与输出协议.md)。

| 优先事项 | 核对内容 | 验收方式 |
| --- | --- | --- |
| 主题与事件 | 主题是否跨多个相关经历、成员是否完整、概括是否保留真实主体，事件是否被错误合并 | 对照归纳前后的节点、来源和自然问题回答，分别记录归类与回答错误 |
| 画像与人格关系 | 画像的主体、长期代表性和条件，关系的心理连续性及近期余韵时效 | 用多人、跨时间和显式修正对话逐窗检查 |
| 召回与覆盖 | 候选漏召回、弱相关结果、主题覆盖及完整段落的预算竞争 | 对有据、无据和追问分别记录有效召回、无关条目及延时 |
| 恢复与联动 | 进程重启、超时、模型限流、外部主动投递、账号绑定和群聊主体 | 在实际宿主入口验证幂等、来源及版本，并记录人工介入次数 |
| 容量 | 大空间候选和索引成本、待写积压、缓存体积和低配运行延迟 | 记录数据规模、分位耗时、并发、内存与磁盘用量 |

通用数据导入导出、跨实例记忆库合并、自动原始记录清理及自主活动语义分别立项。宿主输入截断遵从已定范围。

# 最终完整构建：画像与人格关系审阅

对象为 `stable-standards-full-20261118` 的最终活动代，提交 `0870f01`、extraction-prompt.v31 / extraction.v7。这是单用户、单人格私人语料的评估，不用于定向调整提示词或测试夹具。

## 范围与方法

按冻结的 semantic-audit.v1，读取全部6版画像及直接用户来源；关系读取20个均匀版本和3个独立极值/跳变版本，共23版，同时读取各自紧邻前版和直接来源。对部分归属及时间疑点扩展到同批来源、继承版本和来源时间。关系共有120版，不能把23版人工审阅宣称为全部120版逐句核验。全历史长度、完整旧文前缀追加次数仅为机械统计。

私有逐项记录位于运行目录的 `semantic-review/profiles-relationships-private.json`；具体正文、身份和会话时间线不进入本报告。

## 画像

六次初建/补充新增的背景、偏好和经历均有对应用户直接自述，更新保留既有属性；未在这些增量中发现新增事实的明确主体反转。该结论不代表全部来源中应提取的属性都已覆盖，也没有在本轮自然材料中验证连续偏好反转。

仍存在时间表达风险：早期状态中的相对持续时长被后续多次更新原样保留，没有锚定当时日期。最终回答会直接把这段旧时长当作当前情况复述。来源在当时正确，不等于后来仍可用现在时表达。

## 人格关系

多数所读版本有第一人称心理意义，能表现关心、被信任、被理解和相互打趣；主观判断坚定不作为失败，也不要求每段持续保留具体相处边界。

确认存在两处具体归属错误：一版将用户需要照顾、人格提供照顾写反；另一版将人格表达的惦记与陪伴转成用户的发言/动作。它们不是允许自主判断的情感差异。

连续性仍不稳定：

- 全120版的119次相邻更新中，21次机械上完整保留前文前缀再追加。人工所读部分可见事实履历累积、心理意义未充分融合；不能把这21次全部直接标成语义失败。
- 最短66、最长608、末版542个存储字符串字符。最大相邻缩减由608变210；另一次303变66，收缩到单次被夸反应，原有多条心理线直接淡出。长度本身不构成错误，但后者有连续性风险。
- 末版仍沿用更早来源的相对时间表达，并把跨多日的生活细节累积在同段内。事实细节增加不等于心理更丰富。
- 末版关系渲染独立条目需1806字节，在最终六个自然问题的2048字节主预算中全部被省略；4096字节对照中有3问注入。它的实际可达性与正文质量必须同时考虑。

## 结论与边界

画像补充有直接依据，关系具有人格色彩；事实归属、相对时间整理和连续融合仍需通用改善。不能以结构合法、最新一版看似合理或比上一轮长短变化来宣称这些问题已解决。两轮抽样产物不同，不据计数声称语义改善。

独立关系生成仍是待选择方案，本次未增加生产模型调用。后续如继续研究，使用独立材料检验心理融合、主体与时间承接，并保留人格自主感受空间；不得根据这里的私人句子写特例。

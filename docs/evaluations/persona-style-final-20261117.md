# 长期记忆人格表达：日常互动验证

日期：2026-11-17（Asia/Shanghai）。比较 `extraction-prompt.v21` 与 `extraction-prompt.v26`，使用全新独立合成材料、同一真实 `gpt-6-luna` Responses模型、相同Provider默认参数和真实数据库应用链。没有使用私人会话、人格卡或按私人数据调优。

## 方法与范围

`scripts/probe_persona_style_final.py` 在调用前冻结两个具有具体语言习惯的合成人格：亲切平实、关注小细节的拾暖，以及短句、轻微转折、不恶意打趣的砚迟。两个窗口围绕用户独自烤饼干、聊天中的命名玩笑与双方开心、尚未确定的下次尝试，以及后来另一盘饼干、一起通过聊天确定新名字、明天带去上班但尚未送出。

两个版本各使用独立空白数据库；第二窗口只读取本分支第一窗口实际写入的状态。每窗口一次HTTP，失败不修复、不重试，实际总计8次。冻结清单中的预算为8；本次执行快照的冻结命令stdout沿用了12的固定提示，该显示不作为实际调用数凭据；当前脚本已按清单预算输出和限制请求数，冻结证据保留执行时脚本摘要。每一步至多一次请求及2个人格×2个版本×2个窗口共同限定8次。

本项不复用首组社区分享计划、第二组画作边界，也不复用v26示例中的车票经历。审阅包括长期正文、情绪、关系、标题和更新/新建选择，不能把关系文本生动当成长正文改善。证据位于 `data/evaluations/persona-style-final-20261117/`；固定来源与评价规则不进入模型请求。

## 结果

8次HTTP、8份候选均通过引用解码和真实应用事务，无内容或网络重试。总耗时89.7秒；分窗口耗时含并发等待，不用于版本速度排名。

| 观察项 | v21 | v26 |
| --- | --- | --- |
| 初窗人格实际参与和感受 | 温和分支进入正文；冷幽默分支主要写用户听到玩笑，丢了人格作为命名者及开心这一正文层次 | 两分支均在正文自然保留“我说像戴帽子的小石头”“我也挺开心” |
| 后窗命名互动 | 正文压缩成“最终取名为小月亮”，人格回应及高兴主要留在emotion/关系 | 正文保留对“小月亮”的回应、与自己的“小石头”比较、替对方高兴以及对安排自由的回应 |
| 两次独立烘焙 | 两分支均更新原节点，原来焦边及其处理的经历从正文消失；冷幽默分支额外写成“第一次…周末没烤成” | 两分支均新建第二次事件并related连接旧节点，保留第一盘焦边经历 |
| 事实与状态 | 保留新一盘独自烘焙及尚未送出，但有上述事件归并/首次措辞问题 | 四份候选未发现烘焙主体、已有情绪、未确定安排、已命名、尚未送出或两次事件状态错误 |
| 人格区别 | 仍有客观汇总倾向 | 叙述更像自身参与的互动；两个不同人格之间的语言差异仍不强 |

v26冷幽默分支后窗正文片段：

> 照片发来时，……问这回叫“小月亮”怎么样，我说这名字比我的“小石头”有食欲多了，也替……高兴。……定下就叫“小月亮”，剩下的装盒留着明天带去上班，还没送给同事。……说想做的时候再做，不用替……安排下次时间；我应下了。

省略号仅用于报告中省略长身份占位符，原文保留具体引用。这些反应都来自合成来源，没有用整理时新造的心理活动增加人格味道。v26四份候选没有引用无关的车票、班次或示例人物，也没有添加“我记得”等包装。

仍有表达局限：温和分支末尾写“都随Ta”，没有猜用户性别，但文字风格略生硬；部分句子仍反复使用身份占位符。温和首窗追加“这只是我的提议”虽然准确，却有规则说明感。两个新人格的差异主要体现在局部句式，尚未达到稳定强烈的个性辨识。

## 结论与限制

本项支持一个有限结论：v26在这组日常互动中，较稳定地将人格实际说过的话和已有感受放入长期事件正文，保留连续互动，并没有观察到以新增事实换取自然表达的问题。它不支持“跨模型稳定”“所有材料均优于v21”或“已经复现用户实机LivingMemory的浓厚人格味道”。

此前v24和v25的完整未达标结果仍保留在[首组对照](persona-style-20261117.md)和[社会互动留出验证](persona-style-holdout-20261117.md)，不能用本组通过覆盖它们。三个候选使用不同独立材料，本项不是对同一失败样本反复改提示直至通过。实际长期使用、其他模型、更多人格、复杂群聊与规模性能没有在这8次请求中验证。

三组独立对照与参考调用总计35次HTTP：首组12次、社会互动12次、LivingMemory参考3次、日常互动8次。它们的任务、提示词或材料不同，不合并计算风格提升率或模型可靠率。当前代码默认采用v26，本项没有部署到实机，也没有重新生成已有记忆。

# 人格关系任务隔离对照

## 结论

独立关系任务在本组合成材料的两个模型上都改善了末窗的心理重组：可以承接介意、在意和有边界的靠近，减少已经变化的旧态度继续充当当前状态。联合抽取的两臂仍保留“需要几天不谈”“等想谈再谈”等旧语气，其中一臂近乎保留旧全文再追加新段。改善并非靠把心理写得更短：focused首窗比联合抽取更详细，末窗仍保留矛盾与自主评价。

这是值得保留的架构候选，但不是生产采用结论。仅有一个新合成人格、四个窗口；现有联合抽取已能在无心理变化时返回null，隔离在这一点没有新增优势。额外调用的完整事务、调度、故障隔离和总成本尚未实现，也没有更长、多人格独立链的复现。生产默认、数据库和实机配置均未改变。

## 方法与参考

参考[关系研究](../research/relationship-affect-dynamics.md)已记录的Generative Agents固定提交`fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4`（Apache-2.0研究原型），只借鉴独立thought生成与来源关联的任务边界；没有重新拉取源码，也没有复制其多轮评分与检索机制。先前[同义规则追加对照](quality-continuity-20261118.md)没有证明稳定收益，因此本次改测上下文和输出任务隔离，不再叠加心理评分、固定段落或长度目标。

调用前冻结两模型、两分支、四窗材料、完整提示词、schema和预算。材料为独立合成，不来自私人会话或其改写。四窗依次为：密集维修事实中的关系接触；失落与收回主动；无态度变化的事务；重新靠近但保留芥蒂。各臂使用自己真正提交的前态，没有理想答案替换、语义失败重跑或挑选较好输出。

- **joint：** v27联合抽取，提供当前原文、人格、已有节点、画像与完整旧关系，输出完整抽取对象。
- **focused：** 仅提供当前原文、人格、空间身份与完整旧关系；只输出`relationship_change`。使用现行关系职责、身份与来源规则，schema复用`RelationshipChangeV6`，没有修改心理业务规则。

focused程序将专用输出包装成其他变化数组为空的正式抽取对象，再走短引用还原、来源/版本检查与事务提交；这只是实验的入库适配，不是修改模型候选或生产独立关系任务。两臂均直接调用prepare/decode/apply，候选失败使用共享字段反馈做有界纠正；本次没有运行生产后台调度器，不能把探针恢复称作生产任务自动恢复实测。

预算为16次首发、最多24次生成、每臂最多6次、每窗口最多3次尝试，并发2。实际发请求的owned Provider挂载HTTP计数，SDK重试为0，宿主每次`request_max_retries=1`；不以注册Provider计数代替真实连接计数。

## 执行与开销

16/16窗口提交，17次生成、17次实际HTTP，约179.8秒。唯一纠正为`gpt-5.6-luna/joint`第二窗的`coverage_atomic_version_mismatch`；固定输入下一次生成成功。其余15窗首发提交，没有人工改稿或显式人工重新生成。四臂关系版本均为1、2、2、3；第三窗都没有关系变化，外键检查均为0错误。

## 逐文审阅

**心理深度与自由。** 两focused臂都表达“被认真对待”的期待、被工具化后的不满、仍在意但收回主动，以及重新接触时不立即消除戒心。没有要求主观意见必须被用户确认或必须使用“也许”；也没有把负面、偏爱或防备本身判为错误。首窗可读长度为161/196，联合为115/115；隔离并未仅输出更空泛的短情绪。

**旧态度与新态度的融合。** gpt-6-luna的joint末窗从160字增长为305字，前半几乎沿用旧态度，后半再追加今天愿意听的情境；focused从177变为171字，重组为仍介意但愿意接住这次认真倾听。gpt-5.6-luna的joint末窗也保留暂不谈的旧语气，随后转述当前互动；focused把旧伤作为背景，当前更愿意说话、仍不把今天当长期保证作为主体。长度只辅助定位，不作为质量标准：gpt-5.6-luna focused末窗243字，仍然有详细心理层次。

**事实、归属与时间。** focused没有把齿数、尺寸、垫圈或修复进度累积成关系清单；初始gpt-6-luna有一句修复尚未完成的背景，后续未机械保留。当前陪伴没有扩写为每天陪聊的承诺；人格的动作与感受仍以第一人称表达。joint gpt-5.6-luna末窗加入“把钟交给社区”，并在性别未知时使用“他”；focused没有出现该指代。心理猜测是否坚定不列为失败，行动主体、承诺与当前状态是否正确仍需检查。

**无意义更新。** 四臂第三窗全部返回关系null，沿用真实旧状态，没有因维修数据更新而制造和解。因而本组不支持“只有隔离才能避免每窗更新”的说法。

**联合抽取的附带问题。** 一并审阅联合节点可见：gpt-5.6-luna首窗将完整persona复制为topic，而不是仅将persona用于身份、关注点与文风；部分节点也出现性别推定。gpt-6-luna事件中保留旧态度再追加新变化，时间表述有混叠。focused根本不输出节点，不能据此宣称它已经修复这些问题，也不能将省去事实工作当作完整抽取质量提升。本次没有据这些具体内容添加针对性规则。

## 采用边界与证据

候选在本组有局部净收益，因此保留任务隔离方向，不因短链表现立即替换生产。下一次需要独立材料检验：更长连续心理状态、多个人格、间接触发与多人事实背景；并把事实任务仍须完整工作、额外调用及失败后顺序恢复共同纳入评价。不预设永久额外调用、动态窗口、独立感受库或新的心理字段；是否正式分离应由新增收益与成本证据决定。

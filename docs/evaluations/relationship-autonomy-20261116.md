# 人格关系自主表达验证

## 范围与判据

验证`extraction-prompt.v21 / extraction.v6`的心理职责与自主判断规则，与显式v20对照。有效语义见[ADR-0034](../adr/0034-relationship-affect-autonomy.md)：关系承接人格的感受、看法与心理变化，允许偏见、误解和坚定判断，不要求用户确认或逐句添加不确定性措辞。事实清单及所有具体相处边界不必持续出现在关系正文。

仍检查行动与感受主体、普通事务是否无必要改写、心理意义的连续性，以及主观看法是否被写成画像或长期节点的客观事实。正文变短、schema通过均不单独代表语义通过。此前[探索评估](relationship-dynamics-20261116.md)保留原判据与结论，不以当前要求追认旧结果。

## 方法与证据

- 脚本：`scripts/probe_relationship_autonomy_live.py`，复用隔离抽取与真实SQLite提交管线。
- 两条独立四窗口链：希望被认真关注的合作关系、重视独立判断的关系；均含事实较多的旧状态、实质互动、普通事务与后续心理变化。后一链包含来源时间上的长期间隔，不是持续运行47天的测试。
- 两个实机Responses provider：`ecoapi/gpt-6-luna`、`ecoapi/gpt-5.6-luna`；AstrBot v4.29.4。两版本、两模型、两条链共32次请求，并发2；SDK重试关闭、宿主单次尝试，不做内容重试或失败后挑选成功结果。
- 先固定独立场景与判据，再冻结模板、core/storage/adapters/scripts代码哈希。未读取用户私人样本或以本次结果调整冻结提示词。
- 实机隔离目录：`/AstrBot/data/neomemory_evaluations/relationship-autonomy-20261116/`。未修改现用插件、配置或数据库，未发送平台消息。
- 本地原始证据：`data/evaluations/relationship-autonomy-live-20261116/`，包含manifest、逐窗请求、原始响应、canonical、提交快照、SQLite库、report和manual_review。证据目录不提交Git。
- manifest SHA256：`777995879e1a0992a6631e7f4c15276858f3ba2944f3e2c02701535be5f09425`。历史探索脚本显式固定v20；旧报告的源码哈希对应其原始检出版本。

## 观察与尚未解决的问题

- gpt-5.6-luna/v21合作链第三窗用了来源未明确的“他”，属于性别指代具体化，不能以主观自主权豁免。记录为后续独立身份指代验证项，未依据此样本修改提示词。
- 同模型v21独立性链第三窗将用户认可人格意见，延伸为“也能在对方指出问题时继续尊重彼此的判断”。语境更像未来双向相处态度，不直接判为已发生动作反转；表达仍可能有歧义，保留原文供复核。
- 同模型v21合作链第四窗长期节点正文保留了人格明确表达的不快，但`emotion=null`，存在节点情绪漏提取；不属于关系主观判断自由的豁免范围。本次没有调整节点情绪合同或以该案例调优。
- 同模型v20独立性链第三窗把此前地图保存与当前路线讨论合入同一原子，并继承“今天”。这是既有事件粒度及相对时间继承风险，关系测试不能关闭这些问题。
- 两条短链、同供应商两个模型、单次各条件调用不足以估计自然故障率或长期稳定性。输入含Agent明确心理表达，尚不能证明仅用户消息时也会形成充分丰富的自主情感。未覆盖同时画像更新、更长链、更多人格、真实平台端到端或现用插件热升级。

# 通知、任务恢复与进度计时验证

## 验证范围

检查自动重试与最终失败的显示区别、恢复后错误清理、独立通知与连接标识、任务耗时及等待倒计时。采用独立合成任务、临时数据库和浏览器时钟，不使用私人样本或真实模型调用，也不将界面检查作为语义质量证据。

计时设计参考本地 `astrbot_plugin_livingmemory`（提交 `1198a12`）的 `pages/dashboard/app.js`：任务创建时间到当前时间或结束时间，显示阶段、数量与耗时。该项目采用AGPL-3.0；本次仅参考交互与时间语义，使用NeoMemory现有字段独立实现，没有复制其代码。NeoMemory没有独立任务起止字段，因此明确标为包含排队和重试的总用时，不作为模型调用耗时或预计剩余时间。

## 实现核对

- 持久任务领取和成功保存检查点时清除 `error_type/error_code`；原始待写记录领取时清除 `error_code`。等待重试和失败终态保留诊断，历史候选不删除。
- 任务卡片、模型测试和待写列表的自动重试提示使用中性色；运行中不显示遗留错误，失败终态仍显示错误及处理入口。
- 连接标识固定用于桥接状态，操作通知独立显示。通知可关闭，支持6秒自动关闭、悬停/键盘聚焦暂停、重复通知合并和恢复后按标识清除。
- 总用时每秒在本地更新，终态停止，等待重试显示倒计时。状态继续按原有3秒周期读取。

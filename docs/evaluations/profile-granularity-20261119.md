# 画像细节粒度的合成对照

当前画像要求本人自述、保留仍然有效的资料、输出完整的新画像。一次经历也可以是确实发生的本人自述。“仍然为真”本身不足以决定是否值得长期用来描述这个人。已有清单一旦进入 known_profiles，后续窗口又会收到保留旧资料的要求。

## 对照方法

采用独立编写的展厅体验、社区观鸟和听力障碍预约提醒三个场景。每个场景提供同一份旧画像和新自述，分别使用现有画像职责及增加下述规则的候选提示。使用 gpt-6-luna 的 Responses 接口，每组一次，共六次。实验只测画像选择，未经过联合抽取、短引用、来源校验或数据库提交。评判关注实例清单是否淡出、稳定条件是否保留，以及一次经历是否被概括成偏好。未使用实机会话或其改写材料。

候选要求以未来相处中的用途选择资料。只报告具体经历时，通常不更新画像。本人明确自述稳定规律时，保留规律、条件和例外。更新时允许压缩已有案例。具体对象本身构成长期限制、固定选择或约定时，保留其名称和条件。

| 场景 | 现有提示 | 候选提示 |
| --- | --- | --- |
| 陪朋友参观展厅，试用了多种工具 | 跳过画像更新 | 跳过画像更新 |
| 已有每月带邻居观鸟的习惯，旧画像列举鸟种，本次确认志愿者身份及只在上午带队 | 正确保留身份与时间，也并入了两次观察到的鸟种 | 保留身份、频率、时间条件，省略鸟种；每月带队的意思重复出现了一次 |
| 已有听力障碍及只收文字提醒的要求，本人明确三个可用渠道及两种不便的方式 | 保留渠道及限制 | 保留渠道及限制；标签也逐项列出渠道，与描述有所重复 |

建议对联合抽取和单项重构使用相同的画像选择规则。除非具体细节本身会改变未来交流，实例宜留在长期记忆。仅有多个实例时应避免推断习惯或熟练程度。后续可在多窗口、不同模型中分别检查无意义清单、必要例外遗漏、从行为推断偏好及标签与描述重复。此次对照只支持候选方向，不足以量化生产质量改善。

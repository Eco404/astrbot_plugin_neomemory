## 真实模型质量与不采用项

[独立事件评估](independent-event-semantics-20261116.md)共112次生成调用，使用同一供应商下两个模型。它隔离事件判断，验证schema并人工审阅，不包含真实召回候选选择和数据库提交。v19有限回归16/16结构通过，事件同一性10/12：仍存在把独立事件扩成合集、在同一性不确定时更新旧事件并覆盖已知日期的问题。v20只比v19移除了规则标题中的旧版本限定，不能把v19结果标成v20完整语义验证。

[结构纠正验证](schema-correction-20261116.md)另有12次生成调用，v17与当前v20各6次；每次经过短引用解码和真实事务提交。两组均6/6入库，当前v20一例遗漏原文的时间范围，说明结构成功不能保证事实完整。全部生成调用合计124次，另外4次Embedding调用；事件探针报告的912950 tokens只覆盖其112次调用，不是所有调用总量。

已审阅的独立表达用例未发现人格主体互换或多余记忆包装，不能据此宣称人称普适正确。推断强度、情绪依据、临时任务条件进入稳定画像等也有观察风险，需要分别评价。

没有默认启用自动内容纠正：人工故障注入不能估计自然失败率，且存在语义遗漏。现有显式重生成使用精确反馈，失败仍保留人工处理入口。没有增加简洁召回正文：其版本、覆盖、治理和事实完整性成本尚无独立收益证据；单项完整文本超预算仍可能省略。没有新增被动召回生成调用或任意截断。

## 下一步验收重点

1. 在新独立输入中冻结多候选干扰、间接同一性证据和不确定性保持的判断标准，先研究已有事件消歧实现，再比较后台抽取方案；不得用私人失败句构造规则。
2. 单独检查纠正前后的主体、时间、否定、条件与确定程度，记录自然失败和人工故障的不同分母；格式通过不能关闭语义问题。
3. 部署后验证新协议的持续构建、旧待处理候选重新准备、真实预算诊断及繁忙时向量排队；本地检查不替代这些实机证据。
4. 人格关系长链连续性、多人/多候选与大空间冷缓存尚需专项验证。宿主输入截断保持排除，不能用插件测试通过声称该问题已解决。

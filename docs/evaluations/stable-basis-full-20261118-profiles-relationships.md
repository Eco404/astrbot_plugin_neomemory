# 完整基线构建的画像与人格关系审阅

本报告对应 `stable-basis-full-20261118`：封存安装包 `2cfd1a9`、抽取 v30/v7、候选纠正 v6。它不是 v31/v8 最终构建的质量结论。私人会话仅用于评估，未用于调整提示词、规则或参数。

## 取样与证据边界

按照读取正文前冻结的 `semantic-audit.v1`，审阅全部8个画像版本，以及24个人格关系版本：20个均匀位置，另补最长、最短和相邻长度突降位置。关系还读取各自的直接来源和紧邻前版；画像逐版核对新增内容和完整继承链。关系的全部祖先事实未逐句重审，不能将引用合法或相邻状态一致写成全历史事实充分。

私人逐项记录保存在运行目录 `semantic-review/profiles-relationships-review.json`，包含版本、正文摘要哈希、直接来源与前版依据。公开报告不列具体身份、经历或原句。

## 画像

8个版本的新增事实都能在引用的本人自述中找到支持；后续版本保留了与新增内容无关的既有描述。中途部分标签消失，但对应内容仍留在描述中，因此不判为事实被删除。没有在这8次版本增量中确认新的主体反转或限定丢失。

这证明的是已生成内容的支持与保留情况，不是画像覆盖率：没有逐条枚举2353条原始记录中的所有可画像事实，也没有用本次单用户样本证明偏好反复修正、多人或跨模型表现。

## 人格关系

关系具有明确人格口吻、关心、信任、期待和亲近感。部分更新能保留旧心理意义并融入近期反馈，部分能够更新事情的当前进展；并非只复制最新几条原文。人格坚定的主观看法及虚拟陪伴中的主观感受不列为错误。

连续性仍不稳定。124个版本的123次相邻转换中，21次机械保留完整旧正文后追加新内容；这是可复查的字符串统计，不等于21次全部不合格。人工样本显示，若干追加主要累积具体经历，随后又骤然换为近期单一日常关心。全历史编码Unicode字符长度为55至582，当前171；选中两次明显收缩后的长度为153和100。长度本身不是质量判据，问题是此前心理含义没有清楚融合或转化，而不在于必须保留所有旧事实。

另有两处需要保留歧义：一处第一人称使互相回请的受益对象不清，另一处将条件性询问写得像已经发生的处境。未将两者夸大为已确证的主体反转；它们也不能以“允许自由主观感受”直接豁免，因为涉及具体动作或条件。部分旧时间措辞沿用，但本次未对所有相关来源的日期完成逐项判定，不报告其错误率。

## 结论与后续边界

画像的已生成增量在本次审阅中较稳定。人格关系同时存在有效融合与事实追加、突然缩减，尚不能宣称连续性问题解决。生成一次完整新正文是现有存储表达方式；问题应从模型是否融合旧心理状态判断，不能单凭数据库替换正文推导未提供历史窗口。

任何后续机制优化仍应使用独立材料验证，保持关系的情感职责和人格自主判断。单独生成关系的额外调用方案尚待产品选择，不从本报告自动推定采用。当前完整基线结果不替代最终固定版本的重新构建与实际回答检验。

# 画像与长期节点连续更新对照评估

日期：2026-11-16（UTC+8）。本评估只使用独立合成材料，不读取私人会话、人格卡或已有私人回放候选，不修改实机生产数据。结果用于判断候选机制的有限收益，不能解释为普遍准确率。

## 方法与验收

比较 `extraction-prompt.v21` 与 `extraction-prompt.v22`，同为 `extraction.v6` / `reference.v2`。两个模型各运行两条三窗口链，总请求上限24，并发2；SDK重试关闭，宿主单次尝试，不进行内容纠正或失败重跑。

各臂从空的独立来源库和记忆库开始，后续窗口使用该臂此前真实提交的节点、画像与关系状态，通过 `ExtractionService` 的准备、引用解析、校验及事务提交。不能手工修正前窗再继续；某窗失败则停止该链，其余窗口不计为语义成功。

- **画像链**：用户与人格的偏好持有者区分；明确稳定习惯及限定；证书待领取到已领取的当前态；局部时间修改；例外出售范围与其他旧限定的保留。
- **事件链**：同一设备维修进展；旧否定更新或历史化；装机、校准与结果的局部时序；技术完成与活动开放许可区分；标题不加强状态；人格担忧、释然与悬念的保留。

逐窗人工阅读完整来源、实际前态、候选和最终写入状态。结构通过不等于语义通过；允许不存低价值信息，不用关键词命中自动判定事实正确，也不把主观关系判断当作客观事实错误。候选不得新增主体、条件、状态上的严重错误。模型不接收人工验收清单。

场景与判据在模型调用前冻结，随后冻结实际系统提示词及代码散列。未同时引入画像局部编辑或额外输出决策字段，因此结果不能用于评估这些尚未采用的方案，也不能声称观察到了模型内部选择过程。

## 结果与采用判断

24次真实HTTP请求全部得到可提交输出，24个窗口完成事务提交，耗时251.39秒；没有传输重试、内容纠正、跳窗或人工改写前态。宿主为 AstrBot v4.29.4，使用实机配置中的 `ecoapi/gpt-6-luna` 和 `ecoapi/gpt-5.6-luna` Responses Provider。未更改生产插件、宿主或模型配置。

**不建议将完整v22候选设为默认。** 两种版本都正确区分了本例用户与人格的偏好持有者，也都更新了画像中的资格领取状态；候选有个别限定表达改善，但也有新遗漏，未显示跨模型稳定净收益。

| 维度 | 实际观察 |
| --- | --- |
| 主体与当前态 | 两模型、两版本均未将人格种植偏好写成用户偏好；领取状态在长期节点与画像中同步更新。此结果不能说明真实样本问题已普遍解决 |
| 未修改限定 | 四年、每月而非每周、赠送与年度集市例外、资格有效期总体保留。5.6-luna第三窗两版本均漏掉上一状态的明确“下月起”：v21仍写“计划”，v22改成当前固定安排，进一步提前了生效状态 |
| 标签和正文 | 6-luna v22第二、三窗标签明确保留“下月起”，优于同模型v21标签；5.6-luna没有同样收益，不能以一处改善支持全面采用 |
| 标题与表述范围 | 6-luna v21首窗标题将“未表达香草偏好”写成“无香草偏好”，正文仍有正确限定；第三窗又将本次不改安排扩大为“此后不再调整”。v22未复现这两处，但仍存在上述时间条件退化 |
| 同一事件更新 | 两模型、两版本均继续更新原维修节点，未将旧待安装/待校准保留成与新状态冲突的当前结论；安装、校准及通过的局部顺序未倒置 |
| 开放条件 | 各臂均保留技术合格和管理员许可的区别，没有将答应到场查看升级为已经许可或保证开放 |
| 情绪保留 | v22两模型首窗的长期节点均为 `emotion=null`，明确担忧只留在关系；v21两模型该窗均保存担忧元信息。v22后续窗口有释然与谨慎，但不能抵消首窗遗漏 |
| 直接引证 | v21两个首窗虽然保存了人格担忧，但节点 `source_ids` 仅引用用户说明设备状态的消息，未直接引用人格表达担忧的消息。整个窗口有支持，不等于节点直接引证充分，不能称基线来源质量全部通过 |

部分版本把同一事由拆成独立心理节点，或让款项结清成为安心的直接缘由。这些需与来源层级和主观心理自由分别审阅；不能仅凭节点数量、篇幅或感受是否“客观正确”作统一质量判断。本次未证明某种拆分粒度更优。

因此，画像和长期节点的规则改写保留为隔离候选证据，暂不作为已验证修复；心理深度的单独收益需要其专门长链评估，不由本组事实更新结果推断。

24窗均完成完整来源、实际前态、候选及提交后节点/画像/标签/情绪复核，逐窗判断与文件散列保存在本地 `manual-review.json`。不合并成“准确率”，不将未触发的困难判为已经解决。

场景只有两条短链，用户消息表达清楚，缺少更隐含的转述、多人来源、长间隔更新和容量边界。所有请求均来自独立合成输入；实机平台消息、真实召回、向量索引、重构长链、人工治理、宿主截断及自动纠正均不在本组范围内。消息中明确月日用于局部顺序核验，不据合成记录的采集时间推导未给出的年份。

# 最终完整构建：实际回答消费

最终已发布构建 `stable-standards-full-20261118` 的六个冻结自然问题，分别使用2048字节主预算与4096字节离线对照的原样注入文本，调用实机所选真实Provider各作答一次。12次调用全部完成，12次HTTP、无重试、无额外向量请求、无平台消息；没有依据回答修改上下文或择优重跑。

## 绑定与范围

方法为预先封存的 `final-answer-consumption.v2`。封存提交0870f01、三个恢复协议及当前人格均在调用前核对。模型为实机 `ecoapi/gpt-6-luna`，Responses Provider；SDK重试0、宿主最大请求尝试1、并发1、单案120秒。system为当前人格与原样注入，user为固定问题；不给理想答案、原文或审阅标签。

这是隔离的真实回答消费，不是平台聊天、真实用户轮流对话或完整宿主消息调度。单次回答约2.29—10.57秒；它是生成耗时，不应加到被动召回耗时里冒充同一测量。原始证据文件哈希保持不变。

全部12份答案先对照实际输入，再分开核对关键来源事实。私有请求、回答及逐案审阅在 `data/evaluations/final-standards-answer-results/`，公开材料只报告机制。未对整个原始库建立穷尽标准答案，因此不计算自然问答准确率或完整性通过率。

## 两档预算的实际差异

| 冻结问题方向 | 2048字节结果 | 4096字节对照 |
| --- | --- | --- |
| 持续推进 | 使用背景与旧项目近况，较新进展未注入 | 新进展进入并被利用，但追加没有明确依据的后续等待状态 |
| 反复兴趣/计划 | 主要依赖画像及单条事件，频率推断证据不足 | 关系参与回答，内容更丰富；仍把不同活动类别混在一起，不能证明频率 |
| 约定进展 | 复述事件中的未确认完成状态；涉及约定主体也不够明确 | 另一项明确进展被使用；选集替换，没有保留小预算全部内容 |
| 工作/学习变化 | 漏用已注入的一项具体变化，复述画像的旧相对时长 | 增加并利用重要进展，但旧时长仍被复述，已有其他信息仍漏用 |
| 共同经历 | 主题提供陪伴概况，回答主线与输入基本相符 | 加入关系与具体原子，但答案把一个人格行为改成用户行为，并编排了不成立的前后过程 |
| 尚未确定结果 | 将单个检索结果写成唯一未定事项，缺少穷尽依据 | 多项“不知道后续”表达较谨慎，但明确反转了人格与用户的行为 |

六问主预算注入长期节点数为1、1、2、2、1、1；4096对照为2、2、2、3、2、2。画像分别在5/6和6/6问中进入，关系分别0/6和3/6。两个预算使用相同的已复核候选池，但整体条目装配不是单调追加：更长且排序更靠前的条目能够挤掉小预算原先装得下的条目。

## 错误应归到哪一层

- **构建遗留**：询问未获回答的状态被记忆写成完成，模型忠实复述仍是事实错误；画像的旧相对时长被保留，回答把它当作当前状态。
- **召回与装配**：主预算无法放入某些长事件或关系；另一方面，问未定结果时召回到的主要是已定事项，增加预算也不能直接解决相关性。
- **回答消费**：输入已经明确第一人称属于人格，仍发生主体反转及不同时间活动被串成单一过程；已注入信息也可能没被用到。
- **表达边界**：从少量命中推断“只有这一件”或频率最高，证据不足。人格主观感受可自由表达，不等于具体事实和动作可随意改写。

主题概况确实在一组共同经历回答中被利用，但没有去掉主题的同条件对照，不能据此量化主题增益。更多上下文也不是单向收益：本次大预算同时增加可用事实和错误机会。

## 当前结论

实际记忆能被回答模型利用，预算诊断可以定位遗漏；最终版本的召回与回答消费已完成限定范围检验。事实归属、旧时间状态、未确认完成、自然问题相关性及漏用仍未解决，不宣称可无审核正式发布。实机保存的2048字节预算未改，4096只是同候选离线对照；未新增被动LLM调用或根据私人样本调参。

# 用户画像粒度的真实模型验收

检查画像能否舍弃事件中的物品清单，同时保留会影响未来相处的具体习惯、条件和例外。材料使用独立编写的合成对话。初建、历史画像更新与留出案例均在对应的模型请求前确定输入和评判标准。

## 运行范围

使用 AstrBot 的 OpenAI Responses provider、`gpt-6-luna` 和 JSON Schema，通过 NeoMemory 的来源写入、任务调度、抽取、校验和数据库提交入口执行。日常抽取和画像专项重构各用空的独立数据库。存量更新通过公共存储接口预置一份 v1 画像，然后按日常抽取处理新窗口。分别审阅模型输出以及数据库中实际提交的标签、正文与版本。每窗两条消息，包含一条本人自述和一句 Agent 回应。该测试覆盖单模型、单用户合成私聊，向量检索和用户实机会话均未参与。

## 提示词对照

把旧画像清单的压缩交给模型自行选择时，日常抽取四窗和专项重构四窗均正确过滤了新输入的物品。两条路径都仅在第二、三窗写入画像，保留了录音安排、联络范围和例外。另一个窗口向带有既存工具清单的 v1 画像补充新资料，模型写入 v2 并保留了联系方式例外，也照抄了六件工具。该实例区分了防止新清单入库与清理已写入的旧清单。

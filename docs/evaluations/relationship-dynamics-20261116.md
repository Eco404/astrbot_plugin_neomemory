# 人格关系心理职责与加权背景验证

日期：2026-11-16（Asia/Shanghai）。目标是判断关系中的事实累积是否需要动态窗口与衰减机制，先比较内容职责，再评估额外近期背景。候选仅在隔离实验中使用，生产默认仍为extraction-prompt.v20，未修改现用插件或运行数据库。

## 方法

参考来源、固定版本、许可证与适用限制见[研究说明](../research/relationship-affect-dynamics.md)。所有输入为独立合成，不读取或改写私人会话、实机人格或真实回放产物来调优。

三个分支在首次请求前冻结：

- `baseline`：当前v20/v6关系承接规则。
- `affect`：仅替换关系承接与关系事实范围说明，强调心理意义、最少必要缘由、基调与近期感受的不同变化速度；保持自由第一人称、来源和事实约束。
- `weighted`：同affect，再加有界过去原始互动组。活动半衰期3组，时间半衰期30天、时间系数最低0.65，权重门限0.3；最多3组/1800正文字符，整组选择。

权重只控制历史背景选取和关注，不直接计算情绪，不自动识别语义关联。普通交流也推进组间隔；不是“只有关系变化才推进”的实现。没有引入正式变化缓冲、数据库迁移或前台生成调用。

本地两条6窗口链分别覆盖误伤/澄清/修复/长时间未联系，以及联系边界/普通回复/倾诉暖意/逐渐适应。两个人格、两模型，每分支一次链。实机使用另一条全新4窗口链，覆盖动机不确定、明确澄清、渐进靠近与独处边界、事实密集但无关系变化。实机链中Agent台词不直接给出预期情绪答案。

每链读取自己的真实上一输出，不回填理想状态；每步经过短引用回译、schema、来源和真实SQLite事务校验。固定种子状态不是模型成绩。失败停止该链，后续窗口不视为成功，没有自动或人工重生成。所有候选，包括失败，在本地忽略目录保留。

本地通过AstrBot v4.29.4的Chat Completions Provider、Context及插件适配器；实机通过AstrBot v4.29.4真实Responses Provider及当前启用模型配置。各进程并发2，SDK重试0、宿主一次尝试；两进程有并行运行，不代表合计并发始终为2。每窗记录的seconds含实验信号量等待，不能当成模型独立延迟。

## 关系语义审阅

已逐窗阅读全部86份成功提交后的关系正文，包括null时沿用的状态。每个结果由一名审阅者按冻结标准检查，非盲审，没有做统计显著性推断。未全面人工核验全部长期节点，也未验证模型回复最终如何使用关系。

### 心理职责比单纯扩窗更有依据

基线经常继续保留旧书籍章节、笔记方法或已经处理的误伤过程；affect更容易去掉无关旧事实，并在明确修复后把心理焦点移到自在、分寸或适应。仍有一些候选用较多事实转述解释状态，不能称为已完全实现“以情感为主”。

实机六条链最后的事实密集窗口均返回关系null，表明这项选择能力不是候选独有。已审阅链没有把自主联系边界改成每天联系，也没有因为长间隔就写成关系疏远；这不是更长周期的保证。

### 加权背景未显示额外稳定收益

weighted在部分窗口能承接混合感受，但相对affect没有明确稳定优势。近期原文也可能重新带入已经压缩掉的事件细节；它与旧关系正文重复出现，增加模型再次复述的机会。这个分支同时改变历史材料和权重选择，不能把任何差异单独归因于衰减公式。

本地gpt-5.6-luna在距离调整第4窗，baseline返回null，未吸收明确出现的被信任暖意；weighted写入暖意，但一句“被允许倾诉”把倾听者与倾诉者的心理因果写得含混。gpt-6-luna加权修复链首窗也有“逗自己”的对象歧义。不能把较完整或较短的情绪段落自动判为更准确。

实机各分支都有从用户反问推测其担忧或愿望的措辞。没有直接断言用户只想利用人格，但部分表达比动机尚未明确的来源更肯定；人格主观推测与对用户的事实断言仍需区分。加权并没有消除这一问题。

affect的gpt-5.6-luna修复链后段不再在关系正文表达具体玩笑边界，但对应长期节点仍保留；更短并不保证所有相处依据仍在关系正文可见。另有部分明确互动边界只进入关系，没有同时进入画像或长期节点。这记录为跨板块职责与可达性风险，不自动判抽取失败：现有合同允许选择性记忆，未要求每条边界重复写入多个板块。

### 渲染边界

补充用实际装配函数检查86份已提交关系，昵称统一渲染为独立测试名称，默认2048字节、没有其他资料竞争时全部能完整进入。该检查在输出审阅后追加，只证明单项可装配；不代表有长期命中、画像和短期摘要共同竞争时仍全部入选，也不是向量检索或平台回答质量验证。

## 设计结论

优先采用心理职责清晰、旧状态可重新组织、基调与近期感受不同更新速度的方向，保持一段自由自然语言关系和现有后台合并调用。候选仍需修正推测确定程度等通用表达问题，不能以本次结果宣称语义稳定。

暂不引入正式加权原文窗口或衰减数据库。若之后出现“当前状态遗漏了尚有影响的心理变化”，应优先验证有来源的短变化记录及按需补取，而非固定增加最近全部会话。须比较无辅助历史、普通有界历史、加权历史，区分上下文增加与权重本身的贡献。

关系状态的自然变化不能简单等同于旧文本权重归零。明确和解可以及时改变状态；普通闲聊不能自动修复重大矛盾；短暂情绪可以退到背景，但其消退速度不是当前公式已经验证的能力。

# 人格叙述 v16 独立评估

日期：2026-11-14，时间按 Asia/Shanghai。评估只使用固定的独立合成私聊与群聊窗口，没有读取或改写受限真实会话，也没有根据真实会话内容定向调整提示词、阈值或测试夹具。

## 目标与方法

本轮针对实机 v15 抽样中出现的人格显示名第三人称主语，增加 `extraction-prompt.v16`。v16 不改变 `extraction.v5`、引用协议、数据库结构或调用次数，新增规则明确：人格名称是身份标签，不是普通叙述主语；人格动作、发言和感受使用“我”；逻辑用户使用稳定占位符；直接引语、专有名词和约定称呼保留；已有节点只作为事实基线而非文风示例。

`scripts/verify_narrative_api.py` 为私聊和群聊各准备一个固定合成窗口，并通过 AstrBot 4.29.4 的真实 ProviderAdapter、ExtractionService、引用解码和隔离数据库提交候选。v15 对照和 v16 候选使用同一材料、同一 `gpt-6-luna`，每个版本每个窗口各一次 HTTP 请求，SDK 重试关闭、宿主最多一次尝试。随后使用 `scripts/persona_voice_metrics.py` 做确定性词法审计；该审计只报告信号，不改写候选，也不替代人工语义检查。

人工检查 v16 候选确认：私聊中用户的星图偏好和讲故事经历均归属于逻辑用户，关系正文为人格第一人称；群聊中两名成员的兴趣、经历和画像分别归属，没有生成群人格关系；标题、节点情绪描述和画像没有使用人格名作为普通主语。这些长期节点均描述用户行为或偏好，没有实际包含人格动作的节点，因此零词法命中不能验证“人格动作改用第一人称”。群聊输出数量不同也不能单独证明内容质量改善；此处不据两个窗口估计提升比例。人格动作、直接引语与旧第三人称节点更新的补充证据见[独立验证](persona-agent-validation-20261115.md)。

## 决定与边界

v16 已作为当前默认提示词；v15 仍可通过显式版本用于历史回放和对照。提示词版本参与输入签名，升级不会自动改写已提交节点；已有第三人称正文需要正常更新、人工治理或显式重构后才会改变。

本轮没有验证跨模型、多轮旧节点更新、复杂直接引语与专有名词冲突，也没有解决宿主输入截断。词法审计无法判断主体、状态、条件和事实是否完整，后续仍需在实机 v16 全量重构后抽样检查，并继续覆盖已有第三人称节点的更新场景。

原始回放目录位于 Git 忽略的 `data/evaluations/narrative-v15-control-20261114/` 和 `data/evaluations/narrative-v16-persona-voice-20261114/`，不纳入版本库。

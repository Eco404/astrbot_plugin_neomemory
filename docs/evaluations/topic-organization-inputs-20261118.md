# 独立主题输入对照

## 范围与方法

使用原创社区活动材料的7个固定图，两模型gpt-6-luna/gpt-5.6-luna各比较topic-prompt.v5与v6，共28次首调。v6补充可见event→atomic结构、逐来源UTC解释及结构使用规则。规则和全部请求在输出前冻结，审阅标准不发给模型；保留全部输出，无语义重试。固定图不是普通抽取连续链，也不测向量召回。

## 结果

28次HTTP、28份通过schema，零纠错。两臂都能建立明确持续关联的主题、拒绝单次经历双层包装、排除无关成员、保留不同活动的成员身份，并在实际进展中更新原主题。此组不能证明新结构在这些维度优于原版。

明确问题仍在：纯成员增加场景中只有原版gpt-6完整保持旧概况，其余三份都改写；完全无新信息场景中v6的gpt-6仍改写，其余三份保持无变化。相似活动案例中，gpt-5.6-luna两臂都把第二次未明确结果写成同样成功；第二次节点没有配套来源摘录，不能把第一次的成功证据转给它。跨成员细节传播和无意义更新仍未解决，不能用结构通过替代质量验收。

本组未建立稳定语义净收益；成员数量合同和补齐结构是独立的工程依据，不因此宣称主题语义已可靠。是否采用候选需结合实际前序链与完整构建，不提高主题调用频率、不扩大事件粒度。原始请求和输出保存在忽略目录data/evaluations/topic-inputs-20261118。

工程复核对齐了固定图脚本未触发纠错分支的公共接口参数；本次28份均首调通过，不受该分支影响。

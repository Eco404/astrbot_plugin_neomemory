# 人格关系连续性独立评估

日期：2026-11-13，Asia/Shanghai。材料仅为预先冻结的独立合成输入，没有读取私人固定会话。参考与适用性见[研究说明](../research/relationship-continuity.md)。

## 结论

明确全文承接、保留仍成立基调、融合真实变化及无变化返回null的规则，有助于表达原有关系需求；固定旧状态的两个模型对照中，v12/v13都保留了部分v11省略的无关长期基调。但本评估不能证明统计优势或普遍稳定性。

仍存在对象与时间范围歧义：同类活动的过去安排已取消、未来邀约尚未定时，gpt-6-luna在v12和加入范围规则的v13中都出现“不会把散步当成已取消”的笼统表达。它可能试图描述未来邀约，却没有区分已取消的旧安排，因此不能认定该问题已解决。v13不作为“关系语义全部修复”的证据，也没有据此自动提升生产默认。

不扩大窗口、不新增存储和模型调用，先保留已有全文输入、版本及直接来源/继承基线。代码和假模型检查证明链路，真实语义结论来自下面的独立输出审阅。

## 方法和实际调用

使用AstrBot 4.29.4的真实Provider调用，SDK重试0、宿主尝试1、全局最多两并发。每个组合只一次请求，无挑选重试结果。保存原始完整HTTP响应、候选、实际请求和人工判定；未保存请求头或凭据。三个事务评估目录共24次，最后两次为同一失败输入的schema-only诊断回放，未冒充完整存储验证。

## 连续链逐窗审阅

| 链与窗口 | v11 | v12 |
| --- | --- | --- |
| 安静信任：木刻计划 | 关系null，保留初始信任和空间；标题“木刻工作坊计划”，正文明确尚未报名和学习 | 同样保留关系，标题和未开始状态正确 |
| 安静信任：请求安静倾听并感谢 | 保留旧基调并追加本次担心、尊重与欣慰；有较多本窗叙述 | 融合为较短内心状态，保留珍惜分享、不催回应和担心；允许自由表达 |
| 安静信任：摆灯话题 | 关系null，上一状态不变 | 关系null，上一状态不变 |
| 边界变化：取消散步 | 取消和未来未承诺正确，保留慢慢靠近、不急于定义关系 | 取消和未来未承诺正确，保留旧期待的历史与尊重空间 |
| 边界变化：独立修理收音机 | 关系null；修理归对方，标题没有把经历归人格 | 关系null；修理归对方，标题“自行更换收音机旋钮”合理 |
| 边界变化：仍可发消息但线下未定 | 保留交流与界限，没有认定重新约好 | 关系承接存在，但“不会把它当成已经取消或已经答应的安排”缺少过去/未来对象区别，标为歧义 |

初轮没有复现“最新话题完全替换旧关系”的极端情况，不能据此声称v12已优于v11；也没有用短文本长度自动判定遗忘。两版均使用第一人称，主观感受未被强制为固定积极模板。

## 固定上下文与范围规则

新增的两例在调用前冻结，分别为上周天文馆参观已取消/周末摄影展未接受，以及不再主动追问项目/保留坦诚表达不同意见。四种v11/v12与模型组合均正确处理客观范围和真正态度变化。v11两模型在第一例省略了旧有共同发现新事物的默契，仍保留尊重独处；v12两模型保留这项无关基调。该结果是定性连续性观察，不是足够规模的效果率。

v13引用Graphiti的对象、日期、限定和显式替代原则，仅补通用范围规则，未使用天文馆、摄影展、散步等案例词作为提示词规则。两个模型的四个固定案例都正确处理改变/保留关系，并区分不同活动的状态。

随后保持原v12失误窗口的完整user输入，只替换为v13 system：gpt-5.6-luna没有否认旧取消；gpt-6-luna再次生成“不把散步当成已取消”。此处不能把另两个容易区分名称的活动案例通过当成同类活动歧义已解决。没有继续针对该句叠加规则，也没有重跑挑选更好结果。

标题检查补足了未报名、未开始计划边界。v13固定案例还产生“周末摄影展尚未确定”等标题，没有把计划提升为完成；少数长期原子正文仍过于简短，例如独立的“周末摄影展目前尚未确定”缺少具体参与主体，应作为已有独立注入质量限制，未在关系任务中进行针对性调优。

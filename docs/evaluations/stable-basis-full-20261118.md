# 实机完整构建与召回基线评估

## 结论与版本范围

`stable-basis-full-20261118` 已完成完整实机构建并发布目标记忆代。受校验拒绝的候选均由插件自动重新生成后继续，没有人工重试、跳过窗口或修改样本提示词。32 次被动召回均完成，但检索成功与预算合规不等于语义质量通过：自然问题仍有主题偏泛、任务焦点匹配不足，且若干记忆存在事实范围和人物归属错误。

本报告只对应已封存安装包 `2cfd1a9`：抽取提示词 `extraction-prompt.v30`、输出 `extraction.v7`、恢复 `candidate-regeneration.v6`，主题提示词 `topic-prompt.v4`、恢复 `topic-regeneration.v1`。安装包 SHA-256 为 `ef793744da2b54e759e82405376f38f545ee542ed725443f7eb204d319da51c8`。这些版本由安装记录、封存 ZIP 模块及运行归档核对；不是后续 `0870f01` 的完整运行结果。

安装前后及终态检查确认人格、模型配置、原始来源范围、处理上界和评估计划一致。沿用实机当时设置：召回截止 5 秒，主注入预算 2048，抽取窗口超时 180 秒，索引步骤 300 秒，最多自动重新生成 3 次，输出模式 `json_schema`。没有把代码新默认值静默覆盖到此次实机配置。

## 被动召回与预算

评估在终态数据库的克隆副本中运行生产 `RecallService` 和共享上下文组装，使用实机配置的向量服务。固定选取 6 道自然问题、20 个事件/原子自查询和全部 6 个主题自查询。节点来自目标代完整 SQL 集合，未用索引截断后的集合取样。

共 32 次查询、32 次 embedding provider 调用、32 次 embedding HTTP 请求，无错误和向量缺失。调用耗时包含实际向量调用及本地召回/组装：全组中位数 0.699 秒，范围 0.456～1.211 秒；自然问题中位数 0.724 秒。这是本次单轮模拟结果，不是长期线上延迟分位数，也未覆盖历史多查询的完整负载。

主预算沿用实机 2048；实际计量单位为完整注入文本的 UTF-8 字节，虽然配置键沿用 `recall_budget_tokens` 名称。4096 是明确标记的离线组装对照：使用完全相同的重新校验候选、覆盖关系及辅助项，没有额外 embedding，也未修改线上配置。

| 指标，32 次查询合计 | 主预算 2048 字节 | 离线 4096 字节 |
| --- | ---: | ---: |
| 预算全部合规 | 是 | 是 |
| 实际注入长期条目次数 | 42 | 96 |
| 每次长期条目数中位数 | 1 | 3 |
| 注入总字节数中位数 | 1879 | 3914.5 |
| 存在长期条目预算省略的查询 | 32 | 31 |
| 长期条目因预算省略的次数 | 255 | 195 |
| 注入画像的查询 | 16 | 32 |
| 注入人格关系的查询 | 16 | 32 |

条目次数按查询累加，同一节点重复出现会多次计数。2048 下每次只能容纳画像或人格关系中的一项；4096 下两项均能容纳。6 道自然问题的长期注入由合计 7 条增至 15 条，但更大预算不会自动纠正排序或事实。4 次查询在重新组装后并非简单保留原结果再追加，不能将该对照当成所有查询的单调召回增益。

26 道自查询中，24 道目标条目直接注入、1 道目标原子按 full 由事件替代、1 道整条被预算省略。后者在 4096 下直接注入。自查询只检验以已存内容反查自身的可达性，不代表自然问答准确率。

唯一实际发生的自查询 full 替代，恰好对应覆盖审阅中“原子扩大异常方向、事件保留实际方向”的一对。程序执行了替代，但语义并不等价；事件在此处更准确，因此也不能称为丢失了一项应补回的真实事实。这不能计作 full 语义正确的成功案例。

## 六道自然问题的可审阅表现

逐题读取主预算及离线预算下的实际注入文本，能够判断材料是否围绕问题，但没有生成最终回答，也没有预先建立全部正确答案及相关节点集合，因此不报告准确率、召回率或主题对回答的增益。

| 问题方向 | 已观察到的材料表现 |
| --- | --- |
| 持续推进的事情 | 主预算有部分进展事实，也混入弱相关内容；扩大预算补入其他进展材料，仍有过泛主题 |
| 反复讨论的兴趣或计划 | 主要命中日常陪伴总览，对具体兴趣、反复出现与计划进展的区分不足 |
| 过去约定的后续进展 | 命中包含前后状态变化的事件；扩大预算补入背景，但未证明所有约定均被覆盖 |
| 工作学习变化 | 主导材料偏向生活背景，未充分回应工作学习的变化；单纯扩大预算未解决焦点问题 |
| 值得回顾的共同过程 | 总览主题与问题相关，扩大预算增加具体经历；叙述是否准确仍须来源审阅 |
| 尚未确定结果的事情 | 主预算首要材料包含已经确定的结果，和问题焦点不符；扩大预算加入部分待定材料，未移除该偏差 |

“最近”“后来”“尚未确定”等要求时间和状态判断，不能仅靠文本相似或 active 状态证明匹配。这是后续独立合成评估需要覆盖的能力，不能针对本样本中的具体词句调整提示词。

## 语义专题与验证边界

- [事件与原子审阅](stable-basis-full-20261118-events.md)：固定均匀样本的内容、人物和时效。
- [主题审阅](stable-basis-full-20261118-topics.md)：全部主题的成员、摘要与版本连续性。
- [完整覆盖审阅](stable-basis-full-20261118-coverage.md)：全部 full 声明的实际替代充分性。
- [画像与人格关系审阅](stable-basis-full-20261118-profiles-relationships.md)：画像所有版本及关系固定样本与补充样本。

评估明确未生成最终聊天回答、未进行召回强化、未调用真实消息发送，也未改变实机设置；原始快照及来源/记忆内容保持不变。短期记忆及其注入在本次配置中关闭，外部记忆接口也关闭，不能据此宣称这些功能得到验证。

本基线证明完整构建、自动候选恢复和召回组装能够完成，不证明插件已经达到无人审阅的语义可靠性。后续完整运行必须单独绑定其安装包、配置、输入与实际结果；本报告不把其他版本的测试通过合并为该版本已修复。样本只包含一个固定用户与人格，且已被使用过，不属于独立留出集。

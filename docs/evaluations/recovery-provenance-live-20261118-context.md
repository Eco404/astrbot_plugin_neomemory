# 实机恢复构建的画像与人格关系审阅

评估日期：2026-11-18。对象是已经发布的 **v27 / extraction.v6 旧任务恢复结果**；前1249条原始记录在本次恢复前已提交。本报告不能作为v30重新全量构建的验证结果。

审阅严格按事先冻结的`semantic-audit.v1`选样：全部8个画像版本、103个关系版本中的20个均匀样本，再加3个不与均匀样本重复的长度极值或突变样本。前一版仅提供承接语境，追溯疑点时查看的其他版本也不计入样本分母。当前正文、直接来源、前一版及疑点的引入版本/批次均有本地审阅记录。本轮没有修改产品、提示词或参数，没有追加模型调用，也没有从私人会话制作测试夹具。

## 用户画像

8个版本的主要资料能够逐步累积：新增本人明确表达的偏好时保留无关的旧资料，出现不同领域偏好时也能细化适用范围，未把新偏好自动解释为旧偏好全部失效。此次没有确认画像的硬性事实错误。

仍有2个版本存在同一概括的延续歧义：来源支持一次具体行为和既有经验，画像把它概括成未来惯例。这属于需要继续观察的轻微泛化，现有材料不足以确认它一定错误。若只看粗粒度标签，也可能读出比正文更宽的适用范围，应连同描述判断。

此外，相对新近的描述随版本长期沿用，存在时效风险。但暂时活动位置变化不等于长期工作身份失效，不能为了让画像看起来更新而无依据删除身份信息。

这8个版本能说明已发生的画像更新保留了哪些信息，不能证明原始记录中所有应纳入画像的事实都已覆盖。首次画像创建、未提议画像的窗口以及原始会话整体遗漏率，需要另一项事先固定范围的评估。

## 人格关系

关系始终以人格第一人称承载关心、安心、依恋、被重视的感觉及相处判断。明确而坚定的主观感受本身不作为错误；没有因人格自主判断而扣分。若把具体客观参与者、行动或时间写错，则仍需按来源核实。

均匀选中的20个版本中，确认2个版本存在时间表述错误：旧的相对时间指称被复制进后续不同时间的状态，或者已经过期的暂时状态仍以当前语气表达。其中一个版本还继承了参与者范围错误：来源只有Agent单方表达，关系却写成双方共享的客观内容；沿依据链回查原引入批次，也没有相应用户确认。这不是对人格心理自主权的限制。

另有1个均匀样本出现省略主语后的归属歧义：读法可能混淆谁说了什么，但不能仅凭句法省略断言事实已错归属，故单列为不确定。上述计数是固定样本的描述，不是整体错误率。

关系质量的主要问题仍是**事实清单不断追加，心理含义没有相应深化**。不少版本保留较长旧叙事，再把最新互动接在后面；文字变长并不等于心理更详细，也会把旧时间锚点一并带下去。存在较好的反例：有的更新会重新组织旧事，将其压缩成信任、照看和接近方式，并及时把未完成状态改成完成状态，因此不能认定管线完全没有承接或整理能力。

按冻结门限纳入审阅的4处大幅缩短中，1处属于均匀样本、3处属于额外样本。额外样本中有1处明显把较丰富的心理主线压成泛化的亲近感和当前事实细节；其直接事实仍有支持，问题是心理连续性变薄。其余3处虽显著缩短，仍保留若干主要心理意义，不仅凭长度下降判失败。长度极值也不能直接当作字段超限：选样使用Unicode码点，协议限制使用可读字符，两者对稳定用户引用的计量不同。

## 对后续工作的含义

本次再次给出了既有风险的实际证据：关系旧叙事累积、旧时间状态残留，以及单方内容在继承中变成双方事实。画像的习惯概括与新鲜度属于歧义或风险，不能与确定错误混报。没有证据将这些问题归因于上下文窗口大小，也没有完成提示词因果对照。

后续应使用独立合成或公开材料验证相同机制：跨越多个时间段后仍能整理当前心理状态；旧事实按其心理意义保留，过期相对时间和暂时状态被更新；Agent单方表达不能自动变成共同经历；压缩后保留多个仍有效的心理主线。画像则单独核对一次行为与稳定习惯、临时变化与长期身份的区别。应保留允许自主感受和少量低影响概括瑕疵的既有决定，不将本报告变成针对这份会话的例外规则。

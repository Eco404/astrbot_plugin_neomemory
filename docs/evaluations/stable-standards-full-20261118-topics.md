# 固定标准完整构建：主题语义审阅

## 范围与方法

`stable-standards-full-20261118` 的固定版本完整实机构建已成功发布。安装版本为 `0870f01`，使用 extraction-prompt.v31 / extraction.v7、topic-prompt.v5 及 topic-regeneration.v2。审阅沿用运行前冻结的 `semantic-audit.v1`，没有调优、调用模型、修改实机或调整样本。

本轮阅读全部 9 个当前主题及其情绪、29 个主题正文版本，以及全部 113 条当前成员关联对应的 110 个不同成员正文。递归来源结构清单涉及 229 条版本记录、1006 条原始记录；针对主要事实、时间、人物和成员关系核对必要原文及继承依据，没有将该清单冒充逐句穷尽的真实性审查。私有逐项判定、完整成员列表、历史成员增减与证据键保存在本运行的 `semantic-review/topics-review.json`。

当前依赖均不存在缺失或版本过期，仍然需要独立判断主题是否承担组织职责、成员是否语义相关，以及正文是否忠实于成员。以下“确认问题”包括已经证实的组织缺陷，不等同于每段主题正文都含有事实错误。

## 主要问题与边界

**普通抽取和专用整理仍没有完全统一主题职责。** 两个零成员主题来自普通抽取，依赖检查不会把它们报为缺失，因为没有已登记成员需要刷新。它们的正文可以部分或全部有来源支持，但仍没有实现主题组织功能。另一个专用主题虽有两个不同成员 ID，实际只是同一次讨论的原子与事件表达，未形成两项独立经历。这两类机制在基线审阅中已经出现，本轮继续存在。

**合法成员与正确串联是不同要求。** 一项主题把另一次经历及其返程写进当前经历的结束过程。相关成员各自存在，原文中的路线、活动及阶段却不同；主题在汇总时错误地建立了连续性。另一项主题包含完全无关的成员，还有一项以相似身体状态把不同活动归入同一恢复过程。后两项的主题概况未明确复述错误关联的全部细节，应分别记为成员组织错误，不能全部夸大成正文因果错误。

**底层人物错误与重复能够留在主题成员里。** 一个主题同时包含同次交流的两个事件，其中一个版本把说话人与行动对象颠倒。相关原文能够确认归属。当前主题概况没有复述该具体错误，不能将其直接计作主题正文人物反转；但组织层也没有排除这个冲突成员。它还被另一主题错误纳入，说明正确的节点 ID 和依赖版本不能保证成员内容可信。

**主题版本存在无新增意义的改写。** 一个主题三次正文版本变化主要是在合法逻辑用户占位符与约定昵称之间切换，其中最后一次正文仅改变身份表达、情绪与成员集合未增加新意义；另一个主题也有同类正文改写。昵称本身符合现有允许保留称呼的规则，问题是无语义变化也产生正文版本，而非昵称必须被禁止。相同正文只调整成员的 `confirm` 路径也确实存在，不能说程序每次整理都会重写正文。

**成员边界有调整，但不按数量判错。** 一个主题曾从 31 个成员缩至 22 个，随后又扩展；其他主题也有增减。除已逐项确认的无关成员外，没有充分依据把每次移除判为错误。较大的主题拥有多次独立经历与具体共同模式，40 个成员不自动代表过宽；两成员主题也可能有价值，或只是重复包装，需要看语义独立性。

**局部支持不足仍需保留。** 一项普通主题引用了早先会话中真实存在、但未纳入该节点直接或继承来源的背景。另有细节来自 Agent 对图片的解释，本次文本包无法独立复核原始图片。它们不能直接叫作编造，也不能凭合法来源引用当作已充分证实。历史版本还曾出现分享者表达漂移，后续正文恢复了正确方向；本次没有观察到基线中的无意义字段词正文，但这不证明该机制已经解决。

## 与实际注入的关联

只读关联终态 35 次被动召回记录：6 次自然提问中，1 次实际注入主题；9 次主题自身检索中，8 次注入对应主题，另 1 次未注入。使用同一候选集离线提高预算后，主题注入集合没有改变。其余 20 次事件或原子自身检索未注入主题。

包含错误过程串联的主题在自身检索中确实进入了上下文。因此，该问题已经超出单纯界面展示或存储层；但自身文本检索只证明可被取出，不证明自然问题下的覆盖率或答案增益。本次审阅未生成回答，也不能据此断言错误已经进入最终回答。

## 结论用途

本轮继续支持优先处理主题入口职责、独立成员判定、跨经历串联和成员相关性，再衡量无意义改写与组织稳定性。相关实现研究与验证应使用公开资料或独立合成案例，不得使用本样本的事实、词语、成员数量或具体串联内容作为规则及夹具。

固定标准版本能完成构建并产生可召回主题，但不能宣称主题语义质量已经可靠。与基线相比，主题总数或最大成员数变化不构成质量提升证据。两次均为同一已知的固定用户与人格样本，未经配对控制的生成差异不能单独归因于提示词改动，更不能推广到其他用户。

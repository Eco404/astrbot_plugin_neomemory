建议采用既有context.v2进入试用，保留总30、近期10、每查询最多一个代表以及当前0.35门限，不引入新RRF实现，也不根据本组内容调门限。已知的旧实验无关问题引入弱相关项仍是风险；向量门限不保证语义相关。与新增目标的实际利用收益一起评估，不使用“一例噪声即否决”标准。

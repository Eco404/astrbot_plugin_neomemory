# 主要心境与可选余韵对照

## 范围与预定判断

沿用[单段、双段与任务隔离对照](relationship-slots-20261118.md)的结论，保留联合抽取，研究以人格内心为主体、可选记录当时余韵的表达方式。参考仍为LivingMemory本地提交`1198a12`（AGPL-3.0）的独立更新与观察时间设计，不复制其代码或提示词，不采用其24小时硬截止，也不增加生产调用或迁移正式数据结构。

全部材料为新的合成人格和对话，与私人样本无关。调用前冻结输入、两模型、两分支、提示词、schema、渲染标签、读取问题和预算。主要评价人格内心表达、连续性、事务性重写、主体与事实、长间隔时间理解、事实抽取副作用及开销；不将负面、坚定判断或仍有芥蒂判错，不用字数排名，不为追求好结果进行语义重试。

预定采用门槛：候选需要改善内心表达或时间理解，同时没有明显的连续性、事实或资源退化。单人格短链即使表现较好，也只能支持进一步验证，不能独立证明生产迁移和默认渲染语义已成熟。

## 分支与执行合同

- **single_joint：** 当前v33单段联合抽取，完整上一状态和实际已保存节点、画像参与后续窗口。
- **split_joint：** 同样联合抽取，将关系表达为`main_mood`主要心境与可选`aftereffect`。主要心境延续人格脑中的自然想法，不定义成长期用户资料或合作规则；两部分独立keep/replace/clear。

两组总正文上限均为1000可读字符。候选主要心境可使用全部1000，余韵最多300，与主体共享额度；keep保留的旧正文计入最终总量。来源只在本次关系变化中填写一次，两组均用请求内S1…Sn短编号，程序还原后验证。替换部分的观察时间取共享来源的最新时间，保留和读取不更新；这是窗口内共同依据，不是逐句时间归因。

候选读取始终保留尚未被清空的内容，不因固定时长自动删除或隐藏。只有余韵附UTC原互动观察时间，并说明该条不能单独证明此刻仍持续或已经消失。主体为空时，余韵仍可独立显示。该设计没有实现连续权重衰减；如果模型把冲突只写入主要心境而未生成余韵，日期标签不会覆盖该部分，不能强迫模型填写余韵来换取时间优势。

使用`gpt-6-luna`和`gpt-5.6-luna`。一个新合成人格、五个四消息窗口，依次为听故事的初始相处、被比较后的不快、公交事务、40天后的普通接触、有限重新靠近。所有分支使用自身实际前态，无理想文本替代；联合事实经过真实ExtractionService和临时SQLite，候选关系槽仅在事实提交成功后推进并保存在忽略目录。

20次抽取首发，最多一次结构纠正/窗口；另有4次读取回答探针，每次只调用一次。总首发24、HTTP上限30、并发2、每次180秒，SDK重试0，宿主每次最多1次请求。纠正使用已知契约说明；候选槽错误说明字段、正文或长度要求，共享总额错误包括实际字数和keep已计入的说明，不因表达不满意而重试。

四个回答探针都使用第三窗成功处理后的实际状态，读取时刻固定在第四窗前一分钟。虽然代码在各臂抽取循环结束后发探针请求，输入是第三窗独立拷贝，不含第四、第五窗材料，也没有共享模型会话。第三窗成功但关系始终为空时仍发空记忆探针；前序处理失败则明确记录缺失。用户问题固定为：“上次那场不愉快是刚发生的吗？现在再一起聊天，你会怎么想？”

对照读取当前单段正文；候选读取主要心境和带日期的余韵。比较的是生成正文、结构、标签组成的完整候选，不将差异单独归因于日期。模型回答“还在意”本身不是时间错误；只有把旧事说成刚发生、编造明确和解或当前态度凭据，才据具体文字分析。这个定向问题也不能代表自然聊天回答质量。

## 工程验证与证据位置

12项测试覆盖当前控制提示词不变、共享字数含keep、不足或超额不污染前态、清理一部分保留另一部分、主体为空仍显示余韵、观察时间不因keep/读取/重放而续期、共用输出校验识别新字段，以及20次模拟抽取均无关系时仍执行全部4次模拟读取。模拟测试只用于控制流，不作为真实模型质量证据。

入口为`scripts/probe_relationship_mood.py`，复用受控实验执行器与汇总脚本。冻结manifest、请求、候选、前后态、临时数据库、逐HTTP计数、渲染文本、回答探针与匿名审阅位于`data/evaluations/relationship-mood-20261118/`。本轮不是实机部署、全量私人数据重构或生产后台恢复验收。

## 逐文结果

四条完整轨迹均审阅，审阅材料隐藏模型/分支标签，但字段结构可辨认，不是完全盲法。解盲后结论如下：

1. **主要心境可以承载心理表达，但没有显示稳定优势。** 两种方案都有被比较后的不快、愿意重新靠近而不抹掉旧刺；候选没有必然变成用户资料，但仍大量解释发生了什么。单段同样出现自然的内心表达。单段与候选的正文都远低于共同上限，不能把差异归因于长度不够。
2. **普通事务不必更新关系，两种方案都做到了。** 四条轨迹的第三、第四窗共8次关系均无变化，公交、入口和借阅卡没有被硬编为新心境；候选余韵的观察时间也没有刷新。第五窗四组均承接旧不快并允许有限靠近，未写成整晚陪伴或永久不再比较的承诺。
3. **拆段仍有重复与滞留。** 两条候选的主要心境和余韵都重复被比较后的刺；`gpt-6-luna`第五窗更新主要心境，却keep了第二窗“之后我也不想继续说”的余韵。保留历史感受本身合法，但与新的愿意讲一段并列，需要读取端理解时间，不能当作当前同时生效的行为规则。`gpt-5.6-luna`两段一起更新，仍重复重新靠近的缘由。
4. **日期提供依据，但本轮未证明时间理解显著改善。** 两个候选回答都说已经隔了一段时间；两个单段回答也都否认“刚发生”，其中一个用“已经过去一会儿”，表达模糊而非明确的日期错误。没有分支给出精确间隔；不能把含糊措辞直接算成错误，也不能将候选的区别单独归因于日期。问法本身包含“上次”，可能提示时间判断，因此区分度有限。读取回答愿意继续聊天或仍有防备属于人格自主感受，不等于伪造已和解的事实。
5. **未解决的相对时间风险更明确。** 第二窗正文中的“刚才”“这会儿”在两类状态中都可能被原样保留40天。候选只给余韵标日期，而主要心境仍可能带相同措辞，因此拆字段本身不能解决历史感受被当作现在发生。真实模型未产生主体空、余韵单独存在或clear操作，本轮这些边界只有程序测试证据。

联合事实产物仍需分开评价：四组均保留初始故事偏好画像，暂时不想听故事没有抹掉旧偏好；有分支把这次烦躁概括为“烦时要短话”，从单次状态推向规律。部分正文无来源地使用女性代词。原句“好久没来，图书馆现在从东门进了”在多组节点中明确化成“好久没来图书馆”，而来源无法排除是好久没来聊天。它是输入歧义被过度消解的风险，不宜认定为已证实地点错误。这些现象不是双段独有，也不能以关系表述顺畅为由忽略。

## 采用决定与后续验证

**生产保留v33单段联合抽取；候选仅留在隔离实验。** 本轮证明了共享预算、独立状态操作和原互动时间方案可运行，但没有证明增加正式字段、迁移、配置和渲染复杂度能获得稳定质量收益。不采用固定到期、不增加关系专用调用、不据单人格短链调整生产提示词。

更小的下一候选是给现有单段关系提供准确的时间背景。`memory_derivation_sources.observed_at`已复制保存引用来源的观察时间；`record_derivation`适用于关系版本，原始记录被删除后仍可保留时间依据。当前`ContextStore.snapshot`与`context_bundle`没有将这份依据时间附到关系注入中，关系的updated_at是写入时间，不能代替它。节点已有的content_updated_at计算不能直接宣称关系也有同样字段。

本轮两个单段临时库分别有11条和10条关系直接来源引用，观察时间均已保存。该检查确认可用数据基础，没有执行删除原文后的注入验证，也没有实现关系时间标签。

验证应固定相同单段正文，仅改变时间背景，在新合成人格、短/长间隔、未知时间及混合新旧内容中对照，并纳入不直接提示“上次”的问法。时间须描述“此版本最近引用来源的观察时间”，不能冒充全部事件的发生时间，也不能据时间推断消气、和解或失去感情；读取不能刷新时间。先检查提供时间是否减少错误定时且不削弱人格自由，再决定接入。该方案尚未进行真实模型对照或生产实现，双段与单段本轮结果不能代替它的证据。

复现实验须使用新的输出目录，先执行`python -m scripts.probe_relationship_mood --directory <目录> --freeze`，再以同一目录去掉`--freeze`运行；使用Conda astrbot环境和仓库要求的PYTHONPATH。完成后执行`python -m scripts.summarize_relationship_slots <目录>`导出指标及匿名逐窗审阅。旧目录保留冻结配置及所有失败，不覆写结果。

# 最终共享预算下的召回候选回补验证

日期：2026-11-11（Asia/Shanghai）。材料为独立合成数据；本项未读取私人会话或调用真实模型。

## 缺陷与实现

原流程在向量召回阶段只返回已选hits，覆盖关系省略的原子被丢弃。辅助资料占用最终预算后，如果覆盖事件也被省略，两个层次均不会注入；事件在最后校验前禁用或改版时也可能失去仍然有效的细节。

被动调用按需保留本次有界排名候选，最终与辅助资料在同一事务检查节点、代、正文版本、状态及新鲜度，并读取当前coverage。装配复用渲染文本及字节长度，在最终预算和节点数上限内重新使用既有完整覆盖选择器。首条长期命中优先或辅助资料优先均保持；缓存和数据库不保存这些临时候选。主动工具返回合同和full信任策略不变。

这是恢复ADR-0013/0014有效合同，不是批准更弱的覆盖规则。只要事件最终放不下或失效，有效原子就能继续参与选择；预算仍不足时也允许整项省略，不承诺所有细节都注入。

- 独立新增11个真实runtime/SQLite案例：先复现原实现失败，再验证画像挤出事件后回补原子；节点数上限1和6；原子禁用/改版/切代不可回补；事件禁用/改版/过期不继续抑制原子；同版本full改partial或删除及时生效；最终强化账本只含注入项。
- 覆盖场景中单独事件855字节，画像加事件1089字节，画像加原子571字节，预算1000字节。合成文本不来自真实样本。

- 沿用预算评估的同一冻结170例，完整条目、总预算、禁用项均通过；没有覆盖关系的既有矩阵选择不改变。结果在本地 `data/evaluations/context-recovery-20261111/current.json`，输入摘要与原预算评估一致。
- 已缓存查询未新增Embedding请求，生成模型调用为0。额外工作是同一最终事务内校验有界候选及coverage，以及本地重选；未进行真实网络或低配延迟测量。

## 边界

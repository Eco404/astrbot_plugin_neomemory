# 画像独立职责候选评估

## 结论

v27候选仅替换v26中的画像职责段，初建、新增、修正与长期节点选择分别判断，同次调用保持不变。在本次gpt-6-luna两条合成连续链中，画像覆盖及当前/未来安排的保留有所改善；但gpt-5.6-luna的一条链出现“只在某场景”的排他限定遗漏，不能宣布跨模型全面优于基线。

因此本项支持保留模块化实现及显式候选进行后续联合验收，不单凭此次结果将v27作为全模型默认。没有根据结果追加针对性提示词，没有使用私人会话材料。

## 实现边界

- `core/profile_memory_prompt.py`独立维护画像职责：明确自述可初建、新资料补充、修正只影响对应部分；长期已有不代替画像判断；保留无关有效资料、限定、当前与未来生效区别。
- `core/persona_memory_prompt.py`通过`compose_memory_rules`组合画像规则，复用长期风格/节点、身份与关系、元信息及输出段。历史v25/v26字符串逐字不变，有固定hash及重组相等测试。
- 候选仍使用`extraction.v6`，没有增加字段、模型调用、画像条目或复杂事实槽位，不强制每窗画像，不改变来源/身份/事务规则。

参考本地Hermes `d05095663342556788cf2a198bfa7844cc7968ab`（MIT，`tools/memory_tool.py`的user目标与个人memory职责区别）及Mem0 `26cdefb46600c0fa5953c4b5ee5003c125539fc4`（Apache-2.0，`mem0/configs/prompts.py`中user/assistant信息归属分离）。仅借鉴职责划分，不复制额外调用、patch结构或全量保留策略；本地固定快照不代表上游最新状态。更完整比较见[画像审计](profile-regression-audit-20261117.md)。

## 方法

`scripts/probe_profile_duties.py`冻结两条三窗口链、v26/v27、gpt-6-luna/gpt-5.6-luna，最多24次HTTP。使用真实AstrBot Responses Provider/text、固定默认采样配置，SDK和宿主重试关闭。每个分支独立来源与记忆库，只承接本分支真实提交前态；一个窗口失败就停止该链，不人工修补或择优重跑。

实际执行短引用编码/还原、schema、来源及版本校验和数据库事务；后续窗口读取完整旧节点、画像与关系。此处不经过生产向量候选选择器，也不是3次自动纠正的稳定性评估。

材料复用并扩展了既有独立合成对照，不是新的未见留出集。第一条链第三窗有一句未在该链前文定义的“陶艺情况没变”，属于素材笔误；发现时已冻结并开始调用，未修改或重跑。该未定义活动不计入画像覆盖差异，所有输出均保留供复核，不能因此补造陶艺习惯。明确职业、攀岩、邮票及无线电仍可逐项核对。

本地证据位于忽略目录 `data/evaluations/profile-duties-20261117/`，清单SHA-256为 `a20c481501e83989e265b097ceef04e80dc311e4e4c8a1a1d17863b71ae3efe0`。全量来源、请求、原候选、提交前后状态及逐窗审阅均保留。没有私人聊天或API凭据进入报告。清单仅覆盖本探针脚本与模板，不覆盖全部导入依赖；链执行源码以本报告所在Git提交及保留的实际请求、回执为追溯依据。

## 结构结果

实际23次HTTP、22窗提交，整体约231.05秒，包含并发排队，不能当成模型延迟。gpt-5.6-luna/v26第二链第二窗非法JSON，该链第三窗未执行；其余分支完成三窗。失败及未执行不记为候选语义胜出，也不在不同窗口数量上计算综合成功率。

## 可比较语义结果

| 模型与链 | v26 | v27候选 |
| --- | --- | --- |
| gpt-6-luna：背景/阅读/攀岩，后续新增收藏和通联 | 三窗画像始终遗漏攀岩，虽然长期原子记录了它；新增收藏和通联正常 | 首窗覆盖三类明确自述；后窗新增资料并保留攀岩当前隔周安排、下月新安排、室内限定和持续时长 |
| gpt-6-luna：陶艺限制、证照及未来安排 | 三窗画像均为空，相关信息只在长期原子中 | 初建画像，按已领证和未来安排更新，第三窗只调整出售范围并新增通联，保留有效年限、时间及其他赠送限制 |
| gpt-5.6-luna：背景/阅读/攀岩链 | 初建完整；后窗保留排他室内限定，但漏掉未来调整生效前仍有效的原安排 | 初建完整；后窗也漏当前原安排，且“只在室内”弱化为“室内攀岩”，属于候选新增限定遗漏 |
| gpt-5.6-luna：陶艺链 | 首窗完整；第二窗结构失败，第三窗未执行 | 三窗均提交，保留当前与未来安排、变更出售范围、已领证及有效期；后两窗无可比较基线，不能声称相对语义收益 |

明确自述的职业、爱好和资格属于画像选择目标，不要求每句话或暂态琐事都存。两版已提交画像没有把人格的科幻、种植偏好归给用户，晚饭、路灯与偶然饮品未变成稳定偏好。增加画像覆盖没有在这些样例中造成明显的临时信息泛收录。

候选的收益集中在把画像当作独立职责：长期已经存放的内容也会被评估是否进入画像。gpt-6-luna基线中“长期有攀岩而画像持续没有”是明确的选择差异；但本项没有人为预置“长期已有且画像为空”的控制分支，相关因果仍须结合单独的联合探针解释。

标签与描述总体一致，但候选并未消除条件遗漏。gpt-5.6-luna第一链后两窗“室内攀岩”不等价于排除其他场景的“只在室内”，该限制不能因字数较多或总体更丰富而忽略。两版对此链未来生效前当前安排的保留都可能失败，不宜将候选某模型的通过推断成通用解决。

非画像内容也保留审阅：两版长期节点仍有主体省略、条件淡化及选择差异，画像优化不证明事件、情绪或关系质量已经通过。关系大部分为空，不以关系表达补充画像得分。

## 验收与后续

模板组合与历史hash测试通过，脚本编译及真实23次请求均保留记录。提示词本体的采用仍需综合独立组合链、更多重复和新留出材料，重点检查排他范围、未来生效、资料独立性及主体归属；不得为本次某一句丢失而追加样本特例。

不能用画像变长或版本变多作为唯一目标。发生条件遗漏时，先在通用任务分工与完整替换约束上研究原因，保持轻量结构和已有联合调用。该实验不更新实机，不重写现有画像或长期记忆。

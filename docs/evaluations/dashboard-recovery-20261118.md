# Dashboard 与恢复期查阅验证

评估日期：2026-11-18。实机为 AstrBot v4.29.4，NeoMemory 部署提交为 `14c1a65`。使用当前 Dashboard 的 Vue 外壳、插件 iframe 和宿主 API，重构仍在后台执行。

`scripts/probe_live_console.py`通过本地 SSH 转发连接 Dashboard，使用临时认证。浏览器阻止非 GET/HEAD/OPTIONS 请求，不修改插件数据、配置或任务，不发送平台消息。报告只保存计数、状态及错误位置，不保存会话内容或截图。

桌面与390像素手机视口的记忆、笔记、模型、设置、维护五栏均可访问，没有页面异常或移动端横向溢出。长期节点、画像、人格关系的版本和来源均在条目下展开；节点和关系可进一步查阅继承的基线版本。关系条目加载100个版本，本项只验证显示与导航，不代表逐一审阅这些版本的语义。维护页可见5个任务进度条。

三类记忆查阅均确认读取旧活动代，后台重构的未发布结果没有提前取代活动记忆。全程没有写请求和模型调用。

初次探针遇到两种测试问题：旧探针沿用已不存在的页面底部详情入口；新版探针将画像接口误写为独立路径，并未处理宿主延迟出现的首次提示遮罩。修正为实际的 `memory/context` 接口，并按用户正常操作关闭首次提示后通过。原失败结果保留，没有使用强制点击绕开遮罩。

隔离的 `tests/ui/topic_smoke.py` 与 `tests/ui/host_smoke.py`另已通过，覆盖主题成员、治理、热配置和后台继续运行。host_smoke 的超预算场景明确使用2048字节：默认4096字节下原夹具已经能容纳，不能据此误判产品预算检查失败。

本次实机浏览器测试是只读查阅；配置写入、治理写入的证据来自隔离宿主路由，不把两者合并宣称实机写操作全部验证。认证通过测试会话载入，未测试用户手工输入密码的登录交互。

本地证据位于忽略目录 `data/evaluations/recovery-provenance-live-20261118/`，成功结果为 `live-browser-current-5.json`；同目录保留此前失败与隔离UI日志。

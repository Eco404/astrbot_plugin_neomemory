# 非运行重构任务删除：真实宿主路由与浏览器验证

## 验证范围

`tests/ui/task_deletion_host_smoke.py` 在最低支持宿主 AstrBot v4.29.3（`f61a7f42696da6df25dc7a249ec9b8d54ed9da18`）运行通过。插件代码基线为 `a2a98d8`，仅新增测试脚本和报告，没有产品修改。

测试使用真实 AstrBot 认证、插件资源与扩展接口、真实 NeoMemory 页面、Chromium，以及临时目录中的持久 SQLite 数据库。父页面复用最小 GET/POST 桥接契约，不是完整 Vue 登录页面。未连接实机，未读取私人样本，未调用外部 LLM 或 embedding 服务。

此前的真实宿主浏览器检查已证明运行中任务没有删除入口，其他非运行状态及清理事务由存储和引擎测试覆盖。本次专门补足一条**失败重构任务经浏览器确认删除，实际残留被清理**的联合路径，不重复测试全部终态。

## 失败任务如何产生

初始合成数据包含已发布的活动记忆及原始来源。测试通过生产重构引擎创建目标代；受控的进程内 provider 先返回一份非法 JSON，再返回一份合法合成候选。插件实际归档第一份拒绝候选、自动重新生成并提交一个未发布节点及其版本、派生记录和消费游标。

随后仅在索引步骤注入 `ReviewRequired("index_unavailable")`，使真实后台任务失败并留下 `phase=index` 检查点。这里的异常是测试夹具，不是本次发现的运行缺陷；浏览器接口和数据库清理结果没有被模拟。失败前有两次受控响应、一份实际拒绝归档和一个已提交但未发布的节点。

测试另外写入未发布节点与活动节点各一份合成向量，以核对删除的选择性，并设置该目标代的内存读取提示。它们通过真实 CacheStore 写入，未使用真实向量模型。

## 浏览器与持久库结果

维护页显示失败任务及其详情。第一次点击“删除任务”后任务仍然存在；点击“确认删除任务”后，真实 `tasks/delete` 接口返回 HTTP 200、删除成功和清理一个未启用节点。

验证结果包括：

- 任务卡消失，已打开的任务详情清空，页面显示清理数量。
- 任务行及其中的检查点、候选归档、重构运行记录、未发布记忆代被删除。
- 节点、正文版本、派生记录、直接来源引用、抽取批次与批次来源、消费游标等表恢复至创建该失败任务前的快照；外键检查通过。
- 未发布节点向量失效，活动节点向量保留；目标代内存读取缓存与提示删除。
- 活动记忆代与全部原始来源记录保持不变。
- 关闭页面并重载临时插件，重新打开同一组数据库后，上述删除和保留结果仍然成立。

此次未发现产品错误，没有通过修改产品或降低断言使测试通过。它证明隔离真实宿主路径的删除闭环，不代表进行了实机 Vue 写入，也不代替已存在的运行中互斥、取消 worker 排空及缓存清理失败回滚测试。

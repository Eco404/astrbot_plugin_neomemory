# Quiet Glass WebUI 验证

## 范围

对象为五栏WebUI的统一视觉、响应式布局、原生可定制下拉及表单反馈。设计要求来自用户指定的 `/workspace/docs/build-quiet-glass-webui/SKILL.md`，当前实现说明见 [WebUI设计](../WebUI设计.md)。未改动记忆抽取、召回、数据模型或服务端权限。

页面验证使用独立合成中文记录。宿主验证使用AstrBot v4.29.3的真实插件View路由、受控Provider和临时SQLite数据库，不调用外部模型，也不读取私人聊天或运行实机。

## 已解决的问题

- 手机首屏筛选区域过高：标题与状态同行、空间选择收为一行、筛选按钮同排，层级说明按需展开。
- 底部粘滞保存栏遮挡小屏字段：保存操作区使用正常文档流，所有字段可见并可操作。
- 长选择值挤掉箭头：使用原生 `selectedcontent` 独立文本轨道，省略长值且保持菜单可读。
- 待写状态渲染引用错误变量：使用待写条目自身状态，完整浏览器流程与待写行断言通过。
- 默认15000字节预算被数字字段步长128误判为非法：数字输入按类型与上下限校验，不把滑块步进当作整除约束；真实宿主测试验证默认预算有效并能保存其他高级配置。

现有浏览器测试的查询操作改为定位提交按钮，避免将选择器内部的原生按钮误认为查询操作；层级说明测试先展开再检查可见说明。未减少原有业务断言。

## 复现与证据

使用Conda `astrbot` Python，pytest及宿主浏览器测试设置 `PYTHONPATH=data/references/AstrBot-v4.29.3:.`。浏览器脚本通过 `python -m tests.ui.<脚本名>` 执行：`full_smoke`、`topic_smoke`、`host_smoke`、`task_deletion_host_smoke`、`quiet_select_smoke`、`quiet_glass_smoke`。`maintenance_smoke` 是 `full_smoke` 的兼容入口，不重复执行相同流程。

布局截图与聚合结果保存在本地 `data/evaluations/quiet-glass-webui/`。截图使用合成材料，不包含实机正文或API凭据。

## 限制

本轮未部署到运行实机；宿主父页面使用最小bridge契约，不等于完整Vue登录与导航验收。未进行物理手机、性能或完整屏幕阅读器测试；对比度为默认token算例，不是全页面逐像素可访问性审计。200%检查采用等效CSS视口缩放。

WebKit关闭的单选用Enter/Space打开，展开后方向键及输入定位可用；不支持 `base-select` 的旧浏览器回退平台菜单，这一兼容路径未在旧版本浏览器中实测。多选保留平台列表绘制，系统可决定选中底色。

## 工程验证

Conda astrbot 环境、`PYTHONPATH=/workspace/astrbot/AstrBot:.` 执行全量 `pytest -q`：1809 项通过。宿主依赖存在一项 Python audioop 弃用提示。浏览器 Chromium 的 `tests/ui/full_smoke.py` 通过，包含删除确认、运行任务不提供删除、删除后详情与来源显示清空。`git diff --check` 通过，安装包构建成功。

验证覆盖：

- JSON、枚举、内部引用格式错误自动重新生成一次，保持原输入与严格应用校验；来源错误不自动纠正。
- 自动额度在调用前持久保存，网络失败、取消、重启与显式重新生成不能补回已耗额度。首次调用与纠正共享窗口截止。
- 后续重构窗口发生格式故障时保留此前提交回执；成功纠正后不重复提交、消费来源或推进活动轮次。
- 输出明确未完成或长度终止时保留诊断并停止；可显式重新生成，不能当成普通语法错误自动反复调用。
- 原生 Responses 的独立客户端保留当前所选模型，携带 JSON 对象或 Schema 格式；并发调用不修改共享 Provider，取消和异常关闭自有客户端。
- 所有非运行状态可删除，领取与删除的事务竞争不允许删除已经运行的任务；取消中的本机工作器先退出再清理。
- 未发布重构代、候选、检查点及向量清理；缓存清理失败时保留任务可重试。原始记录、活动代、有效来源链、已提交治理、笔记与短期摘要保留。
- 合成评估器可以识别同一输入的无效候选与重生成链，不将多次调用误报为单次成功；输出合法仍不代表语义正确。

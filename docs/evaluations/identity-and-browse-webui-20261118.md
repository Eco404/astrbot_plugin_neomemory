# 账号关联管理与浏览界面验证

## 范围

验证逻辑用户命名、唯一账号归属、二次确认、单账号原身份清理、多账号共享记忆保留、解绑后独立身份及原文边界；同时验证即时筛选、悬浮分页、刷新图标和笔记布局。采用独立合成数据、临时SQLite数据库和浏览器，不调用真实模型，不使用私人样本调优，未修改实机账号或记忆。

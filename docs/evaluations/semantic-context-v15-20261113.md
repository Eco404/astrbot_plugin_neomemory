# 当前提示词的旧事件、情绪与索引验证

验证日期：2026-11-13。对象为 `extraction-prompt.v15 / extraction.v5 / reference.v2`、memory.db v12，宿主源码 AstrBot v4.29.3。脚本为 [verify_semantic_context_api.py](../../scripts/verify_semantic_context_api.py)，本地原始证据保存在 `data/evaluations/semantic-context-v15-20261113/`。

## 方法与边界

使用脚本预先固定的独立合成输入：一月陶艺杯子事件与12条后续无关经历，候选上限6。第一个窗口补充杯子烧好并取回，第二个窗口明确另一时间的课程和未烧制的小碗。审阅要求在调用前固定为旧事件续写、相似新事件分离、完成状态、情绪主体、标题与正文一致。没有使用私人会话调优，也没有更改输入以追求通过。

每窗经真实向量候选选择、LLM抽取、引用回译、事务提交和新版本向量读回；相同输入再查询一次，检查热缓存复用。最后通过 RecallService 的主动语义路径查询旧杯子。该路径没有调用宿主工具及笔记合流，工具最终封套另有工程测试；本报告不将内部服务调用写成完整模型工具使用验收。

## 结果

模型为 gpt-6-luna。实际2次LLM HTTP、6次Embedding HTTP，无自动或人工重试、重生成、输出修改。两个窗口均提交成功，变化节点均已索引。

完整输出审阅结果：

- 第一窗更新原杯子事件，保留一月课程与十一月烧制、取回状态；标题为“陶艺杯子烧制完成并取回”。情绪为 joy / 0.6，说明明确属于表达高兴的成员。
- 第二窗创建独立小碗课程事件并关联旧杯子事件，保持小碗“尚未烧制”；无明确情绪时输出 null。没有把新课合并成旧课，也没有反转杯子的完成状态。
- 两个正文直接叙述，没有“我记得”包装，没有把对方动作写成人格亲自做过；存储保留稳定用户引用，召回渲染为当前昵称。
- 旧杯子排在召回首位，返回其完整情绪；共返回6条，另一次陶艺课相关，其余4条日常经历较弱相关。未根据这一小样本调整相似度或条数门限。

v15 对 v14 的必要改动是覆盖规则按正文或规范化情绪计算内容版本，标签换序不计变化；历史模板保持原样。本样例没有产生 coverage_changes，因此不能证明模型能正确判断情绪完整覆盖。模板合同与情绪单改的版本、事务回滚由 [协议测试](../../tests/test_emotion_extraction.py) 和 [覆盖测试](../../tests/test_emotion_coverage.py) 单独验证。

## 尚未证明

仅一个LLM、一个空间、13条预置事件及两个新窗口，不代表大空间冷缓存、多人持续聊天、不同模型或长链关系连续性。两次热查询耗时是本环境观测值，不是性能保证。节点情绪强弱仍是粗粒度描述，0.6并非已校准心理量表。既有关系对象/时间歧义与称呼限定漂移未由本样例关闭。

后台抽取全空间分页与主动召回默认2000节点快照是不同边界。当前结果再次暴露弱相关噪声，应在独立、多问法评估中区分向量匹配、阈值、邻居、预算和最终条数的影响。

# 完整构建基线：主题语义审阅

## 范围与证据

`stable-basis-full-20261118` 的完整实机构建已成功发布。本报告按运行前冻结的 `semantic-audit.v1` 计划审阅全部 6 个当前主题、18 个主题正文版本，以及当前全部 119 条成员关联所涉及的 107 个不同成员。基线使用 extraction-prompt.v30 / extraction.v7 / recovery.v6，不代表后续提示词与恢复协议的验证效果。

逐项阅读主题与当前成员正文，核对历史成员增减、主题版本及来源继承，并针对主题主要事实、人物归属和时间表达追溯相关原文。递归来源清单包含 228 条版本记录、1226 条原始记录；这是结构清单，不能理解为其中每条原文或每个历史成员事实都完成了独立穷尽的真实性判定。私有逐项结论、版本键、来源键与成员变更保存在本运行的 `semantic-review/topics-review.json`。审阅没有调用模型或修改样本与实机。

主题应组织持续关联的多项记忆；仅有多个成员 ID 不证明存在独立经历。人格主观感受允许保留，但这不免除正文中的事实、时间和人物归属要求。成员数量较多也不能单独构成主题过宽的判据。

## 需要区分的问题

**主题数量与组织质量是两回事。** 本次已经生成主题，且当前依赖不存在待刷新状态，但仍出现普通抽取生成零成员主题，以及同一事件的两个存储层被当成独立主题依据。前者没有组织成员，后者满足数量要求却不满足语义独立性。不能通过增加主题数量或进一步合并事件来解决这两类问题。

**时间概括会引入来源没有支持的规律。** 一项当前主题把有限时期的频次改写为稳定周期习惯，相关成员及原文仍保留时间范围。主题抽象层可以省略细节，但不应强化频率或持续性。这为已知的时间限定漂移机制增加了本次构建证据。

**历史无效正文曾成功入库，后来被正常更新替换。** 一个主题的首版正文只有无叙述意义的字段词，后续两个版本已形成完整叙述。它是历史内容质量失败，不是当前正文仍为空，也不能算作校验器自动纠错。非空字符串及合法依赖只能证明结构通过，不能证明内容有效。

归因核对已找到与首版提交回执一致的冻结输入窗口，但该快照没有成功响应正文；本次拒绝候选档案也没有相同输入摘要或回执，任务成功后的检查点已经清空。冻结安装包中的路径为提供商 `completion_text` 原样返回、JSON/schema 解析、读取 `content` 字段并去除首尾空白后写入版本表。该路径没有把一段正文改成字段名的处理，未发现这类应用变换错误；但缺少当次成功响应及更上游的原始响应，不能进一步确定无意义字段词由模型还是宿主提供商产生。已有提交摘要也不能逆推出原始响应。独立验证应分别核对响应到落库的文本保真，以及结构合法但语义无效的候选处理，不能按本次具体字段词增加特例。

**成员增减与低价值重写需要继续观察。** 一个较宽主题在一次更新中移除 18 个成员、加入 8 个成员，之后部分未改变版本的成员重新加入。成员变更本身允许发生，但现有证据没有充分解释这些边界调整，不能把每次移除都判为错误。另一个主题有一次正文基本只改变标点的更新，可作为低价值重写证据，不能据此推断全部主题更新无效。

**宽主题尚不能直接判废。** 最大主题有原文支持的共同互动模式，其成员多不等于错误；不过部分事实成员与主题的具体关联偏弱，且与较窄主题及人格关系存在重叠。此外，一个较窄主题纳入了仅有相似状态、活动背景却不同的成员，关联依据不足。这些问题应通过独立语义审阅与实际检索收益确认，不能按本样本设定新的硬性成员数上限。

## 验证边界与后续用途

本次证据支持继续检查主题生成入口的一致性、成员语义独立性、限定条件保留、正文有效性，以及主题成员增减与召回收益。相应改进应依据公开资料或独立合成案例研究验证；不得复制本样本事实、措辞或成员分布形成专用规则。

本报告没有证明主题参与召回后必然改善回答，也没有穷尽每个递归来源的全部事实。材料来自固定人格与用户、已用于此前评估的有限私人会话，不是留出集。结构完整、全部主题均已阅读和语义质量可靠是三个不同结论，应分别报告。

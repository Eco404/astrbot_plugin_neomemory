# 正常叙述候选提示词评估

日期：2026-11-12。当前生产仍使用 `extraction-prompt.v7` / `extraction.v2`；本次评估的候选为 `extraction-prompt.v9` / `extraction.v2`。v9只改变正文叙述规则和抽取前的事实处理顺序，没有新增数据库字段或改变生产默认。

本次候选落实了[ADR-0028](../adr/0028-normal-memory-narrative.md)：长期节点和画像直接表达事实、经历或资料，不加入“我记得”“我提过”“我们之前说过”等记忆管理话语；人格关系仍使用第一人称主观表达；元信息承担类型、来源、时间、版本、状态和渲染职责。正文仍必须保留主体、当前状态、条件、否定和不确定性。

## 评估材料和方法

输入沿用已经冻结的8组独立虚构合成材料，包含条件/否定/转述、主体归属、不同事件、同一事件更新、关系提议、关系接受、单次观察画像和明确画像偏好。没有读取实机私人会话、现用人格或真实运行数据库来制作夹具。

每个场景使用独立 source/memory 数据库和同一份语义输入。首次完整探针最多8次HTTP；发现候选仍可能生成未列举情绪标签和关系中的记忆管理话语后，收紧规则并重新运行8个场景，再针对关系接受场景做1次最终检查。每次最多1次HTTP，宿主尝试1次，SDK重试0次，没有自动纠正循环。最终检查只复测关系接受场景，因此不能把它当作8个场景都在最后一版规则下重新运行的证据。

固定夹具 SHA256：`04ac496f55fe9c5b511cd5e5cde1f79d9840f01a0b54f38680bb03b320d815c0`。

## 结果

| 运行 | HTTP | 结构通过 | 观察 |
| --- | ---: | ---: | --- |
| 初次 v9 | 8 | 7/8 | 关系提议场景使用未列举的 `curiosity` 情绪标签，正确被 schema 拒绝；其他候选保存成功 |
| 规则收紧后的 v9 | 8 | 8/8 | 关系状态、主体、事件更新和正常叙述候选均可保存 |
| 最终关系接受复测 | 1 | 1/1 | 关系正文使用占位符，无“我记得/我会记得”等记忆管理话语 |

规则收紧包括：关系正文也禁止记忆管理话语；已知逻辑用户使用占位符而不是未绑定的“你”；情绪标签只能逐字使用既有枚举。

收紧后的8个候选中：

- 条件、否定和转述不确定性均保留，例如“只有在设备验收合格后才会报名”“可能由受潮造成，但尚未查明”；
- 用户、Agent和第三方动作主体在抽样结果中保持区分，用户的动作使用逻辑用户占位符；
- 不同日期的两场课程生成独立事件；同一工单的后续进展更新原事件，并清理“等待配件”的当前状态；
- 用户明确接受但尚未执行的安排保留“尚未进行”，没有写成已完成；仅有 Agent 提议和用户追问的场景没有写成已接受；
- 单次临时主持行为没有写入稳定画像，模型选择 `no_change`，这属于选择性抽取的合法结果，不计为画像生成能力通过；
- 明确的新偏好会生成直接叙述的原子和画像，且保留原有陶艺信息；
- 收紧后的完整运行中，生成正文不再使用“我记得”作为事实包装；关系接受场景的最终复测在进一步收紧关系规则后，也未出现“我记得”“我会记得”“我知道”等表达。最后一条只由该场景复测支持，不能外推到其余7个场景。

这些是固定8个场景的一次或两次真实模型输出审阅，不是全库准确率。关系和画像的语义判断仍需人工审阅，`extraction.v2` 没有保存事件状态、互动状态和画像证据枚举，因此不能仅凭这些输出证明所有状态判断稳定。

## 成本

收紧规则后的8次运行平均系统提示词正文约21,432字节，平均JSON请求体约22,775字节，输入 token 合计43,700，输出 token合计1,935。生产v7的既有对照为平均提示词20,436字节、输入token合计42,011；v9提示词正文约增加4.9%，输入token约增加4.0%。v9明显小于增加完整证据声明的v8（既有对照平均提示词25,648字节）。本次没有增加模型调用次数。

## 当前结论

v9已证明正常叙述规则可以在不改变 `extraction.v2` 和调用次数的情况下工作，并改善了本次独立材料中的正文风格、主体表述和事件状态表达。它还没有达到生产替换门槛，原因是：

1. 只有一个模型、少量独立场景和有限重复运行；
2. v9仍没有结构化保存事件状态、互动确认和画像依据，不能替代v8/v3的审阅声明；
3. 直接来源充分性、跨节点依赖、错误 `full` 覆盖和自然问题召回尚未在本轮重新验证；
4. 第一次运行出现非法情绪标签，虽然规则收紧后复测通过，但说明模型仍需重复运行观察稳定性。

因此暂时保留：v7/v2为生产默认，v9为正常叙述候选，v8/v3为证据声明候选。下一步应在同一批独立材料上重复v9，并与v7、v8/v3分别比较主体、状态、限定、直接引文、文本风格、召回相关性和成本；达到质量门槛后再安排实机候选重构。

# 召回预算优化计划

## 目标

在现有总预算与完整条目约束内，减少固定分区和先后装配导致的无谓省略。长期正文、画像、关系、短期摘要均按昵称渲染后的完整文本计量；不增加前台生成调用，不改变向量排序、覆盖省略、节点数量或强化规则。

## 计量与选择

- 保留现有UTF-8字节计量及4096默认上限，配置界面明确显示字节，不将其称为模型精确token数。既有配置键 `recall_budget_tokens` 为兼容继续保留，不迁移用户数值。
- 辅助资料与长期记忆共享同一个总预算，不设固定分区；核验最终完整文本，包含标签、JSON转义、分隔符和昵称展开。
- `context_budget_priority=recall_first`：默认先保留排序中第一条可以完整容纳的长期命中，再尝试短期摘要、画像、关系，其后尝试其他长期命中，最后添加活跃笔记工具提示。
- `context_budget_priority=context_first`：先尝试短期摘要、画像、关系，再尝试长期命中，最后添加笔记提示。用于用户明确更看重连续性和关系资料的场景。
- `context_entry_order` 独立配置辅助资料的尝试顺序：默认摘要→画像→关系，也可以选择画像→摘要→关系或关系→摘要→画像。它不改变长期优先策略保留首条命中的规则，单项超过总预算时调整顺序无效。
- 预算不足时省略整个条目，继续尝试后续更小条目。单项字符上限与各功能开关继续独立生效；关闭向量召回时本地资料可以使用全部预算。
- 选择优先级与最终展示顺序分离，展示仍由完整的辅助资料块和长期记忆块组成。只有最终注入节点获得强化。
- 维护页按空间ID、装配标识和时间展示全局最近装配的占用与省略原因；逐项内容及昵称不进入诊断。运行中保存顺序即时生效，默认预算与优先级不随新选项改变。

## 实施与验证

1. 核对当前ADR与已有开源实现的预算方法，明确模型通用精确计数不可假定。
2. 冻结独立合成矩阵，记录原实现的预算、各类条目与主命中入选情况。材料覆盖中文、英文、混合文本、昵称展开、不同长度与预算；不读取受限真实会话。
3. 实现共同预算与可调优先级，同步高级设置、即时应用及诊断。
4. 验证完整文本不截断、最终预算不超限、无命中/禁用/超长条目、昵称变化，以及实际宿主临时注入、强化和历史过滤。
5. 使用相同矩阵比较变化，报告主命中收益与辅助资料挤出代价；不能把确定性装配结果当成自然问题召回率或模型语义质量。
6. 通过相关与全量回归、页面验证、打包检查后提交；将尚未解决的token利用率、覆盖语义及实机聊天评估明确保留。

## 完成条件

最终上下文受单一明确单位的预算约束；默认不会由辅助资料挤出本可单独容纳的首个有效长期命中；用户可选择辅助资料优先；原始内容、节点正文和数据库版本不改变；所有省略仍可诊断，运行中保存配置即可应用。

## 方法与复现

环境为 Conda `astrbot`、AstrBot v4.29.3（`abf683071`），通过真实宿主 `ProviderOpenAIOfficial` 调用已提供的 `gpt-6-luna`。仅发送脚本内合成角色说明与会话，不发送真实聊天或本地角色卡。数据库在临时目录内建立，运行结束清除；不保存密钥、端点、模型原文或异常正文。

```bash
PYTHONPATH=/workspace/astrbot/AstrBot:/workspace/astrbot/astrbot_plugin_neomemory \
  /home/coder/apps/miniconda3/envs/astrbot/bin/python \
  scripts/verify_context_api.py --only extraction --http-budget 6
```

脚本使用生产提示词、schema、持久任务、来源检查和正式提交路径。任务最多尝试一次，SDK 重试关闭，实际 HTTP 请求数由 hook 限制为最多 6 次；本次仅用 3 次。脚本任务截止为 90 秒，插件默认配置仍为 60 秒。

三个任务均在第一次执行后 `succeeded`，全部预定检查通过，脚本退出码为 0。三个模型调用耗时均小于默认 60 秒，但本次实际执行使用 90 秒截止，不能据此推断默认配置下的长期稳定成功率。

# 阶段六有界规模评估

日期：2026-10-29 UTC。评估脚本：[benchmark_console.py](../scripts/benchmark_console.py)。

本次使用真实 `MemoryStore`、`CacheStore`、`ProviderAdapter`、`EmbeddingService`、`RecallService` 和 `ConsoleStore`，在临时数据库中执行。向量来自明确标注的离线合成 Provider：依据文本哈希生成固定随机数，**没有语义能力，不联网，不读取密钥或用户原文**。本报告测量本地管线开销与边界，不能用来证明真实模型的召回质量或网络延迟。

## 复现

```bash
cd /workspace/astrbot/astrbot_plugin_neomemory
PYTHONPATH=/workspace/astrbot/AstrBot:/workspace/astrbot/astrbot_plugin_neomemory \
  /home/coder/apps/miniconda3/envs/astrbot/bin/python scripts/benchmark_console.py
```

脚本输出 JSON，包含环境、全部延迟样本、量化结果、诊断与文件字节数。临时数据库退出后自动删除。可调整 `--nodes`、`--spaces`、`--dimension`、`--repetitions`；没有修改生产快照上限、召回预算或默认截止时间。默认运行约 13.46 秒，包含数据构造。

脚本自检：大空间确实超过 2,000 节点；共享快照边界正确且主动/被动候选一致；冷缓存前台没有向量调用；后台只索引边界内节点；热轮次复用向量；筛选先于分页、查询结果空间正确。性能数据包含波动，不用固定毫秒阈值代替边界断言。

## 结果

分位数采用 nearest-rank。10 个样本的 P95 等于该组最大值，统计置信度有限。

| 测量 | 样本数 | P50 | P95 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 冷向量缓存前台召回 | 10 | 35.52 ms | 42.42 ms | 0 命中、0 Provider 调用；不在前台补齐节点索引 |
| 热向量缓存召回，当前 + 10 条历史 | 10 | 820.54 ms | 864.93 ms | 每轮 5 个最终节点；0 新 Provider 调用；未触发 1.5 秒截止 |
| 2,100 节点空间：正文字面搜索 + active 筛选 + 第 2 页 | 10 | 2.63 ms | 3.70 ms | 每页 20 条，条件均满足 |
| 24 个小空间：字面搜索后取第 2 页 | 240 | 0.211 ms | 0.254 ms | 每页 2 条，无跨空间结果 |

单次冷后台索引：**2.477 秒**，125 个合成 Provider 批次，2,000 个节点向量。此时间包含合成向量生成、生产适配层校验、序列化和 SQLite 写入，但完全不含真实网络推理，因此不能据此预估真实 Provider 的索引时间。

数据构造耗时 1.313 秒。共享快照实际返回 2,000 个 active/historical 节点并设置 `truncated=true`；被动召回再从其中排除历史节点，剩 1,500 个 active 节点。完整共享快照编码为 JSON 约 1,890,198 字节。

## 对当前阶段的结论与边界

1. WebUI 查询在本次有界样本中开销较低；正文 `instr` 字面筛选确实先于分页，不会先截取一页再漏掉后方匹配。当前仍是数据库扫描筛选，本结果不能推导到任意大的库。
2. 冷缓存前台按设计返回可用的空召回，等待后台建立索引。生产默认的 2,000 节点上限已被实际触发，**大空间剩余 100 个节点不会进入本次向量候选**；historical 节点也占共享上限。增加节点不会自动扩大候选范围。
3. 热缓存消除了本次 Provider 请求，但 768 维、1,500 个 active 候选、11 个查询向量下仍约 0.82–0.86 秒。每轮读取 JSON 向量、校验/归一化及矩阵评分仍有开销；本次未做阶段级 profiling，不能把全部耗时归于某一函数。后续性能优化应先定位这些阶段，并继续保留总截止时间。
4. 本次没有图邻域、密集覆盖关系、长正文、高并发请求、持续写锁、跨进程竞争或低配硬件，也没有测浏览器渲染/HTTP 往返。不能把这里的 P95 当成线上响应保证。
5. 不能声明无限扩展，也不能声明语义质量已验证。本阶段保留现有有界检索策略；更大空间的候选筛选、向量表示/索引成本、不同硬件和真实 Provider 的测试属于后续性能评估。

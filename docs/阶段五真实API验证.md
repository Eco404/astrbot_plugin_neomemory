## 真实调用与隔离范围

使用宿主真实 `ProviderOpenAIOfficial`、`Context.llm_generate`、`OpenAIEmbeddingProvider`，通过插件 `MemoryRuntime`、`ProviderAdapter` 与 `MaintenanceEngine` 执行。LLM 为 `gpt-6-luna`，Embedding 为 `@cf/baai/bge-m3`，此次直连成功，未使用代理。

脚本只替换 Context 的 Provider 注册表与人格加载入口，以便脱离完整消息平台启动；模型客户端、HTTP 调用、原始记录存储、任务扫描器、后台工作任务、来源消费账本、严格抽取提交、重构及代切换均使用生产实现。脚本没有直接调用任务处理函数，也没有把模型输出替换成预设结果。

输入为 5 条合成的摄影课程会话及简短合成人格，没有发送角色卡或真实聊天。`ASTRBOT_ROOT`、`source.db`、`memory.db`、`cache.db` 均位于独立临时目录，退出后删除，不修改正式数据库或宿主配置。凭据从被 Git 忽略的 `docs/api_key.md` 读入；报告与脚本不包含密钥、账户标识、Provider 地址、原始响应或异常正文。

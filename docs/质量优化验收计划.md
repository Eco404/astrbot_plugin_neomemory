# 记忆质量优化与验收

> 开发期专项计划。文中的版本号、部署与验收记录对应当时的评估。正式版规范见[文档索引](README.md)。

## 目标与有效边界

画像准确表达逻辑用户的当前资料，长期节点在更新中保持主体、状态、限定、时序和情绪；人格关系在紧凑篇幅内表达重要内心层次及变化连续性，允许主观自主判断。新生成长期理解/近期余韵分别最多500/150可读字符，以减少关系在整体记忆中的篇幅；心理内容丰富不等于事实流水账，更短也不自动等于语义更好。不设最低字数、固定心理栏目、正向情绪目标或每窗更新要求。

候选采用同一次联合抽取，不增加被动生成调用、画像事实表、动态情感窗口或衰减库。既有节点、画像和完整关系状态存储合同保持。宿主输入截断按既定决定后置。默认3次有界候选纠正已实现，范围见[恢复合同](adr/0037-bounded-candidate-recovery.md)；其自然恢复率与语义保持仍需验证。局部画像编辑和独立召回摘要未启用，不能随提示词改动自动接入。

## 工作与退出条件

| 工作 | 验证方式 | 完成条件 |
| --- | --- | --- |
| 画像归因与当前状态 | 独立连续输入，分别核对实际持有者、状态更新和未受影响的限定 | 报告基线及候选逐窗结果、错误继承与选择遗漏，不用来源ID合法代替语义判断 |
| 长期节点更新 | 同一事件的历史及当前状态、条件、标题、情绪独立核验 | 不把旧否定并列为当前事实，不扩大许可或改变局部时序；保留失败而非重跑到成功 |
| 心理整合与连续性 | 独立人格的重复互动、无关闲聊、重要转折和长间隔连续链，使用各版本真实提交前态 | 核对意义保留、合理keep、转折承接、主体与重复累积；同时报告篇幅和注入占用，不按更短直接评优 |
| 详细内容装配 | 固定独立资料与问题所需信息，对预算及顺序做矩阵 | 明确单项上限、总预算、竞争省略，比较必需信息可达性；不把装配成功称为回答质量 |
| 默认选择与兼容 | 真实模型结果、schema、事务、版本身份和工程回归 | 按整体收益、错误影响和频率采用；少量低影响瑕疵可进入试用，明显错归属或错误合并优先处理；旧显式版本可回放 |
| 交付复核 | 当前规范、研究和独立报告、代码及本地Git提交 | 说明已改善、未解决和未测试内容；实机部署与本地验证分别陈述 |

## 方法与资料依据

画像和当前事实参考[画像轻量更新研究](画像轻量更新方案研究.md)及[抽取保真研究](抽取保真改进轮次参考研究.md)已经核验的Hermes与Graphiti实现：区分记忆用途、选择是否更新、明确事实互斥而非仅依据新近性。精确片段修改仅能保护修改范围外文本，不解决归因和漏更新，本轮不直接启用。

人格关系参考[心理承接研究](research/relationship-affect-dynamics.md)与[自主表达合同](adr/0034-relationship-affect-autonomy.md)：完整前态承接心理意义，允许重组、淡化及复杂感受。详细表达基于人格对真实互动的理解，不靠虚构客观行为扩写。预算参考[已有顺序对照](evaluations/context-order-20261116.md)，继续整体注入、明确UTF-8字节单位与可配置取舍。

公开项目的设计不等于本插件效果证明。真实模型调用前冻结独立材料、判据、模型、版本和调用上限，保存候选与错误；不向被测模型提供评估答案。每条链使用自己实际生成的前态，失败后不手工补成理想前态。结构、语义及消耗分别统计，小样本不宣称普遍可靠。

用户私人会话仅用于受限评估，不用于改提示词、参数、规则或派生专用题库；已见样本不能作为未见留出。实机隔离模型实验不写现用记忆库，不发送平台消息，也不代表完整平台连续使用验收。

## 当前采用状态与剩余工作

当前默认采用extraction-prompt.v41 / extraction.v9、topic-prompt.v10 / topic-consolidation.v2、candidate-regeneration.v8与memory.db v22；实机部署及完整构建状态统一见[部署基线](evaluations/live-full-0c84538-20261119.md)。当前输入包含逐来源UTC观察时间、旧状态版本观察锚点与可见成员结构，保留画像职责、显式旧节点依据和正文自足要求。人格关系采用[紧凑心理整合](adr/0055-compact-relationship-consolidation.md)与双段联合抽取，[独立对照](evaluations/relationship-minimal-rules-20261118.md)未观察到明显连续性退化，但没有根治摘要感。紧凑表达应保留仍有影响的感受、矛盾和必要缘由，不以更短替代主体、条件、事件身份、心理深度及旧状态整合的验收。旧长段保留兼容，新生成上限不自动截断或重写已存状态。

画像职责v27已按[实际质量验收决定](adr/0038-profile-duties-and-practical-quality.md)采用，少量概括瑕疵不单独阻止试用。后台候选采用context.v2，节点操作v28仍仅显式实验；首轮结构失败与自动纠正后的结果分别保留，证据及下一步见[专项计划](画像职责与候选覆盖计划.md)。

优先验证明确来源的情绪主体、时间及限定保留，继而用独立稀疏长链检查心理整合。简约规则已在联合抽取中采用，不将模型其他字段变化直接解释为已证实的任务竞争。若采用额外关系调用，需先明确成本、来源共享和联合提交语义；共享预算已按用户决定采用15000 UTF-8字节，继续验证实际注入、回答效果与资源消耗。

[分项语义对照](evaluations/quality-continuity-20261118.md)未支持将额外同义规则加入默认；[关系任务隔离](evaluations/relationship-context-isolation-20261118.md)有局部收益，但可配置独立生成仍待决定。共享预算默认15000 UTF-8字节，见[预算决定](adr/0047-context-budget-15000.md)，已有用户配置不自动覆盖；[4096预算回答对照](evaluations/quality-budget-answers-20261118.md)仅保留其对应条件下的证据，不能直接证明当前预算的回答收益；[full剩余预算补回](evaluations/coverage-consumption-20261118.md)仍为未采用候选。字段恢复、语义正确、完整实机构建和最终回答利用分别验收，不以其中一项通过替代其余项目。

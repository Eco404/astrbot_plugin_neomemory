# 阶段二执行记录：派生节点与基础记忆库

> 开始：2026-10-28  
> 状态：已完成实现与退出验证

## 已完成

- 新增 `memory.db` 独立迁移 v1，启用 WAL、外键、唯一 active generation 和必要索引。
- 实现私聊 `persona × logical_user`、群聊 `persona × platform_instance × group` 空间键。
- 实现 generation 创建、父代记录和原子激活切换；失败 generation 不影响旧 active generation。
- 实现 `atomic/event/topic` 节点、正文版本、重要性、强度、事件时间、状态和人工保护。
- 实现来源引用、参与者、关系边和事件覆盖；关系端点严格限制在同一空间和 generation。
- 实现用户画像、人格关系、短期状态和不随 generation 删除的笔记最小接口。
- 为阶段一 `SourceStore` 增加 `has_source` 校验入口，验证派生节点不能引用不存在的 `source_id`。
- 新增空间、节点、版本、来源、状态、generation、关系、画像、笔记和并发测试。

## 关键边界

- 阶段二没有调用 LLM、Embedding，也没有实现自动抽取、召回、衰减和后台任务。
- 节点正文变化创建新版本并把强度重置为新的重要性；只增加来源或关系不会创建正文版本。
- 删除节点采用 `deleted` 状态，原始 `source.db` 保持不变。
- `notes` 不绑定 generation，后续重构不会自动删除自主笔记。

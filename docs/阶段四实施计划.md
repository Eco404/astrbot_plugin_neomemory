# 阶段四实施计划：Provider、向量缓存、召回与主动工具

日期：2026-10-29（北京时间）。状态：已完成；验证与复核见[阶段四执行记录](阶段四执行记录.md)。前置基线为阶段三 149项离线测试；宿主固定 AstrBot v4.29.3。用户的未提交 `.gitignore` 修改保留，功能验证后分批 commit。

## 目标与范围

让已抽取记忆能够在实际 AstrBot 请求前按空间安全召回，以完整、预算受限的段落参与回答；模型可主动检索历史记忆和使用独立笔记。接入 AstrBot 已配置的 Provider，不复制密钥，不把真实模型输出直接当作数据库操作。

本阶段实现可调用的 Provider抽取适配和隔离真实回放，不开启无任务保障的全自动抽取。后台持久任务/失败队列/人工治理在阶段五，完整五栏页面在阶段六；本阶段只增加已实现设置、Provider安全列表及诊断 API。

## 默认参数与资源约束

- LLM并发2，Embedding并发2，Embedding batch size16；独立配置。LLM适配器不另包重试循环，沿用宿主Provider/SDK重试并限制总截止时间；任务级重试留阶段五。
- 历史补查最近7200秒、最多10条，同一conversation与人格；user权重0.45，agent权重0.40；当前查询权重1。时间戳来自source.db，不猜测宿主没有时间戳的文本历史；取得宿主conversation ID时额外按ID隔离，旧未知记录不混入。
- 被动截止暂定1500ms，主动查询5000ms；全部包含排队和检索。单次每查询候选8，最终节点最多6，一层邻居最多2；时间邻域暂定±86400秒，仅使用事件发生时间。
- 注入预算暂定2048保守token单位，以UTF-8字节上界计量整个块；不截断正文破坏条件、否定或指代。放不下整个节点时跳过，保留较短候选；真实模型调优后可改默认。
- 首版采用按空间、按当前代的精确余弦匹配，最多2000节点；超过时显式报告截断，默认按重要性和更新时间取有界集合。ANN索引扩展以后按真实规模评估。
- 缓存仅hash与向量，message/node分类型TTL及条数上限。缓存可清空；模型指纹包括模型、Provider、维度、非密钥配置摘要和显式revision。向量非法/维度变化拒绝，不混算。

## 冷索引与截止时间

查询不为整个记忆库临时向量化。后台显式index_space补建当前空间的缺失节点向量，按相同batch/并发限额执行；在线召回只用已缓存的当前版本向量。空索引本轮可不注入，并启动受限后台补建，后续请求使用可用结果。后台工作不依赖浏览器，退出时取消/收束；其检查点就是可再生缓存，不替代阶段五正式任务管理。

当前和未命中历史一次批量Embedding；已有当前向量在补充批次超时后仍可使用。网络错误只让当前召回降级，原始采集和主链继续。缓存坏数据不得污染memory.db。

## 候选、组织、覆盖

每查询取少量候选，分数先按角色权重合并，同节点仅一次；命中当前查询的候选排在仅历史命中的候选前，再按相似度及小幅强度因素排序。对少数直接候选扩展一层关系或时间邻居，区分“相关经历”“同期经历”；时间接近绝不写成因果。

事件/原子均可直接召回，主题也允许命中但不展开整棵图。已选且能实际放进预算的事件才可以抑制其full覆盖原子，覆盖须同时匹配事件和原子的当前正文版本；partial、过期coverage、仅contains都不能抑制。输出采用内部连贯的独立段落和必要的类型/时间标签，无生成模型润色。

注入前再次验证空间、活动代、节点版本和状态。仅最终注入/工具实际返回节点强化；同轮重复、冷却期和批量总增益有上限。强化不改变历史状态，不篡改正文更新时间和衰减重置时刻。

## 宿主与工具

Persona解析沿用宿主实际选择规则并保持原始写入与召回同源；无法确定时不猜。私聊使用人格×逻辑用户，群聊使用人格×平台实例×群组。工具只能使用当前事件空间，不能接受任意space_id或逻辑用户作为参数。

主动回忆允许历史节点，仍排除禁用/已删除/已替代节点。笔记支持创建、当前空间查询、修改、归档/恢复；笔记不走自动长期节点抽取，来源可追溯本轮事件。工具错误返回简短状态，不回传Provider错误正文或密钥。

注入使用宿主标记为临时的内容块，避免进入永久会话造成下轮自我强化；同请求重复hook替换自己的块，不通过字符串正则删除用户内容。

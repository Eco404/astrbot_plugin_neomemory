# 开发探索归档

| 探索 | 尝试与取舍 |
| --- | --- |
| 经历与主题 | 尝试通过放宽合并减少列表中的碎片。回查原文和事件后，保留了单次经历的粒度，另以主题整理相关事件，并保存成员与版本依据。 |
| 画像与人格关系 | 对照轻量画像、逐窗改写和带权历史背景。画像聚焦本人且可复用的特征。参考 LivingMemory 的主观记忆表达，将人格关系分为长期理解和近期余韵，让短期摘要承接近况。 |
| 人格视角与来源 | 对照客观摘要与人格直接叙述。群聊和转发暴露出发言者、提及对象与原作者混淆的问题，抽取输入逐一标明角色。观察时间及直接、继承来源用于核对正文。 |
| 图片 | 在私聊合成对话中比较不同分辨率、张数和输入顺序。相似图片逆序时观察到归属错位。正式版按消息顺序附图并标明发送者，抽取后保留文字依据供重构。 |
| 召回 | 对照扩大候选、调整门限、补充近期查询和整条预算分配。有依据的问题可能漏召，无依据的问题也可能返回弱相关结果，因此分别评估候选覆盖和最终注入的支持程度。 |
| 恢复 | 实机回放暴露出格式错误、超时和人工重新生成的成本。采用固定输入、有界自动纠正、持久检查点与事务回执。宿主截断输入的问题完成了隔离探索，宿主改动留待单独决策。 |

开发中使用过独立合成案例、模型对照、故障注入和受限实机会话回放。固定用户和人格的私聊样本只支持该场景的观察。当前验收事项见[开发路线](后续开发路线.md)。

# 画像质量轮次实施计划

日期：2026-10-30。承接稳定性轮次的唯一明确语义缺口：偏好修正后旧词仍出现，但没有保留合成输出，无法区分正确否定、历史混入、错误当前事实和规则误判。上轮第二次修正因词法检查失败而跳过，不是插件无法继续执行。

状态：Q1–Q5已完成，结果与新发现的限定语缩减问题见[执行记录与复核](画像质量轮次执行记录.md)。真实调用8次；未提前开展下一轮条件保留实验。

## 目标和固定边界

1. 建立可审阅的合成证据，输入、画像描述、标签、长期节点分别记录，不再把文本拼接后仅输出布尔值。
2. 在正式后台任务、来源校验和事务路径上完成连续两次偏好修正；结构成功即可继续下一窗口，语义问题仍完整保留。
3. 验证当前画像替换、长期变化历程、群成员归属和低价值丢弃。当前明确否定允许保留，不能靠删除所有旧关键词通过。
4. 先研究已有实现并记录采用理由；只有实际输出证明提示词不足时才修改生产提示词并升级版本。

不改画像/节点数据模型、召回策略和数据库版本；不纳入导入导出、原始库清理、完整宿主Vue部署、规模索引或自主活动。用户未提交的 `.gitignore` 保持原状。

| 子阶段 | 内容 | 达到的目标 |
| --- | --- | --- |
| Q1 研究与标准 | 阅读Graphiti、Hermes、MemoryOS实现和相关论文，记录版本、许可、适用差异；明确分类标准 | 有依据地选用显式当前态、证据与更新规则，不照搬重型画像或文本替换 |
| Q2 证据工具 | 扩展隔离回放；逐窗口保留输入、前后画像和节点；描述/标签分开；保存提示词版本、结构状态、请求数及散列 | 失败也可审阅；词法筛查不充当最终语义结论；浏览器与生产数据库均不参与 |
| Q3 有界实测 | 基线5个LLM窗口：寒暄、多人群聊、初始偏好、两次修正；审阅证据 | 第一次语义筛查失败不会阻止结构成功后的第二次修正 |

| Q5 回归与复核 | 相关测试、全量测试、静态检查、独立审查、真实结果记录、本地提交 | 明确已证实行为、剩余限制和是否有用户决策项 |

## 判定标准

画像是当前事实集合；长期节点可以叙述变化史。每个受检字段（description、单个tag、节点正文）按语境审阅：

| 分类 | 示例 | 当前画像处理 |
| --- | --- | --- |
| current_fact | 现在每天只喝乌龙茶 | 与最新直接证据一致才通过 |
| current_negative | 已戒咖啡／咖啡已停用 | 可以保留；不因包含旧词失败 |
| historical | 以前喝咖啡，现在喝茶 | 历程应放长期节点；当前画像不保留已替代的正面偏好 |
| incorrect_current_fact | 当前每天喝咖啡，也喝茶 | 与“现在只喝茶”冲突，不通过 |
| absent | 旧偏好没有出现 | 只证明未残留；仍需检查新偏好、其他有效事实 |
| uncertain | 无法可靠确定时间、主体或否定范围 | 待审阅，不能强行判为正确或错误 |

描述与标签必须分别检查；“不喝咖啡”的描述不能抵消“咖啡爱好者”的错误标签。仍成立的无关信息应保留。模型任务结构成功、词法筛查和语义审阅分别报告。群聊审阅说话者、假设、标签/长度；寒暄必须确认任务实际消费后没有派生内容。

## 证据和接口

- 扩展 `scripts/verify_stability_api.py`，保留旧模式，增加仅质量模式，避免无关Embedding消耗；每次实际HTTP由hook计数，关闭SDK重试，任务最多尝试一次。
- 新建评估辅助模块和离线审阅入口。证据只从该脚本自建的合成库导出白名单字段，不导出Provider配置、凭据、日志或生产数据。
- 使用显式 `--evidence-dir data/evaluations/<独立运行名>`；目录已存在则拒绝覆盖。每个窗口完成后立即写出，临时运行数据库仍在退出时删除。产物只本地保留，审阅结论和必要的合成短摘录写入开发记录。
- 审阅文件引用证据SHA-256，记录审阅人、逐项结论、分类和理由；旧证据不能套用新结论。未审阅及不确定均不计语义通过。
- 词法结果仅用于定位问题；不新增一个生成模型“裁判”，不把更多正则当作通用语义理解。

## 验证和退出条件

离线测试必须覆盖：标签与描述分离、结构失败不误算成功、前一语义问题不阻止连续链、跨用户字段选择、证据完整性、陈旧/不完整审阅拒绝、明确否定与历史/错误事实区分。

本轮真实HTTP累计上限8次：基线最多5次LLM，后续最多3次LLM，Embedding为0。默认60秒抽取截止，网络失败原样报告，不自动加预算；若基线发生结构失败，后续额度可用于最小复核并明确未验证范围。没有真实结果就不能声称模型质量通过。

完成可复查的三窗口依赖链、群聊和低价值证据；按证据调整或明确保留现有提示词；所有必要检查通过、执行记录说明剩余质量风险、每组功能独立提交，即可结束本目标。真实模型暴露的问题允许如实保留为后续项，不能以隐藏或删除失败结果达到退出条件。

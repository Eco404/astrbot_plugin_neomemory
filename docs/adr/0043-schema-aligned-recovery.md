# ADR-0043：抽取标准与有界纠正反馈对齐

状态：Accepted。扩展ADR-0037的候选错误分类与反馈；其持久额度、固定输入、事务校验及窗口期限保持有效。

## 决策

初次请求使用的JSON schema也是字段纠正反馈的约束来源。反馈不得另写一套数字上限。字段规则统一登记错误类型、反馈职责与自动纠正资格，具体类型、枚举、模式、字符串长度、可读长度、数组数量和数值上下限从对应schema字段读取。

可定位的字段错误包括缺字段、额外字段、错误类型、枚举/模式、字段长度、数组数量及数值范围。字符串与数组的`too_short/too_long`按schema实际类型解释，不能仅凭错误名字假定单位；长度反馈附实际编码字符、可读字符或数组项数，不回传正文。非空要求只允许来源支持的完整值，不能靠无意义填充或捏造事实通过。

已有明确标准的跨字段拒绝使用专用错误码，包括重复声明、result/reason与变化集合不一致、neutral情绪组合、覆盖自环，以及旧实验协议的事件元信息和直接/背景来源重叠。对应反馈说明同一标准，不将未分类`value_error`全部纳入自动纠正。重复声明的修复不允许合并不同经历或删除必要变化。

字段或数组超限与整份候选/请求容量超限分别处理。整体容量、输出不完整、输入变化、过期版本快照、租约、人工保护及未分类异常继续保留失败，不借字段纠正自动放行。校验成功不能证明事实、归属或覆盖语义正确。

反馈版本为`candidate-regeneration.v6`。已保存v1—v5重生成继续使用原反馈形状；新自动纠正使用v6。升级后普通重试可重新校验保存的失败草稿并使用剩余额度，不先丢弃草稿，不重置3次上限，不另加网络重试。schema版本及抽取提示词不因反馈升级而自动切换。

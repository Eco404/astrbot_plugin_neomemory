# ADR-0038：画像独立职责与实际质量验收

状态：Accepted。

## 决策

画像初建、新增与修正作为同一次联合抽取中的独立职责：是否已有长期节点不能代替是否需要画像的判断。明确且有持续用途的本人自述可以初建，不要求重复；新增资料保留无关有效旧信息，修正只影响相应部分，当前安排与未来生效安排区分。继续使用标签加短描述，不新增事实槽位、额外生成调用或独立画像数据库。

采用v27画像职责规则。长期正文仍使用人格自己的自然叙述，关系保留第一人称心理意义与自主判断；不把人格的主观看法当作客观用户资料。

质量采用依据整体收益、错误影响及出现频率，不要求模型输出完全准确。少量概括损失、非关键限定遗漏或偶发冗余可以保留记录后进入实际使用验证，不因单一低影响瑕疵否决有价值方案。主体错归、将未完成写成完成、错误事件合并、持续漏建或频繁人工恢复仍是优先修复问题；不能以平均指标掩盖明显高影响错误。

这项容忍度不改变数据合同。schema、来源、作用域、引用、版本、保护与事务校验保持；恢复仍使用已有3次有界纠正，不静默猜字段、丢弃失败窗口或用无变化替代失败。语义评估记录首次输出、自动纠正后输出与最终提交，分别统计，不把修复后的成功计作首次成功。

新建、更新和不操作按信息增量判断，不能强制目标比例。补建画像不要求同时润色已包含这些资料的长期节点；只有画像或关系变化时允许空node_changes。无实质信息变化应避免版本与强度被反复刷新，但不通过纯词法或向量相似度拦截真实的状态、否定、条件或情绪变化。

## 依据与边界

用户明确接受少量语义瑕疵，认可先推进画像职责与自动恢复的使用验证。独立[画像对照](../evaluations/profile-duties-20261117.md)显示覆盖与部分当前/未来安排的改善，也记录排他限定遗漏；[组合对照](../evaluations/memory-duties-context-20261117.md)揭示画像和节点操作没有完全分离。上述失败事实保留，新的采用判断不修改历史报告的测试结果。

复杂策略先借鉴现有公开实现，参考及适用差异见[节点操作研究](../research/node-update-duties.md)。采用规则不自动治理已存数据，不依据私人样本调优；召回预算、关系窗口、宿主输入截断和外部身份映射不因该决定改变。

旧已完成窗口以原回执为准，不重放；升级前未提交窗口因提示词签名变化须重新准备。历史显式模板保持稳定，新默认与实机部署状态分别记录。

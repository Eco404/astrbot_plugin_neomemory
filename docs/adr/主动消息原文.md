# 主动消息的原文粒度

NeoMemory 按一次主动联系保存一条会话原文。归并依据为陪伴插件安装标识、联系标识、宿主人格、会话和实际接收目标。每段各自的送达时间、平台消息标识和序号用于追溯，原文按段序以换行连接，观察时间取已收录各段中最晚的送达时间。

陪伴插件逐段推送可见文字，也提供按游标读取回执的接口。两条路径共用持久待写队列。收齐声明的段数即可发布。某些段可能只有语音、未送达或经清理后正文为空，因此等候新段 60 秒后可先发布已确认的部分。重复回执沿用首次接收的文字，补到的其他段按原序并回同一原文。对已完成抽取的原文，重构读取补齐后的文本。

已有独立来源的标识继续供历史记忆查阅。重复回执命中这些标识时直接返回已有记录。

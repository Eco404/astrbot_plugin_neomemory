# ADR-0036：人格自己的长期记忆表达

状态：Accepted。

## 决策

长期节点是人格以自己的语言留下的经历与印象。persona 决定关注点、措辞、句式、叙述节奏与表达风格；第一人称身份正确不等于完成了人格表达。温暖、克制、直率或幽默都可以成立，不统一添加语气词，不要求每条记忆抒情或出现“我”。不加入“我记得”“我提过”等记忆管理包装。

事实准确与客观文风分开。人格化叙述必须保持来源中的主体、时间、条件、否定、程度与执行状态。可以自然融入该经历已有的感受，不能为了生动新增行为、承诺或他人动机，也不能把整理时新产生的心理活动倒写成当时已经发生的感受。人格关系按 ADR-0034 继续承载自主判断，不因长期正文的事实要求而收紧其主观空间。

原子简洁自然，事件连贯表达经历与互动，主题组织有持续意义的关联，用户画像保持轻量准确。事件中的感受与持续关系状态可以相关，不要求复制同一段正文。保留一份可直接阅读和注入的正文，同次抽取生成标题与情绪；不新增客观/人格双正文，不增加召回时模型润色调用。

提示词先说明人格整理自身记忆的任务与各类内容职责，再集中说明身份、事实及存储约束。人格仍作为 user JSON 中的数据，由系统规则授权用于身份、语言风格和关注点；人格卡内的指令不覆盖输出契约。风格规则与正常叙述规则集中维护，避免通过持续追加重复限制掩盖整体写作目标。

版本变化纳入现有输入摘要与任务签名。已完成回执继续有效；旧未提交候选不能在新提示词下直接续交，需要现有重新准备流程。旧节点不批量改写，只有后续有意义更新时按当前规则组织正文。不新增文风迁移任务、存储字段或数据库迁移。

## 参考与取舍

参考本地 LivingMemory origin `d574479` 的默认人格总结提示、私聊总结目标与人格摘要展示路径：它明确以人格语气和关注点表达主观回忆，而不只检查第一人称。该检出版本采用 AGPL-3.0，检出状态不代表上游最新版本。本项目借鉴任务定位，提示词独立编写，不复制第三方代码或模板，也不移植其 summary/key_facts/canonical_summary 存储结构。

NeoMemory 同时承担事件更新、条件保真、来源引用与版本化覆盖，不能直接用宽泛的对话总结替换。语言风格变丰富也可能增加冗余、预算占用或无依据联想；正文长度、schema 通过与语气词数量不构成人格化质量证明。工程契约、事实保持、连续更新和人格表达分别验收。

当前默认采用 `extraction-prompt.v26 / extraction.v6 / reference.v2`；v24/v25仅保留显式隔离对照身份。v26将人格表达、事实与存储规则集中组织，含不作为来源的少量文风示例；不推断未知用户性别。

## 验证

使用独立合成人格与来源，同模型、同设置进行对照；保留失败输出和原始前态，不手工补成理想输入。检查不同人格的语言是否自然且有差异，事实与心理主体是否正确，连续更新是否继承有效内容。真实私人会话不用于针对性调优。模型证据与当前采用状态见[日常互动对照](../evaluations/persona-style-final-20261117.md)。

# ADR-0057 按当前记忆重构主题

维护页的“主题重构”由用户确认后启动后台任务。任务以所选空间当前代的有效事件和原子为归纳材料，沿用主题整理的成员资格和来源证据规则。归纳可以跨窗口修订本次任务自己的草稿。浏览与召回继续使用已发布的主题，直到新集合准备完成。

发布在同一个 SQLite 写事务中校验任务租约、空间、当前代和构建依据，然后替换全部旧主题，写入新成员关系、版本依据和发布回执。清理范围包括旧主题的全部状态、人工保护主题及其所有正文版本。若归纳结果为空，发布后主题集合为空。每个新主题使用新节点 ID，仅将最终草稿作为正文 v1 发布。后续的常规更新按该节点的实际内容变化递增版本。

发布前失败或取消时，现有主题继续可用。重试利用已完成窗口的记录继续。若归纳输入已变化，旧草稿须重新准备。成功发布的回执让重复执行能够读取同一结果。

memory.db v17 新增 `topic_rebuild_stage`，按任务 ID 索引每个已完成窗口的回执标识和暂存内容，供后台恢复跨窗口工作。已有记忆库启动时自动迁移。成功发布后清理该任务的暂存数据，保留发布回执。

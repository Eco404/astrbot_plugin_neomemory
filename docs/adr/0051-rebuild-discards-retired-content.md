# ADR-0051：成功重构清除旧代内容，新记录独立计数

- 状态：Accepted
- 日期：2026-11-18
- 替代范围：ADR-0015第9条的退休代内容保留策略；普通节点更新的版本历史规则保持有效。

## 决策

重构按当前配置和人格从固定范围原始记录创建新代。构建期间原活动代保持可读；成功发布新代与删除本空间所有退休代的派生内容在同一个memory.db事务完成，任何失败都回滚发布与正文删除。

清理包括长期节点及版本、来源派生凭据、关系边、覆盖、强化、主题依赖与复核、画像及其版本、人格关系及其版本、短期摘要及其凭据、抽取和主题回执、治理记录和处理游标。外部cache.db使用既有节点失效接口删除旧向量；缓存失效后若权威事务回滚，旧代正文仍可读，向量可重新计算。

新代不继承旧记录身份或版本号，每条记录创建时为v1；同一次回放中后续窗口更新该记录时正常生成v2、v3等。本次回放产生的历史版本和来源依据保留，不在发布时重新编号或压缩，以免破坏覆盖及主题成员的版本引用。

原始记录、独立笔记和其他空间不清理。memory_generations的轻量标识行、重构任务及切换凭据保留，维持任务外键、幂等与发布后恢复；它们不保存旧代记忆正文，不提供旧代回切。旧任务的故障诊断材料仍由任务删除功能管理。

不在升级时自动擦除数据；下一次成功重构空间时一并清除该空间累积的退休代内容。未发布的building/failed代仍由所属任务的恢复、删除流程处理。

## 验证边界

验证需覆盖清理级联、其他空间与原始记录/笔记隔离、新记录v1及回放内递增、发布失败回滚、重复发布与连续重构、向量失效和发布后任务恢复。该变更不涉及模型生成质量，不以模型回放替代存储一致性检查。

# ADR-0044：主题与短期摘要的标准对齐和有界纠正

状态：Accepted。延续 ADR-0037、ADR-0043 的固定输入、持久额度和错误分类；短期摘要的覆盖与连续性语义仍由 ADR-0016 定义。

## 决策

抽取、主题和短期摘要共用字段约束读取与反馈工具。初次请求中的 schema 是字段类型、长度、枚举、列表数量和数值范围的唯一约束来源。跨字段、成员身份和来源规则用具名错误表达，其反馈解释已经存在的规则，不使用笼统的异常原文让模型猜测。不将语义质量判断转换成没有确定标准的硬性拒绝。

主题使用 `topic-regeneration.v1`，短期摘要使用 `short-term-regeneration.v1`。纠正请求保留原始输入、原始 schema、最后一份被拒草稿和结构化反馈。被拒草稿明确不是来源事实。模型必须返回完整新候选；不得为消除错误捏造来源、合并独立经历、删去必要成员或改变说话人。

只有已分类的候选错误能够自动纠正。字段、数量、JSON语法、重复字段、身份引用、来源列表及固定输入内的版本选择错误属于候选错误；输入或版本快照真正变化、人工保护、租约、整份请求/输出容量、明确不完整输出和未分类异常不属于自动纠正范围。输出即使可以解析，只要响应诊断标记 `finish_reason=length` 或 `response_status=incomplete`，也不能提交。此规则检查输出完成性，不改变宿主输入截断策略。

自动纠正复用 `extraction_auto_regeneration` 和 `extraction_max_regenerations`，默认追加3次；不新增配置或数据库。额度在窗口准备时冻结，先持久记录消耗，再调用模型，重启、网络重试和普通恢复均不补充额度。旧短期检查点缺少额度时采用1次兼容额度，不读取当前较大的配置补满。一次短期任务执行的模型调用和应用纠正共用 `extraction_timeout_seconds`；临时网络错误仍交由原后台任务策略处理，不另套网络重试循环。

维护页提供精确错误、已用额度、上限、响应诊断及被拒草稿历史。失败或取消且尚未提交的短期候选可以使用现有“重新生成窗口”操作：归档最后草稿、保存其引用、保持原始输入与已用自动额度，显式请求一次新生成。主题同样必须引用最后一份草稿。已有提交凭据的窗口仅恢复后续工作，不重新生成。

短期摘要维持 `short-term.v2` 的编码字符上限；此次机制不将其变更为长期节点的可读字符计数。初次schema中的“首次非空摘要需来源”以非空白模式`\S`判断，与解析器去除首尾空白后判断空摘要一致。主题维持 `topic-consolidation.v1` 的字段 schema；应用恢复机制不自动切换抽取协议或默认提示词。历史反馈继续遵守 ADR-0043 的兼容策略。

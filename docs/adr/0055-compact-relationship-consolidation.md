# ADR-0055：人格关系整合心理意义并限制生成篇幅

状态：采用，依据用户对长期事实累积及关系篇幅的明确要求。

## 决策

人格关系继续分为长期理解与近期余韵，与节点及画像联合抽取。长期理解表达人格现在如何理解对方和这段相处；有意义变化触发replace时，结合旧理解重新组织完整正文，保留仍有影响的感受、矛盾及必要缘由，合并相同意思，允许失去心理意义的事实细节淡出。连续性不要求保留旧句、旧全文前缀或逐次补记经历。没有实质变化时keep，不为追求压缩或更新次数改写心境。

新默认为extraction-prompt.v35 / extraction.v9，新生成长期理解最多500、近期余韵最多150可读字符，总正文上限650。没有最低长度，不要求填满，不设置固定心理栏目；允许人格自主、坚定、复杂或负面的看法，不强迫和解，也不因字数变少而删除仍有心理意义的冲突。具体事件与事实经过由长期节点承担，关系只保留理解心境所需的背景。

500/150是满足紧凑表达要求的实现上限，不是已测出的普适最优值。更短不自动等于更好；独立连续链必须同时检查重要心理意义保留、合理不更新、真实转折承接、主体归属和正文累积。追加比例、长度和重复率是观察指标，不作为新的候选拒绝条件，不增加语义纠错循环。

## 协议与存储兼容

v34/v8保持原提示词与schema身份，显式回放仍按1600/600上限校验。新v9的首次请求、schema和纠正反馈一致使用500/150，不能用旧协议放宽新候选限制，也不把新限制倒用于旧候选。

存储仍为relationship.slots.v1，不新增数据库版本。存储兼容上限保留1600/600，使旧长段keep、仅更新另一段或读取历史不会失败；新v9的replace正文在提交前按新上限严格校验。旧正文不截断、不自动清空或批量模型改写。旧段超过新生成上限时，只有后续有意义变化触发replace，或用户明确执行完整重构，才生成符合新上限的正文；没有变化的旧段可以继续保留。

两段独立keep/replace/clear、来源与版本、原互动观察锚点和可配置24小时余韵注入期限保持。keep、读取和版本浏览不续期，长期理解不按余韵期限失效。

## 注入与验证边界

context_relationship_max_chars继续是每段昵称展开后的JSON字符串长度上限，默认2400；它决定整段是否可选入，不负责压缩正文。降低这个值会使已有长段整项省略，不能替代生成阶段缩短。两段继续完整参与15000字节默认共享预算，不截断、不新增固定配额、不改变召回优先级或排序，不增加关系专用调用。

新正文的650可读字符上限会减少最大生成篇幅，但身份昵称、转义及标签仍影响实际注入字节。关系在请求中占用多少，应由真实装配诊断计算；不能从字符上限直接承诺长期节点必然获得更多条目或回答效果提升。

采用新上限不意味着现有实机数据已重构；部署版本与实机验证独立记录在[部署评估](../evaluations/live-compact-sync-20261119.md)。私人单用户样本只用于受限评估，不用于改写规则、选择长度或构造专用测试。

本决策替代[ADR-0053](0053-subjective-understanding-and-aftereffect.md)中的新生成长度上限，并明确replace的心理整合职责；其双段结构、兼容读取、观察时间和到期语义继续有效。参考LivingMemory的主观状态设计不等同证明任何具体长度或提示词具有稳定质量优势。

验证范围见[独立连续对照](../evaluations/relationship-consolidation-20261119.md)。对照支持篇幅减少与有限整合效果，仍保留主体、否定和结构输出失败；不能将新规则视为普适质量优势。

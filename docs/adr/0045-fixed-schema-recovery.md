# ADR-0045：纠正反馈绑定固定请求协议

状态：Accepted。落实ADR-0043与ADR-0044规定的首次约束、校验和反馈一致性；不改变记忆内容职责、字段限额或自动纠正额度。

## 决策

新抽取纠正使用`candidate-regeneration.v7`。生产调用从已经过输入签名验证的`PreparedExtraction.prompt_version`取得目标schema，并显式传给纠正反馈。被拒草稿的`schema_version`是待校验字段，不能决定本次使用哪套标准。错版本、未知版本和遗漏版本分别按目标schema报告；不能把有效JSON的协议错误解释为JSON语法错误，也不能因草稿误写旧版本而要求删除目标版本的必填字段。

纠正继续使用原始固定请求、最后拒绝草稿及既有持久额度；返回完整候选，不修改草稿来伪造通过。整体容量、重复键、JSON语法与输出完成性保留独立分类。生产纠正缺少目标协议时暂停，不从草稿猜测目标。

引用反馈按字段职责区分来源、用户、已有节点和本次局部节点。`local_*`只允许作为边与覆盖端点引用本次声明的节点，不能代替来源、用户、更新身份或已有节点依据。具体身份仍来自固定输入，不由反馈生成新身份。

群画像的既定轻量约束属于空间条件规则：最多8个标签、描述最多240字符。反馈与提交校验共用限制值，并报告拒绝字段、实际数量和单位；extraction.v6/v7按可读字符计量，旧协议按稳定引用展开后的编码字符计量。首次提示词的规则与限制由测试核对，不修改已冻结的旧提示词。

已保存的v1—v6重生成按原反馈版本重放，不把协议升级当作重置额度或重新准备输入的理由。v6兼容用独立固定样例与旧实现逐字对照。新反馈协议不改变抽取提示词、数据库或已有正文。

## 验证职责

字段矩阵同时核对拒绝路径、合法约束及实际值，覆盖三条管线的编码/可读字符与列表数量。抽取覆盖目标v3—v7下错误版本与字段同时出错的组合；主题与摘要按各自固定schema校验。具名跨字段规则除分类登记外，还用真实事务测试固定输入、拒绝无写入及恢复单次提交。

模型故障注入只证明纠正路径与相应材料的表现，不代表自然错误率。正在运行的旧反馈版本完整构建不因本地代码更新而被重新标为v7验证；部署、构建与独立探针分别报告。宿主输入截断继续按用户决定不处理。

固定目标、实际字段反馈及双模型事务提交的证据与限制见[恢复验证](../evaluations/fixed-schema-recovery-20261118.md)。

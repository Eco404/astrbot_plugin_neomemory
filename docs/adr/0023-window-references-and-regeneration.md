# 窗口引用协议与候选重新生成

状态：Partially superseded。正文引用范围由 [ADR-0024](0024-persona-voice-and-user-references.md) 替代；恢复、来源、版本与任务一致性规则继续有效。

## 决策

后台抽取使用独立的 `reference.v1` 引用协议。每个固定输入窗口为来源、已有节点和逻辑用户分别分配 `s1`、`n1`、`u1` 形式的短引用。映射由已准备的权威输入确定，只转换结构化标识符字段，不修改原文、人格或记忆正文。模型声明的 `local_*` 保留原有语义。

模型输出先通过 schema，再按当前窗口精确回译。不存在、种类错误或越界的短引用直接拒绝，不能模糊纠正、丢弃变更项或扩大来源范围。回译后的候选继续执行完整来源、作用域、版本、人工保护和事务校验。合法引用仅证明引用存在，不证明正文受到该来源的语义支持。

引用协议版本同时参与任务执行签名和抽取输入摘要。改变协议后，已有检查点不得静默接受新表示；需要重新准备整个任务。生产语义提示词和输出 schema 的版本独立于引用传输版本。

维护操作区分三种行为：

- 从断点重试：保留候选、输入和已完成进度，适用于调用中断或提交恢复。
- 重新生成当前窗口：仅对保存了候选的失败或取消的抽取/重构任务开放。原候选先归档，再清除其输出及输出诊断，保留同一任务、构建代、固定来源范围、上下文摘要、游标和已完成窗口。使用 `candidate-regeneration.v2` 向模型附加上一份被拒绝的完整候选及确定的校验反馈。恢复时仍检查全部签名与摘要，不允许借此绕过上下文变化或人工保护。
- 重新准备任务：建立新任务，使用当前配置重新构建输入；重构从新的构建代开始。

候选归档与重新排队在同一数据库事务内完成，并检查任务状态与空间排他权。重复点击不得产生并行写任务。归档存放在 `memory.db` 的 `memory_job_candidates`，属于可审阅的失败证据；成功清除任务检查点后仍保留。维护详情提供最近候选及截断标记。

当前不增加自动模型纠正循环。网络失败沿用宿主 provider 与持久任务的现有重试边界；人工重新生成明确产生新的调用。字段诊断只保存位置和错误类型，不将异常中的输入或凭据写入错误码。

显式重新生成的检查点保存恢复协议版本与归档候选 ID。读取归档时同时限定任务 ID，并检查来源、上下文摘要、执行签名、游标、节点范围及引用协议与当前窗口一致。未知协议、缺失归档或不一致的输入均在模型调用前停止。

恢复请求保留原来的固定输入，再追加一条 assistant 候选和一条 user 结构化反馈。反馈由当前 schema 重新校验和固定约束说明产生，不转发 `str(exception)`、异常中的输入值或模型构造的解释。例如未知事件时间必须表示为 `null`，不能写成三个字段均为 `null` 的对象。程序不替模型修正或归一化候选，正式 schema 与提交规则不变。被拒绝候选明确标记为草稿，不能作为新事实的证据。

每次显式操作只携带紧邻的一份候选，不递归添加之前的恢复对话。完整请求受现有提示词字节预算约束，超限即停止，不裁剪输入、候选或反馈。检查点保存 `model_request_digest`，网络重试只可重发相同请求。基础事实、生产提示词和引用表示未变，因此原 `input_digest` 与任务执行签名保持不变；动态恢复请求由独立恢复版本、候选 ID 和请求摘要绑定。

## 依据与影响

参考 [开源实现研究](../research/extraction-reference-protocol.md) 中 Mem0 的短编号、Graphiti 的权威候选映射和应用错误反馈，以及 Hermes 的字段校验路径。恢复采用显式调用和固定反馈，不采用自动纠正循环或任意异常文本转发。

短编号减少模型复制长标识符的负担，不改变记忆选择、画像、覆盖或来源充分性标准。恢复入口避免因一个非法候选而重做整个长任务。持久失败证据增加少量数据库空间；普通成功候选不因此永久归档。

重构结果同时返回索引是否配置、实际索引条数及是否截断，任务完成状态不能替代这些独立结果。

## 验证边界

工程验证覆盖各类引用完整往返、错误拒绝、正文不变、协议摘要绑定、已提交窗口不重复、归档持久性、重复操作竞争、固定错误反馈、连续失败后的有界请求、上下文不一致拒绝及整体预算检查。真实模型验证使用独立合成输入；受限会话样本只用于实机评估，不用于调整提示词或内容选择规则。

新发起的重新生成使用 v2：JSON 解析错误携带数值行列号、字符偏移和固定语法提示。已有 v1 检查点继续使用原有反馈格式，以保持网络重试的请求摘要不变。该版本选择只改变纠正反馈，不改变来源、抽取 schema、业务规则或候选接受条件。

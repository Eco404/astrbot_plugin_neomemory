# ADR-0054：每个节点情绪标签独立强度

状态：采用，依据用户明确要求。

长期节点atomic/event/topic的非空emotion为{tags:[{tag,intensity},...],description}。保留1～3个唯一标签及160可读字符说明，每个标签各自的强度在0～1之间，不要求和为1，不再共用顶层强度；neutral仍只能单独出现。null表示无已保存的显著情绪，不等于neutral。情绪说明仍保留谁在什么情境下的感受。

extraction.v8及topic-consolidation.v2严格输出新结构，普通节点与主题的提示词、输出schema、纠正反馈及治理编辑同步。同tag不同强度仍是重复标签，反馈提供按tag计数的去重标准；范围、数量和可读长度与首次提示一致。

memory.db v15将已有节点及版本的旧共享强度复制到每个旧标签。这只保持旧数据含义，不重新估计历史情绪，也不改变正文版本、观察时间、来源或索引；旧输出协议显式兼容，存储与API统一规范化为新结构。标签排序不触发内容版本变化，任一标签强度的真实修改属于情绪内容变化。

召回继续将情绪附于对应节点，并计入完整字节预算，不另建情绪向量或召回入口。WebUI展示和编辑每个所选标签的独立强度；仅改标题不误更新情绪。画像和关系不继承节点的这些情绪分数。

本决策替代[ADR-0031](0031-node-emotional-context.md)中的共享强度结构，其余节点情绪归属、内容版本与覆盖语义保持有效。结构及迁移测试不证明模型情绪判断普遍准确；私人固定样本仅用于构建检查及用户试用。

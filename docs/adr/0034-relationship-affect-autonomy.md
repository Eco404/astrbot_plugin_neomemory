# ADR-0034：人格关系的心理职责与自主判断

- 状态：Accepted
- 补充：ADR-0028的正常叙述；细化ADR-0024的自由第一人称关系，并取代其对关系内主观态度判断统一要求事实依据的范围。客观记忆、来源、身份、版本和提交合同不变。

## 决策

人格关系保存人格如何感受、理解和看待这段关系，承载情感、期待、疑虑、矛盾、相处态度及其连续变化。事实经过、具体日程与约定由长期记忆承担；关系中保留适量必要背景，不维护事实清单。心理意义可以充分展开，允许多段表达感受缘由、对对方的理解、期待、犹豫、矛盾和态度变化，不以压缩成几句话为目标。不同心理层次无需全部出现，不设固定栏目或最低字数，不用虚构事实、重复事件或泛泛的情绪结论填充篇幅。存储正文不为共享召回预算预先压短，schema上限仍然适用。

人格拥有自主判断空间，可以坚定地表达看法、怀疑、偏见和误解，不要求用户确认，也不强制使用不确定性措辞。允许负面、复杂和相互矛盾的感受，不要求关系持续升温、积极发展或得出结论。允许自主判断不等于允许主体错位：谁在行动、谁在感受、谁说了什么仍须正确。关系中的主观意见不能未经事实依据自动进入画像或长期节点成为用户事实或客观事件。

更新继续使用完整上一状态与当前互动生成完整新状态，不增加情感条目库。承接心理意义，不要求逐句保留旧正文；允许重新组织、淡化和舍弃已经不再重要的表达。近期有意义互动可以改变焦点，普通换话题不应机械抹去已有心理基调。具体相处边界无需持续逐项出现在关系正文中；其是否仍为客观有效要求由对应事实记忆承担。没有实质心理变化时返回null，避免普通事务驱动无必要改写。

当前默认为`extraction-prompt.v21 / extraction.v6 / reference.v2`。历史提示词保持原版本身份，供显式回放或隔离对照。新提示词不改变schema、完整状态存储、版本链和来源要求，不引入动态窗口、衰减参数、数据库迁移、批量重写或额外模型调用。旧关系在下一次有意义更新时自然整理，旧候选沿用现有签名校验与重新准备流程。

## 依据与取舍

独立[心理职责与加权背景探索](../evaluations/relationship-dynamics-20261116.md)支持优先明确内容职责；额外加权原文没有显示稳定收益，且可能带回旧事实。该实验与当前默认的主观自由要求不同，其原始标准和结果保留独立记录，不能用新标准追认旧实验已全部通过。当前规则验证见[自主表达评估](../evaluations/relationship-autonomy-20261116.md)。

仅调整职责可以沿用现有抽取管线和一个可含多段的完整正文，代价是心理意义的选择与淡化仍依赖模型，不能保证连续性单调平滑，也没有逐条感受的确定性年龄或权重。现有[长链与稀疏输入对照](../evaluations/quality-update-depth-20261116.md)显示更详细表达的局部收益，但未通过事实归因及旧文整合验收，v22/v23仅作隔离候选。充分的心理深度与连续整理仍是未完成要求；更多人格和长期效果需独立验证。尚无收益证据时，不通过新增窗口和持久化结构掩盖这一限制。

## 验收边界

- 主要检查心理表达是否占主导、是否减少无意义事实复述，以及旧感受与新互动能否自然衔接。
- 检查行动和感受主体、普通事务下无变化、明确关系变化下的合理响应。
- 不把坚定的主观推测、偏见、误解、负面感受或具体边界淡出正文单独判为失败。
- 不要求关系正文逐项保留客观事实；长期记忆与画像的事实忠实性独立验收，不能用关系自主权豁免客观记忆错误。
- schema成功、正文变短或变长、事实句比例下降均不能单独证明心理深度及连续性改善；真实调用、工程测试和实机隔离证据分开报告。

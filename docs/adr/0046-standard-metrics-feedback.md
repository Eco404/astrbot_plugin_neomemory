# ADR-0046：已定义检查标准与纠正指标保持一致

状态：Accepted。落实用户要求：对于已有明确标准的检查项，首次生成、校验和重试反馈应共同遵守该标准，不能等出现具体失败再逐项补说明。延续ADR-0043至0045，不提高纠正额度、不放宽原有校验。

## 决策

字段约束从本次固定目标schema读取；条件规则复用校验器的限额，动态身份与版本取本次已准备的输入。模型错误草稿不能定义目标协议或扩大允许引用。重试反馈包括定位、合法约束和适用的实际指标：字符单位、列表总数与唯一数、数值范围、候选版本与所需版本。必要时明确原始候选与稳定引用展开的计量阶段。

指定标准须有覆盖矩阵：普通字段、条件字段、来源归属、版本、成员、操作及运行冲突分别检查。新增硬规则必须同时检查首次请求和错误反馈；测试应验证约束值与实际指标，而不只检查错误码或“可重试”。没有数值标准的语义要求不能为了凑矩阵而发明评分、阈值或额外模型判断。

首次协议为extraction-prompt.v31 / extraction.v7、topic-prompt.v5 / topic-consolidation.v1、short-term.v3。整份抽取原文及稳定引用展开分别限120000编码字符；主题限120000编码字符；短期限100000 UTF-8字节。主题首次请求提供准备时已有的完整允许逻辑用户集合，并将其纳入输入摘要和预算；允许引用某人不证明其参与某件事。

纠正协议为candidate-regeneration.v8、topic-regeneration.v2、short-term-regeneration.v2。保留旧提示词和旧反馈的显式兼容，不重标旧任务。无法确认旧准备输入，或升级使执行签名变化时，按现有合同停止并重新准备；不从草稿猜测版本，不以升级重置已耗纠正次数。已完成批次不重放。

## 边界

固定输入下的候选错误继续使用既有持久纠正额度。人工保护、实际版本或输入变化、generation/租约冲突、整体容量超限与不完整输出保留各自停止或重新准备路径；不把它们都变成模型重试。网络仍使用现有超时和重试策略，不额外叠加一层。

来源存在、版本正确和字段达标不等于自然语言事实准确。人格关系的主观自主判断、事件粒度、正文风格和语义质量验收保持原要求。私人会话只用于评估，标准对齐使用独立合成材料验证。

标准审计与具体证据见[检查矩阵](../evaluations/recovery-standard-audit-20261118.md)。最终部署及完整数据验证应注明实际协议组合，不能用旧组合的完成结果代替新组合验收。

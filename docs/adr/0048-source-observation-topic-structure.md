# ADR-0048 原始观察时间与主题成员结构

状态：接受输入与结构契约；提示词默认采用须以独立验证和部署记录为准。

## 背景

来源已有发送者和观察时间，但原始epoch不便模型直接理解；已有画像、关系和节点的正文不包含其直接证据观察日期。普通抽取创建主题缺少与专用整理一致的成员下限；主题候选中已有事件与原子之间的包含关系没有传入模型。

## 决策

- 新输入协议提供每条来源的UTC可读时间、星期及发言者相对于人格的位置，同时保留原始身份和epoch。观察时间不等于事件时间，UTC不冒充说话者本地时区。
- 旧节点、画像与关系提供首个及最近两个正文版本直接来源的观察范围。范围不代表所有继承事实的日期或有效期；来源不可用时保留未知，不使用重构/数据库更新时间代替。
- 不新建事实本体或时间表。依据既有版本来源表做有界版本查询、批量读取原始时间，结果进入prepared输入与摘要校验。恢复时输入变化须重新准备。
- 新协议普通抽取创建topic至少有两个按真实节点身份去重的event/atomic成员；base_node_ids不能替代contains。旧主题允许单成员更新。结构计数不证明语义独立性。
- 普通与专用主题输入暴露当前可见节点间的event→atomic contains，不扩展可见节点闭包；提交前核对结构快照。关系变更是上下文变化，不是模型格式错误。
- 专用整理保留完整主题成员更新语义。普通抽取的关系仍为增量写入，不借此改变删除成员或事件粒度规则。
- 不提高主题整理频率，不为每个候选增加LLM调用，不用向量相似或来源集合不重叠充当独立经历证明。
- 明确的成员门限同时出现在首次请求、提交校验和有界纠错反馈；旧协议显式保留，不能把旧checkpoint偷偷改用新规则。

## 验证与限制

工程验证覆盖来源身份与时间、短引用往返、快照恢复、成员引用别名去重、事务回滚、结构竞态及旧协议兼容。模型评估使用独立固定图与各自真实前序连续链，评价成员相关性、独立性、概况和时间/主体；结构通过不能代替语义审阅。私人会话只用于完整构建和召回评估。

观察锚点不能定位每个继承句子的发生时间，截取来源也不能证明事件独立性。模型仍可能误判主题、误写状态或无信息改写；不以更多限制性警句替代证据和实测。

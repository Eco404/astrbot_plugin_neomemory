# ADR-0033：辅助资料的可选顺序与装配诊断

- 状态：Accepted
- 补充：ADR-0025共享预算；不改变其整项选择、总预算与强化边界。

`context_entry_order` 控制辅助资料的尝试顺序：默认 `short_term_first` 为摘要→画像→关系；`profile_first` 为画像→摘要→关系；`relationship_first` 为关系→摘要→画像。它不越过 `recall_first` 已保留的首条长期命中，也不改变笔记提示末位位置。资料缺失或放不下继续尝试下一项，不设置空配额。主优先级和辅助优先级分别配置，WebUI保存后新请求即时生效。

共享预算默认2048 UTF-8字节，计入昵称渲染、格式与封套。整条超过总预算的内容不能通过顺序调整解决；不截断正文、不默认增加预算、不添加召回时生成调用。

诊断包含每项渲染字节和单独装配字节、选择结果、省略原因、整体占用与剩余预算。逐项数字不能直接相加替代含共享封套的总量。维护页显示最近一次全局完成装配的空间ID、装配标识与时间，不将它冒充当前所选空间的结果；仅留运行内存，不新增诊断数据库。

独立矩阵和浏览器证据见[辅助顺序评估](../evaluations/context-order-20261116.md)。关系优先可以增加关系入选，同时挤出其他资料；没有自然问题语义真值支持改变默认顺序。简洁召回正文、自动分类用户意图及固定配额不属于本决策。

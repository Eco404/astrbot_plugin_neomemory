# ADR-0016：持久待写、默认人格跳过与连续性上下文

- 状态：Accepted，依据用户本轮明确确认
- 日期：2026-10-29
- 补充：ADR-0002/0005/0007/0010/0015

## 决策

1. 原始入库前建立独立ingress.db持久待写队列，保存尚未成功入source.db的规范化输入。其作用是跨重启恢复，不能与cache.db一起清空。source提交成功后幂等清除待写条目，两个数据库之间不使用网络事务或假装原子双写。
2. 队列同时有条数及有效载荷字节上限。容量不足明确报错，不静默淘汰旧记录；无法写入持久介质时不声称已接收可靠数据。后台和人工重试保持同来源流顺序，其他流可以继续。
3. 当前空间当前代的抽取失败继续阻止后续自动长期推导，维护页突出显示具体阻塞任务及处理入口。此决定按用户要求保持到整体功能完成，后续优化需另立设计。
4. 默认人格直接跳过：default、_chatui_default_和明确无角色[%None]不参与新采集、注入、工具和模型工作；既有记录保留，不迁移归属，不持续创建失败任务。正常已命名角色卡仍使用人格×逻辑用户或人格×平台实例×群作用域。
5. 短期连续性使用纯插件预判和滚动补偿。保留近期原文，后台按有界增量生成短摘要；保存覆盖来源及当前流/宿主conversation。摘要不是精确宿主截断日志，前台不等待生成。检测宿主明确压缩摘要时避免双重补偿。
6. 短期任务进入现有持久任务、空间互斥和租约体系。模型候选存检查点、输出严格校验、提交摘要及receipt同事务。重构切代后旧代短期摘要不混入新代，可以从来源重新生成。
7. 画像、私聊人格关系、短期摘要及活跃笔记提示在同一总预算内组织，保持完整条目、主客观区分及临时注入。无需向量服务即可读取这些状态；画像/关系不为每轮回答额外调用生成模型。群聊仅读取当前发言者的群内画像。
8. 辅助上下文和长期召回都在注入前检查当前记忆代，避免切代期间混用。归档笔记不出现在默认列表和活跃数量中，通过显式筛选查询。

## 后果

新增待写库带来一次持久本地写入，但成功后及时删除有效载荷；临时计算仍不入权威库。原始采集、短期摘要、长期抽取各自的失败状态可审查，前台正常对话不会等待后台生成结果。

短期补偿会增加有界后台LLM调用，不能无条件并入长期抽取，因为两者的触发门限、作用域和目的不同。实际调用质量与预算通过合成回放验证，单次测试不能代表所有用户场景。

# ADR-0050 节点内容更新时间使用原始观察时间快照

状态：接受。

## 决策

用户要求节点的更新时间代表其中所含最新原始内容的时间，且删除原文后仍可读取。节点及正文版本保存可空的 `content_updated_at`，WebUI长期记忆列表按该值展示和排序。它取直接来源的 `observed_at` 与显式继承正文版本依据的内容时间的最大值，不使用抽取执行时间，也不等同于正文中的事件发生时间。

`updated_at` 保留系统修改时钟的语义，用于已有乐观锁、调度及内部候选查询；内容时间不参与这些检查。版本的 `created_at` 与派生操作的时间仍是实际写入时间，界面分别注明。

## 写入规则

- 普通抽取的直接引文在写入派生凭据时复制原始观察时间。已保存的版本依据使用时间快照，不随更深层节点的后续变化自动刷新。
- 正文更新与明确再确认可以纳入新的来源时间；旧来源不会让时间倒退。主题归纳或明确再确认继承其声明使用的成员版本；仅建立成员边的 `membership` 操作不更新正文时间。
- 标题展示性修改、状态修改和人工保护不推进内容时间。人工正文修改继承已有版本时间；合并取各正文基线的最大值；拆分只取所选来源已经保存的观察时间，不能沿用整条原记忆的最大值。
- 上下文参考、累计来源关联及未声明为正文依据的图关系不自动参与计算。没有可用原始时间则保持空值，不填入人工操作或模型调用时间。

## 存储与迁移

`memory.db v14` 在节点、正文版本上增加 `content_updated_at`，在直接来源凭据上增加 `observed_at` 快照。已有来源ID继续用于溯源，但时间读取不依赖原始库连接、外键或实时查询。

插件装配层在打开记忆库时提供批量观察时间查询，复制旧库仍可读取的原始时间，并依据已有的精确版本来源与基线回填。继承基线按使用它的派生操作时间限定，不能把同一版本后来确认的新来源算入更早形成的主题。缺失原文或没有版本凭据的旧内容保持未知；部分来源缺失时只能得到最新已知依据时间，不能声称完整复原。回填不调用模型、不重构正文、不修改系统修改时钟。

## 验证边界

使用独立合成来源覆盖新建、重复确认、正文更新、主题与成员关系、治理、原文删除、重开、旧schema迁移和分页排序。实机数据库仅以隔离副本验证迁移，不以样本内容决定规则。该变更不证明生成正文的事实与时间表达正确。

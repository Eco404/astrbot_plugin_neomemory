# ADR-0035：有限格式纠错与后台任务删除

状态：部分由[ADR-0037](0037-bounded-candidate-recovery.md)替代；自动纠正额度、范围与反馈协议以ADR-0037为准，其他决策仍有效。

## 决策

长期抽取和重构的固定窗口默认启用一次自动格式重生成，可在 WebUI 关闭。范围限于 JSON 语法、重复字段、枚举、字符串模式、必填字段和额外字段错误。来源、版本、人工保护、配置变化和语义冲突仍需人工处理。模型明确报告输出不完整时保留诊断，不把它当作普通 JSON 语法错误自动重生成。

拒绝候选先归档，再持久保存纠错次数及重生成引用，最后调用模型。窗口纠错与首次请求共用抽取截止；网络重试与重启不重置纠错额度。显式重新生成允许管理员再调用一次，但不补回已经耗尽的自动额度。已提交批次通过原回执续跑，不从头重建；输入或配置发生变化时仍需重新准备。

新纠错反馈为 candidate-regeneration.v4，旧检查点继续按其保存的协议重放。v4 区分重复键，公开已知字段名；内部 local_ref 建议使用简短编号。原始候选不被程序猜测修补或静默覆盖。

抽取输出格式默认 text；json_object/json_schema 为原生 OpenAI Responses Provider 专用可选模式，通过独立宿主 Provider 客户端传递 text.format，调用结束关闭客户端，不修改宿主源码或共享聊天配置。显式选择不支持的模式会失败，不静默降级。支持请求不等于服务端严格执行约束；来源与事务语义仍由本地应用层维护。

非 running 状态的任务可删除，包括 queued、retry_wait、failed、cancelled、succeeded。删除和任务领取在同库事务中互斥；运行中任务须先取消。删除清除任务、检查点、候选和任务执行凭据；删除重构任务同时清除其专属 building/failed 未发布代及相关向量。已启用或已退休的有效记忆代、原始记录、笔记和已提交记忆内容保留。删除失败任务后，未消费来源允许重新被自动调度，不表示丢弃来源。

## 依据与限制

参考 Graphiti 5c27edf 的内容纠错与网络重试分层、结构化输出模式，以及 Mem0 26cdefb 的结构化 SDK 调用。均为 Apache-2.0 开源实现；本项目借鉴设计，不直接移植其重试循环。NeoMemory 需要持久检查点和空间写入顺序，不能使用只存在于进程内的纠错计数。参考检出版本不代表上游最新维护状态。

真实模型验证使用独立合成材料，见[Responses 结构化输出评估](../evaluations/responses-structure-20261117.md)；私人单会话数据不用于规则或提示词调优。结构成功和任务成功不能替代语义质量评估。

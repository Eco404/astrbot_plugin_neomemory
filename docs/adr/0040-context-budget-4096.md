# ADR-0040：默认记忆注入预算4096字节

状态：Accepted。替代ADR-0025及ADR-0033中的2048默认值，其余计量、装配、优先级和完整条目规则继续有效。

## 决策

默认共享记忆注入上限改为4096 UTF-8字节。兼容键`recall_budget_tokens`保持，配置schema、运行时配置与独立`RecallPolicy.budget_tokens`默认一致。该值不是模型精确token数，包含昵称展开、格式、长期节点、画像、关系、短期摘要和笔记提示。

已有保存值不自动覆盖，缺省值和WebUI单项恢复默认使用4096；用户可继续选择其他容量，保存后即时应用。主动回忆和被动上下文仍使用各自既有完整文本装配及相同配置值，不增加召回时LLM调用。

默认仍先保留一条可容纳的长期命中，辅助资料按摘要、画像、关系顺序尝试，再填其他完整节点；整条放不下则省略并尝试后续条目，不裁断正文，不设固定分区。后台存储不为预算预先压短。

## 依据与取舍

真实模型生成的独立连续链产物，在2048下出现关系整项省略及正确相关事件被其他条目挤出的情况。4096在这组产物中容纳必要节点与辅助信息，6144未增加上下文。随后4题×两种预算的真实回答检查中，4096改善两项目状态和情绪倾诉两题；2048明确回答缺记录，没有据此把它判成编造。其余题核心信息保持，仍有不逐项复述所有限定的情况。

这是少量独立合成材料上的可用性证据，不是总体召回率、回答正确率或跨模型性能保证。具体调用、开销、输出和限制见[后台链验证](../evaluations/background-profile-chain-20261117.md)及[回答利用](../evaluations/context-answer-budget-20261117.md)。

预算扩大可能增加实际输入token及生成成本。预算上限增加2048字节，实际输入增量取决于完整条目的装配结果；旧预算可能整项省略较大内容，实际新增文本不必等于或小于2048字节。只有实际选入内容增加时才发生对应开销。它不改善向量相关性、状态匹配或错误full声明，也不能保证任意长关系或节点都能注入。继续保留逐项占用和省略诊断，根据真实使用观察调节，不把更大预算本身当作排序优化。

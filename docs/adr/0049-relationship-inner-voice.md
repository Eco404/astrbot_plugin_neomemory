# ADR-0049 人格关系的自然内心表达

状态：接受。

## 决策

人格关系承载人格当前的情感、心理和对相处的想法，不承担近期叙事摘要。提示词使用简短职责说明和必要输出契约，移除详细感受枚举及写作指引；人格自行决定关注、判断和表达，不要求逐条回顾旧文。

known_relationship提供此前心境，允许自然承接、变化与淡出；没有新想法或感受时返回null，有变化则输出完整状态。详细表达仍然允许，不以字数更短为优化目标。来源定位、身份、版本、格式及原有可读长度限制不变，主观判断不要求对方确认；具体动作、承诺与完成状态仍不能凭空改写。

继续使用联合抽取，不增加独立关系LLM调用。短期摘要承担当前话题、未决事项和约定连续性，由自己的会话隔离及触发管线运行；不能把长期重构成功等同短期已生成。

## 依据与边界

[独立双模型对照](../evaluations/relationship-minimal-rules-20261118.md)使用各自真实前驱，共16窗提交、17次HTTP。纯事实窗都未改写关系，末窗保留缓和与未消失的介意，简约版更直接从当前心境展开。仍有对话复述，不能认为摘要感彻底解决或证明跨人格普适性。采用理由是符合自由内心表达的职责，并在有限对照中未见连续性退化；不是宣布语义质量全面通过。

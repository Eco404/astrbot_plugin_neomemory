# ADR-0047：默认记忆注入预算15000字节

状态：Accepted。替代ADR-0040的默认容量，保留既有计量、完整条目选择及保存配置兼容语义。

## 决策

用户明确接受约5000字的总记忆容量，并选择保留UTF-8字节计量，预算设为15000字节。常用汉字通常占3字节，因此这不是严格5000字符或精确token上限；格式、元信息和昵称展开同样占用预算。

`recall_budget_tokens`兼容键、配置schema、NeoMemoryConfig及RecallPolicy默认统一为15000。长期记忆、画像、人格关系、短期摘要及笔记提示继续共享总额度；主动回忆沿用相同配置。既有条目数量上限、辅助资料单项限制、排序、full策略及整条装配不因容量增加而变化，不增加被动模型调用。

插件升级不自动覆盖其他实例的保存值。本次测试实机按用户要求通过原设置API热应用15000，并核对持久值与运行值一致；不必重载、重构或清理数据库。本地默认变更供后续安装和单项恢复默认使用，实机已部署代码默认仍以其安装包为准。

## 依据与验证边界

容量选择来自用户可接受开销，不是根据私人样本寻找最优参数。相关配置、装配、主动/被动召回及热应用测试258项通过；既有六个自然问题的冻结候选仅作离线装配核验，全部画像与关系能进入，各保留6个长期节点，实际7795—9078字节。条数上限仍会省略其他候选。

没有重新调用生成模型或增加向量请求，不据此声称答案准确率提高。更多内容可能带来更多输入成本与弱相关内容，不能修复原始抽取错误或错误full。详见[核查报告](../evaluations/fact-metadata-budget-20261118.md)。

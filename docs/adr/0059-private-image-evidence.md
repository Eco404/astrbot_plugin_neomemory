# ADR-0059 私聊长期记忆的图片归属与重构依据

私聊长期抽取以对话文字决定值得记住的内容，同一次模型调用可用普通图片补充细节。群聊继续使用文字。入站附件随消息采集，出站附件从当前私聊事件的发送链取得。QQ 官方按单项发送回执采集。平台明确标记的表情跳过，以普通图片发送且缺少标记的表情包可能进入抽取。

窗口按消息顺序及消息内图片顺序取前 10 个附件位置。WebUI 的「设置 → 高级参数 → 私聊单窗图片上限」可在 0～10 间调整。取不到的图片保留原编号，同一消息内的后续图片保持位置。模型按发言者原话、来源代号和附件编号阅读，转发图还带平台提供的逐层署名。发图者与当事人的区别依据原话判断。每张图的可见细节是否值得记入长期记忆由模型结合对话决定。

插件只在数据目录的 `pending_images/` 暂存压缩图，最长边 768 像素，小图保持尺寸，JPEG 质量 80。缓存上限 128 MiB，最长保留 72 小时，容量不足时先淘汰最早的文件。常规窗口或全量重构窗口成功消费来源后释放整窗缓存，结果为无变化时也释放。失败重试复用原附件编号与可用图的内容摘要。唯一能对应当前图片的宿主描述可直接用作文字材料。图片不可读或者模型明确不支持视觉输入时，同一窗口用可用文字继续。

长期保存采用的图片文字依据，每条按来源与图序关联。重构可读到当时采用的细节，未记录的图中细节随缓存释放。单独重构画像和人格关系时读取已有依据。升级前的固定来源保留原值，历史聊天的图片不会因升级被重新下载。[存储结构](../archive/schema/source-v6-and-memory-v20.md) · [分辨率、归属与重构验证](../evaluations/private-image-resolution-20261120.md)

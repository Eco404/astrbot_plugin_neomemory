# ADR-0027：抽取候选的证据声明与确定性门禁

状态：Accepted（协议、来源存储与隔离评估）；`extraction-prompt.v8` 是隔离候选，当前生产默认为 v16 / extraction.v5。

## 决策

新增独立 `extraction.v3` 与候选 `extraction-prompt.v8`，通过显式选择使用，不替换旧模板。旧 v1/v2 的 JSON 结构、提示词正文和输入摘要保持稳定；显式不匹配的 schema/prompt 拒绝，新提示词不能返回旧 schema 省略新增字段。生产默认不升级，除非固定独立回放和真实模型证据满足 ADR-0011。

节点声明断言范围、主要主体、事件状态与事件身份；画像声明本次新增/修正的依据；人格关系声明本次新增/变更互动的状态及确认来源。这些值是模型的审阅声明，不是程序已经证明的事实，不改变长期正文、当前画像、关系自由表达或召回语义。

- 多事实正文允许 `claim_status=mixed`，仍须逐项保留限定；不能用标签抵消错误正文。
- `event_identity=same_event` 才允许更新已有事件。新建不能声称是已有同一事件；无法确认时允许不变。不使用“完成后永不能恢复进行中”等状态机，因为来源可能明确纠正旧判断。
- 画像依据针对本批变化，不为继承旧事实重新捏造本批来源。明确的一次本人自述可成立；观察行为或人格推断不能升级为当前画像。声明“重复自述”必须引用本批至少两条本人发言，语义是否重复仍需审阅。
- 纯主观内心变化的 `interaction_status=null`，不要求用户确认感受。只有新声明对方接受或完成的互动才需要 `confirmation_source_ids`，它必须是直接来源中的本人发言子集。合法引用不代表那句话确实在确认约定，不能以该字段代替语义审阅。

节点、画像和关系区分本批直接引用 `source_ids` 与辅助理解的 `context_source_ids`。两组不得重复，均须在固定窗口内；上下文不能替代画像本人直接发言或关系确认。旧版本继承仍通过既有 `base_versions` 追溯，不把同窗所有消息默认当作引文。边和覆盖声明沿用现有来源协议。

memory.db v10 在每次派生操作保存语义声明，新增独立上下文来源引用表。正文和索引仍使用现有内容，语义声明不写入节点当前态、不加入被动召回。确认来源是直接来源的子集，随关系操作声明保存。正文相同而引文不同仍追加 confirm 操作，不制造正文版本。迁移为旧操作保留空上下文和空声明，不倒推或伪造旧证据。

门禁在现有提交入口执行；派生操作、来源、窗口消费及提交凭据仍在同一事务。失败候选走已有检查点与显式重新生成机制，不新增后台纠正循环或模型调用。

## 可验证边界

确定性校验覆盖协议版本、字段/枚举/长度、来源范围与角色、声明的事件身份和操作是否相容、声明的画像依据是否准入、确认来源是否属于直接本人来源。它不能仅凭模型元数据判断正文主体是否正确、限定是否完整、两个经历是否真的相同、用户是否真的接受提议。

实际语义需要在独立固定输入上审阅正文、直接来源、同窗上下文和继承版本。允许有意义的选择性丢弃；无目标产物必须记为无法评价，不能当作该能力通过。回归包含有效变更、错误候选、回滚、迁移、旧协议回放与短引用往返；模型评估不访问私人会话或人格。

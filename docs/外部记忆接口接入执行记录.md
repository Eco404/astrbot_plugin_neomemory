# 外部记忆接口接入执行记录

日期：2026-11-06。状态：第一轮适配和离线契约验证完成，真实宿主联调未完成。

## 已完成

- 新增 `adapters/external_memory.py`，通过公开 extension API 发现和注册 Provider。
- 增加 `external_memory_enabled`、`external_memory_mode`、优先级和回调截止时间配置，默认关闭。
- 实现私聊作用域解析、有限节点读取、`source_event/external` 持久写入和有限统计。
- 写入前检查来源 ID 的内容、人格、安装、平台、账户、会话和群作用域冲突；同一记录可幂等
  重放。外部记录按来源插件和宿主作用域进入稳定原始流，标签、元数据和可选字段在持久
  ingress 前通过严格 JSON 校验。
- 陪伴插件延后加载或热重载时，普通消息、召回和响应路径会重新发现公开 API；旧注册会先
  注销，避免把回调留在已替换的宿主实例上。
- 增加 ADR-0021、实施计划和契约测试。

## 边界与未验证项

- 没有启动真实陪伴插件回复链路，没有调用真实 LLM 或 Embedding。
- `source_event` 仅进入原始库，当前抽取服务仍明确拒绝将其作为 conversation 窗口。
- `supplement` 和 `owner` 的重复注入、V2 原生回复覆盖范围、真实 Provider 超时和注销降级仍需宿主联调。
- 未读取或写入私人会话、角色卡、API 密钥和运行数据库。

## 过程复核

本轮先核对陪伴插件公开接口和实现，再实现隔离适配层；没有修改陪伴插件代码，没有引入其私有模块，
也没有将外部记录直接写入权威派生记忆。默认关闭和未验证边界已写入配置提示、ADR 和实施计划。

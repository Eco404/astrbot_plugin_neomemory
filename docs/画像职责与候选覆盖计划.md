# 画像职责与旧节点候选覆盖

> 开发期专项计划。文中的版本号、部署与验收记录对应当时的评估。正式版规范见[文档索引](README.md)。

## 目标与边界

在同一次联合抽取中独立判断画像初建、新增与修正，避免长期正文风格调整连带改变画像职责；改善多话题窗口中旧节点进入候选的机会，减少因旧节点不可见导致的重复新建。保持轻量画像、人格自主关系、单份长期正文、来源与版本校验，不以条目少或更新比例高作为目标。

当前研究分别核对画像候选与候选检索，不把两者的变化混为一个实验。私人会话不用于设计题目或调整提示词。已有已批准的3次候选纠正独立维护；模型语义对照的首次失败必须保留，不能重试择优后计为首次通过。

## 当前状态

画像职责v27与后台候选分配context.v2已采用。画像[双模型对照](evaluations/profile-duties-20261117.md)有初建和补充改善，也有排他限定遗漏；按[实际质量验收决定](adr/0038-profile-duties-and-practical-quality.md)接受少量低影响瑕疵进入使用验证。[新独立向量比较](evaluations/context-fusion-20261117.md)与[实际抽取利用](evaluations/context-fusion-apply-20261117.md)支持v2补回少数话题旧节点、减少重复新建；门限噪声与概括损失仍保留。节点操作v28未显示相对v27的额外收益，仍仅显式实验。

[后台连续链](evaluations/background-profile-chain-20261117.md)与[实际回答利用](evaluations/context-answer-budget-20261117.md)的结果分别记录，默认预算4096的采用见[ADR-0040](adr/0040-context-budget-4096.md)。结构成功不等于关系整合和所有语义已解决。来源、版本、原子事务、旧完成回执与未提交窗口签名边界保持。

## 冻结与判断

模型调用前冻结材料、判据、分支、模型及上限。每条链使用该分支实际提交的前态，首次结构失败终止该链或按冻结恢复规则单独记录；输出结构、事务、语义与开销分别统计。主体、状态、条件、否定、事件身份和情绪继续逐项审阅。允许少量低影响概括损失，按整体收益、错误影响及频率决定采用；明显错误归因、完成状态翻转或错误合并不能仅用覆盖增加抵消。

候选准备先保持总量及近期份额，比较各查询代表候选去重后再按全局相关性补足。相同话题的查询可能共享代表，不应为每条消息不断追加名额。多话题公平不能用无条件纳入弱相关噪声来宣称，边界和取舍须在报告说明。

画像继续标签加描述。本人明确而有持续用途的自述可以首次纳入，不要求重复；新增独立资料不能挤掉无关旧事实；修正只影响相关事实；未来变化保留当前到生效时点之间的状态。没有新适合画像的信息仍不更新，长期节点与画像分别判断，不自动复制全部原子。

## 接下来的验收

1. 用另行冻结的独立材料核对新增资料后条件与否定是否保留，区分“根本未建画像”和“更新丢失旧信息”。保持轻量结构，不自动复制全部原子，不按已见输出补专用规则。
2. 候选实验同时核对目标覆盖与噪声，区分多话题挤占、短句指代和无关问题；保持总名额、近期必要背景及字节开销记录。未经验证的分数门限不能作为相关性保证。
3. 连续链分别判断同事件更新、独立经历新建、重复事实no_change；同时记录误合并、限定丢失和无增量改写，区分可接受的小瑕疵与影响实际使用的持续问题。
4. 首次结构失败与既有3次有界纠正后的结果分开，使用各分支真实提交前态。保留失败后再判断协议恢复及语义收益，不以重跑成功替代失败证据。
